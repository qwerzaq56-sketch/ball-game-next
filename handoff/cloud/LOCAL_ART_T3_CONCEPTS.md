# T3 오브젝트 컨셉 · 승인 대기

2026-10-05 / 사용자 요청 “컨셉 계속 뽑아줘” / Codex 제작

지형 요청 팩29의 T3 비교판 두 장이다. 생성 이미지는 래스터 참고이며 SVG나 게임 리소스로 확정하지 않는다. 승인된 T1·원본002를 직접 참조했다. T2의 캐릭터 가시성은 양호하고 패턴은 향후 원화와 비슷하게 개선 필요하다는 피드백은 계속 유지한다.

## 비교판 A · 위에서 아래

초원 꽃무리, 초원 바람돌, 숲 열매 덤불, 숲 수호 고목, 호수 진주 조개밭, 설원 얼음꽃, 설원 서리 피난석. 왼쪽 사용 가능/활성, 오른쪽 소진/휴식의 형태 차이를 비교한다.

## 비교판 B · 위에서 아래

호수 해류, 호수 소용돌이, 사막 오아시스, 사막 모래 비석, 화산 흑요석 광맥, 화산 열기 분출구. 해류 첫 행은 경로 변형, 나머지는 상태 차이 참고다. 두 판의 묶음은 제작 편의이며 각 오브젝트의 게임 기능을 새로 분류하거나 변경하지 않는다.

## 구현할 때 구분할 것

이득/위험 경계·방향 화살표·스택 숫자·이름·재사용 흐림은 코드 표현이다. 그림에 굽혀 넣지 않는다. 접촉 반경·보상·쿨다운·상태 판정은 변경하지 않는다. 형태와 상태 차이가 줌0.5에서 읽히는지 실제 구현 시 검증한다. 생성 비교판만으로 이 검증 완료를 주장하지 않는다.

공·T1·T2 방향 승인은 이 T3의 자동 승인이 아니다. 사용자 피드백을 받아 승인 부분만 SVG 제작 대상으로 정리한다. 게임 코드나 공개 배포는 수정하지 않는다.

## 생성 결과 검수

planning/art-concepts/objects-t3a-001.png와 objects-t3b-001.png에 각각 7행·6행, 상태 두 열이 생성됐다. 정확한 프롬프트는 같은 이름의 -prompt.md에 보존했다. 꽃·열매·진주·얼음꽃·흑요석·분출구는 형태 차이가 보인다. 바람돌·고목·비석은 주로 명도 차이이고 해류/소용돌이는 강도 비교다. 오아시스·피난석 상태 차이는 작아 실제 재사용 표식과 함께 읽혀야 한다.

일부 고목·비석·조개·흑요석은 완전한 수직 시점보다 기울어진 일러스트로 생성됐다. 디자인 참고로 사용하되 최종 자산 제작 시 게임 카메라에 맞춰 평면화해야 한다. 실제 접촉 범위나 위험 경계로 그림 실루엣을 사용하지 않는다. 0.5줌 판독은 아직 실제 게임에서 검증하지 않았다. 아직 사용자 승인 없음.
