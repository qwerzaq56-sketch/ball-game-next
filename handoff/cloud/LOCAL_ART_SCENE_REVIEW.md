# 효과와 지역 플레이 화면에서 아트 검토

2026-10-05 / 사용자 직접 제안: 개별 오브젝트뿐 아니라 아군 버프 효과·각 지역 실제 게임 화면 컨셉을 만들고 화면 안에서 오브젝트를 재구상한다.

## 작업 방식 추가

개별 오브젝트 형태를 정하는 것과 플레이 화면에서 읽히는 것을 함께 확인한다. 작은 크기·여러 개체·전조·효과·지형이 공존하는 화면에서 과한 물체는 축소/단순화하고, 기능을 알기 어려운 물체는 실제 수혜 개체의 효과로 연결한다. 생성 컨셉은 실제 게임 캡처를 참조하지만 구현 결과와 구분한다. 마지막 검증은 실제 캡처(T5)로 한다.

## 기존 규칙 유지

생성 화면에 표시된 효과/개체 수/먹이/범위/장식이 새로운 게임 기능을 뜻하지 않는다. 승인된 공 몸체·수치·종족·대상·쿨다운·위험 판정은 유지한다. 기존 피난처의 전체 범위 동상 해제나 오아시스의 실제 회복 대상을 임의 동색 전용으로 바꾸지 않는다. 아군 강화의 실제 효과 정의도 그림으로 대체하지 않는다.

패턴은 원화처럼 유기적인 면·겹침을 늘리는 방향으로 발전시키되, 사용자 평가 '캐릭터 가시성 양호'를 유지한다. 버프는 공격 전조보다 낮은 시각 우선순위, 종족 몸색/실제 크기를 가리지 않는 짧고 얇은 표현이다. 대표 대형 배경 형상·새 능력·폐쇄 지형·실제 UI 교체를 이번 컨셉에서 추가하지 않는다.

## 검토 기준

1. 먼저 공의 몸·방향 전조·현재 위험이 읽히는가.
2. 누가 누구에게 어떤 혜택을 받았는지가 효과의 출처/도착으로 읽히는가.
3. 작은 오브젝트가 배경 장식과 구별되고 이동 공간을 과하게 차지하지 않는가.
4. 여러 효과가 겹쳐도 화면이 과밀하지 않은가.
5. 준비·수혜·다시 준비되는 장면이 기능 서사를 설명하는가.

이미지 컨펌과 실제 게임 가독성 검증은 별개다. 생성 후 관찰 사항을 아래에 추가하고, 승인된 부분을 후속 SVG/효과 구현에 사용한다.

## 001차 결과 관찰 · Codex 의견

3장 생성 완료, 아직 사용자 세부 컨펌 없음. 효과의 시작/전달/소멸과 6지역 배치를 확인했다.

- 고목은 화면의 이동 공간 옆에 작은 군락으로 두고 보호 잎의 도착으로 역할을 보여주는 방향이 적합하다. 숲 가장자리의 연속 수관은 벽처럼 읽힐 수 있어 실제 자산은 틈과 밀도를 더 조정한다. 물리 장애물로 추가하지 않는다.
- 조개밭·꽃·열매는 작은 군집으로 묶되 공 몸체와 비슷한 크기의 먹이/보상 표현이 전투 개체로 오인되지 않게 한다. 바람돌은 초원 화면에서 충분히 구별되지 않아 문양이 보이는 소형 돌로 후속 검토한다.
- 피난처는 수혜 개체의 서리 해제, 오아시스는 수혜 회복 효과로 읽히게 한다. 생성된 설원은 밝아서 하늘색·흰 전조 대비를 실제 자산에서 다시 조정해야 한다.
- 효과 비교판의 오아시스→개체 연결선과 초록 펄스는 전달 순간 참고이며 계속 유지하는 선/넓은 발광으로 구현하지 않는다. 보호막·강화는 작은 표식, 회복은 짧은 물결, 동상 해제는 각진 서리 파편으로 차별화한다.
- 화산 생성 화면의 용암 폭·위험 원이 큼직하다. 실제 위험 크기·위치·개수는 기존 판정 그대로, 장식 분포로 새로운 위험을 만들지 않는다.
- 생성된 HUD·버튼·플러스·종족 몸의 잎표식·연결 점선은 참고이며 실제 UI/스킬 교체 승인으로 취급하지 않는다. 지역 B의 민트 플러스는 회복 오인 가능성이 있어 일반 강화 표식으로 단순 복사하지 않는다.

화면을 먼저 구성하고 오브젝트를 다시 조정하는 검토 절차는 사용자 요청으로 채택한다. 구체 배치·범위·기능 변경은 이번 이미지에서 확정하지 않는다.
