# M15: 실시간 장시간 브라우저 검증 계획

M9–M14의 기능 개발과 가속 시뮬레이션에 이어, 렌더링/DOM/오디오/입력까지 포함한 실제 브라우저를 한국 시간 낮 12시(2026-10-03T03:00:00Z)까지 연속 관찰한다. 이 문서는 계획이며 장시간 통과 결과를 선행 주장하지 않는다.

`node tools/browser-live-soak.mjs 2026-10-03T03:00:00Z /tmp/ball-next-live-soak.json`

- 시드 23, 터치 브라우저 에뮬레이션, 세로/가로 전환과 주기적인 안내 열기/닫기를 포함한다.
- 가장 가까운 먹이를 찾고 위협에서 도주하며 공격/스킬/회피 입력을 시도하는 통제 정책이다. 테스트 목숨을 보충하므로 자연 플레이의 생존/난도나 사람 플레이를 주장하지 않는다. 실제 다중 터치 이벤트는 별도 기능 검사로 검증했다.
- 매 활성 프레임 apex≤3, 대열 2–6명과 리더/동일 색·평화 상태를 확인하고, 1초 간격으로 생존 개체의 유한 좌표/HP/속도와 고아 대열을 검사한다.
- 주기적으로 게임 시간·프레임·검사 수·몸집·패배·동행 진입/이탈·능력 발동·JS heap을 기록한다. JS heap은 대략적인 브라우저 수치이며 전체 RAM이나 누수 확정 근거가 아니다.
- 결과는 /tmp에 원자적으로 저장한다. 실패 시 기록/스크린샷을 남기고 중지한다. 완료한 뒤 최종 자료를 reports에 복사해 작업 브랜치에만 푸시한다.

도구의 30초 예비 실행은 1,754프레임·1,869개체 표본을 검사했고, 플레이어 크기 20→30.97로 실제 이동/섭취가 진행됐다. 이는 장시간 결과와 분리한다. 현재 기능 테스트는 103개 통과다.
