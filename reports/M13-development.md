# M13: 창 이탈 자동 정지와 지속음 정리

창의 blur 또는 문서 숨김 신호에서 런을 멈추고 이동·공격·회피·E 대기 입력을 지운다. 돌아온 뒤 자동으로 재개하지 않고 P/계속하기 버튼으로 재개한다. 정지 표시에는 창 전환 이유를 알려준다. 안내를 연 상태에서 창을 떠났다면 안내를 닫아도 정지를 유지한다. 최초 프로필 선택/게임 오버/초기화 확인과는 충돌하지 않는다.

일시정지·안내·초기화 확인은 흡수의 지속 오디오 그래프를 즉시 정리한다. paused Game.update도 남은 지속음을 정리하며, 다시 실제 흡수가 진행되면 한 번만 재생을 시작한다. 지속음이 정지 중 무한히 울리거나 매 프레임 새 그래프를 만들지 않는다. 일반 단발 효과음의 짧은 종료음은 유지한다.

검증: 단위 테스트 **100/100 통과**. 정지 시간/snapshot 불변·지속음 한 번 정리·재개 재생·리셋 정리 포함. Chromium에서 통제한 blur/visibilitychange 신호로 정지·입력 해제·수동 재개·안내 중 이탈 상태 복원과 실제 Web Audio 그래프가 다음 RAF 이전에 제거되는 것을 확인했다. 이 검사는 OS가 실제 탭 전환 신호를 전달하는 하드웨어 시험을 대신하지 않는다. 기존 P/H/초기화 취소/설정 저장/모바일 안내 회귀 통과, 페이지 오류 없음.
