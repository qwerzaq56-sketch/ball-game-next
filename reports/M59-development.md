# M59 — 흡수 충격과 복수 전쟁

흡수의 기존 크기/남은HP 비례 총비용을 진행25%/완료75%로 분할했다. 완료 피해는 성장HP증가 후 적용해 직후 회복에 가려지지 않으며 붉은HP텍스트/피격표시/플레이어 피해음이 난다. 실제 지불량은 최대HP1% 생존선에서 제한하고 비용 때문에 취소하지 않는다. 이미1%미만이면 더 깎지 않는다. 도중 해제 시 지급한 부분은 반환하지 않는다. 공격·지형의 실제 피해에는 이 생존선이 적용되지 않는다.

경계 중 접촉을 이동 업데이트마다 처리한다. 공격 가능하면 즉시 시작하고 불가능하면 도주해, 결정 타이머 대기 동안 몸을 부대끼며 멈추지 않는다.

전쟁기 최상위마다 한 번80% 선언 확률. 직접 공격/스킬의 실제 누적 최대HP20% 피해가 역참전을 유발한다. 상대 목록을누적하는방향Set,방향쌍당피해비율합을사용한다. 상대와의거리/회복/직위상실/사망이목록을지우지않으며전쟁기끝에해제한다. AI/자동플레이는전쟁상대를공격우선으로추격하고HP10%이하에만도주한다. 수동플레이어입력은강제로조작하지않는다. 동색전쟁도허용하며흡수/평화동행/동색버프에서는제외한다. 캐릭터⚔상대수,디버그라벨,Era플레이어상태와참전인원표시를추가했다.
