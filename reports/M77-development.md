# M77 — 회피 중 흡수 유지·최소 공격 이동·달리기 강화

회피 시작과 무적 상태는 진행 중 흡수를 취소하지 않는다. 회피로 실제 흡수 유지 거리 밖으로 멀어지면 연결과 진행이 취소된다. 피흡수자·흡수자 양쪽 회피의 근거리 유지와 진행값 보존을 회귀 검증했다. 현재 개발 코드의 거리 기준을 확인한 작업이며, 존재하지 않는 회피 취소 조건을 제거했다고 주장하지 않는다. 사망·크기 역전·흡수 토글 해제·기존 피격/빙결/동행 합류 중단 규칙은 유지한다.

무차징 이동 하한은 `min(풀차징 거리, max(70, 풀차징 거리×0.12))`로 조정했다. 이전 하한은 풀차징 거리의 3%였다. 예를 들어 비최상위 Size 400의 풀차징 거리 600에서 무차징은 18→72다. 충전량에 따라 이 하한과 기존 풀차징 거리 사이를 선형 보간한다. 피해 배율과 풀차징 이동 상한은 유지하며 조준 미리보기와 실제 이동에 동일 함수를 사용한다.

달리기를 기본 이속의 1.5→2.1배로 강화했다. 기존 달리기 대비 40% 빠르다. 크기 150 해금·게이지 3초·회복 규칙·짧게 Space 회피/길게 달리기와 모바일 별도 버튼은 유지한다. 지형/버프 배율은 기존대로 함께 적용된다.

새 테스트 4개: 피흡수자 회피 중 연결/진행 유지 후 거리 이탈 중단, 흡수자 회피 중 유지, 실제 무차징 이동/미리보기 일치와 풀차징 상한, 실제 달리기 2.1배와 회피 충전 보존. 전체 테스트 328개 통과. 실제 Chromium에서 Space 짧게 회피/유지 달리기와 회피 충전 보존을 재확인했다. 페이지 JS 오류 없음.
