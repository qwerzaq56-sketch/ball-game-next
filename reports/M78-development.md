# M78 — 지형 오브젝트 효과 개편

꽃/조개 치장과 동행 확률, 바람돌 3스택 15초 이속, 흑요석 3스택 보호막 및 공방 버프, 열매 덤불의 주기 먹이·회복 아이템을 적용했다. 열기 분출구는 분출/휴식 주기와 범위 내 지속 피해를 가진다. 호수 해류는 다양한 폭의 호수 내부 경로를 따라 캐릭터와 먹이를 이동시키고 소용돌이는 중심으로 당긴다.

이득은 초록 실선·+·마름모, 위험은 붉은 점선·경고 삼각형, 해류는 하늘색 경로·방향 화살표로 구분한다. 보호막 잔량과 스택, 몸 주변 꽃/조개 치장을 표시한다.

F1에서 20개 후보를 선택할 수 있고 기본 배치는 13종·78개다. 이전 후보와 수치를 보존하며 v1 저장을 새 효과로 이관한다. 맑은 샘 교체의 미확정 효과는 별도 백로그에 남겼다.

검증: 전체 자동 테스트 336개 통과. 치장 만료, 3스택 발동, 보호막 실제 피해 흡수와 소진 후 보너스 종료, 접촉 없는 보상 생성과 성장 없는 회복, 분출 주기 피해, 해류의 먹이/캐릭터 이동, 소용돌이 당김, 프리셋 이관·잘못된 설정 거부를 검증했다. 실제 Chromium에서 기본 78개 배치·20개 후보, 소용돌이 이동, 새 설정 저장 후 재로드 복원을 확인했고 JavaScript 오류는 없었다.
