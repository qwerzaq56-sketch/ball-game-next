# M17: 장시간 이벤트 기록 정리

일반 브라우저 플레이에서 특수기·직위 원시 이벤트를 최근 256개로 제한한다. 특수기 총 시전 횟수는 별도 누적 카운터로 유지하고 스냅샷은 전체 목록 재검색 없이 읽는다. 기존 최상위 포식자 이력은 누적 횟수와 기간을 계속 보존한다. 명시적인 collect 모드의 분석 도구에서는 전체 이벤트를 유지한다.

초기 직위가 undefined에서 false로 설정될 때 발생하던 가짜 apex-loss 기록도 제거했다. 실제 직위 획득·상실은 그대로 기록한다. 직위 판정과 전투 난수에는 영향을 주지 않는다.

## 검증

단위 테스트 108개 통과. 1,000회의 시전·직위 상실을 기록해 최근 목록 제한, 총계 유지, 분석용 전체 로그, 초기화 및 시작 시 가짜 상실 기록 부재를 검증했다. M17 미커밋 소스를 대상으로 실제 Chromium 5분 검증을 완료했다: 17,893프레임·23,320개 개체 검사, 최상위 최대 3명, 오류 없음. 보고서의 commit은 기반 4dc02f0이며 테스트한 전체 소스 커밋을 뜻하지 않는다. M15 정오까지 검증은 기존 로드 버전으로 별도 진행 중이며 결과를 혼합하지 않는다.
