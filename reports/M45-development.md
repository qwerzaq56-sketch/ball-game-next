# M45 — 먹이·흡수·사냥 잠재 기회와 실제 성장

안전한 먹이 지표를 보존하면서 별도 기회 경로와 최근 실제 성장 달성을 추가했다. F1, 관찰 JSON, 밸런스 그래프가 같은 구분을 사용한다. 기본3시드10분 자료만 먼저 읽고 다른 비교 자료는 선택할 때 불러온다. 네트워크 실패 재시도, 오래된 요청 무시, 이전 JSON의 미측정 표시를 검증했다. 성장·전투·먹이 공급 규칙은 이번 단위에서 변경하지 않았다.

전체 테스트 **227/227** 통과. 실제 Chromium의 실패/재시도·빠른 데이터 전환·조건 필터·관찰 가져오기·옛 JSON 검증과 페이지 오류0을 확인했다. [브라우저 기록](M45-browser.json), [잠재 경로](M45-potential-channels.png), [실제 성장](M45-actual-growth.png).

기회는 한 시점의 충분한 잠재 보상, 실제 성장은 이전 구간의 결과로 서로 같은 사건을 추적하는 표가 아니다. 작은 몸 구간 표본이 적고 생명 전환/시작 구간은 실제 성장 미측정으로 제외한다. 흡수는 성공, 사냥은 성공 및 드롭 전량 수거를 가정하므로 실제5초 달성을 보장하지 않는다. 예상 사냥 시간도 추격/회피/경쟁을 제외한 기본 공격 근사다.

Size400+에서 먹이만 보면 기회0이지만 실제 성장이0은 아니다. 그래도 현재5초 성장 기준 달성은3.9%로 후반 병목이 남는다. 지표를 넓혀 병목을 해결했다고 주장하지 않는다. 추가로 목표800개의 먹이가 장기적으로 약650개에서 평형을 이루는 보충 로직을 확인했다. 부족분200개마다 보충1개를 추가하는 비례 규칙은 소비량과 같아지는 지속 오차를 남긴다. 다음 단위는 수치 자체를 높이지 않고 기존 목표에 도달하도록 부족분 보충을 수정하고 같은3시드로 비교한다.
