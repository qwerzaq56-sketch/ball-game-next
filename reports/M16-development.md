# M16: 큰 공의 공간 검색 비용 감소

큰 개체의 검색 반경이 넓어질 때 빈 격자 셀을 반복 탐색하던 비용을 줄였다. 일반 검색은 기존 격자를 유지하며, 64개를 초과하는 셀 범위에서는 점유 셀만 원래 x/y 순서로 탐색한다. 격자를 다시 만들거나 게임을 초기화하면 정렬 캐시를 폐기한다. 아군 연결은 같은 색의 최대 반경을 사용하며 큰 범위에서는 같은 색 후보를 직접 확인한다. 거리·연결 히스테리시스·공격·성장·직위 규칙은 유지한다.

## 검증

- 단위 테스트 106개 통과. 큰 범위의 검색 순서, 캐시 초기화, 매우 큰 유한 반경의 종료, 큰 공의 색상별 연결과 진입/해제 거리 검증 포함.
- 시드 7/11/23 각각 300초·18,000프레임의 개선 전후 스냅샷, 연결, 대열, 통계, 난수 상태가 정확히 일치했다. 플레이어 생존은 검증용으로 보정했다.
- 시드 23의 크기 1,200 플레이어 10초·600프레임에서도 동일한 항목이 정확히 일치했다.
- 실제 Chromium에서 대열 연결·동행 평화·G 이탈·연결 표시 전환·인스펙터·모래바람 회귀 검증 통과.
- 합성 80개 개체 벤치마크에서 연결 수와 검색 결과 수는 같았다. 크기 4,000의 연결 갱신 평균은 1.6848ms → 0.0823ms, 검색 평균은 0.0590ms → 0.0013ms였다. 단일 클라우드 실행의 합성 수치이며 실제 모바일 성능 보장은 아니다.

M15 실시간 브라우저 검증은 이전 로드 커밋 a34c4e4로 계속 실행 중이다. 이 개선을 장시간 실시간으로 검증했다고 주장하지 않는다. 종료 결과는 별도 보고서에 기록한다.
