# M12: 선택형 월드 지도와 터치 능력 피드백

- 기본 OFF인 미니맵을 F5/지도 버튼으로 켠다. 먹이·색별 공·내 위치/방향·최상위 표시·현재 화면 범위를 그린다. 설정은 새로고침과 새 게임에 유지한다.
- F2가 열린 상태에서 지도 위 AI를 클릭하면 상세 정보만 선택한다. 지도 클릭 자체로 인스펙터를 열거나 이동/공격하지 않는다.
- HUD·순위·생태계·터치 컨트롤을 피하는 위치를 선택한다. 작은 화면은 지도를 축소하며, 다른 패널 표시도 유지한다. 지도가 차지하는 공간은 이름 라벨도 피한다. 모든 패널을 동시에 크게 띄워 공간이 없으면 화면 안의 중앙 하단 위치를 사용한다.
- 터치 버튼에 공격/회피 해금 크기, 충전·빙결·동행 금지, E 최상위 조건·시전·쿨다운·행동 상태를 표시한다. 회피 버튼은 실제 회피 가능한 상태에서 활성화한다. 공격 버튼 유지/드래그와 동행 회피 규칙은 유지한다.

단위 테스트 **98/98 통과**. 브라우저에서 F5 표시/저장, 미니맵 그림의 RNG 및 snapshot 불변, F2가 열려 있을 때만 선택, 390×844에서 HUD/순위/생태계와 지도 배치를 검증했다. 실제 다중 터치의 이동+공격/드래그 조준·회피·E·취소·회전·정지와 버튼 해금/동행/충전 상태 검사 통과. 기존 키보드·TOP10·F1–F4·표시 독립성·저장·리셋·삼중 파도 회귀 통과. 페이지 오류 없음.
