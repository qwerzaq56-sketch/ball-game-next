# 캐릭터·공통 효과 묶음 · 2026-10-06

승인 원화의 정확 크롭을 직접 생성 입력으로 사용했다. 원본·좌표·SHA256·프롬프트·실패 시안은 각 자산 팩에 보존한다. 개별 그림보다 실제 Game.render에서의 합성을 기준으로 채택했다.

## 반영

- 몸체 3단계: 기존 공격 해금/최상위 상태로 선택. 5종 실제 색으로 캐시하고 명암을 제한한다. 몸체 광원은 고정, 문양·방향·필수 윤곽은 기존 렌더 유지. 실제 visualSize 반경 유지.
- 공통 질감 7종: 차징·피격·회피·보호·강화·서리 해제·회복. 장식은 몸체/필수 벡터 아래에 배치. 피격은 기존 impact-ring의 실제 접촉점에만 합성하며 보호막 피격의 청록 표현은 기존 벡터 유지.
- 회복은 HP가 실제 증가한 대상, 서리 해제는 동상이 실제 해제된 대상에만 짧은 표시 타이머를 부여. 범위 밖 대상과 체력 가득 찬 대상에는 새 회복 표시 없음. 게임 효과·수치·대상·쿨다운·게임 난수 불변.
- 성장 질감은 기존 성장 펄스에만 연결. 흡수 질감은 거친 파편이 남아 제작 결과만 보존하고 실제 연결 보류. 기존 흡수 진행/방향 유지.
- 이미지 실패 또는 아트 비활성 시 기존 벡터 렌더 유지. 캐릭터 색 캐시32, 공통 효과7, 성장 색 캐시24 상한. 최초 로딩/보정만 픽셀 작업.

## 확인

전체 402/402 테스트 통과. 실제 렌더 fixture에서 5색·크기40/100/200 및 최상위400 단일색, 방향0/180·이동·중첩·ON/OFF, 6지역 줌0.5/1 캡처. 브라우저 오류/경고0, 7효과 loaded/failed[] 확인. 수혜 비교: HP250→255 및 회복 표시20.22, 밖은250/표시0. 동상1→0 및 해제 표시20.3, 밖은1/표시0. 접촉점은 몸체 중심에서 반지름50만큼 떨어짐. 피격 생성 함수의 통제시각 호출이며 실제 피해 판정 테스트를 뜻하지 않는다.

캡처 `character-effects-001-*`. 모든 조합/자연 전투/FPS 검증 완료는 아니다. 설원 안개가 범위 밖 캐릭터를 가리는 기존 동작 유지. 큰 화면 합성/최초 지형 청크 지연은 남아 있다.

규칙 추적:117카드/109승인/106구현/93검증, 기존 충돌1·확인식 불일치3 유지. AI 쿨다운 카드1.8/구현1.5, 옛 차징 테스트 제목2곳 및 파란 AI 패턴 확인식은 이번 아트 변경 전 HEAD에도 동일. 해당 게임 코드를 수정하지 않았다. VIS의 잘못된 기존 테스트 제목만 실제 제목으로 정정. 추적과 밸런스 산출물은 repo 밖 ART_SPEC_TRACE_TEMP.md/ART_BALANCE_SHEET_TEMP.md에 보존.

## 병목과 다음
