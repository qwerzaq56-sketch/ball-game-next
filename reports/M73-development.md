# M73 — 지형 오브젝트 후보 시스템

요청: 지형별 2~3개 오브젝트 기획·구현, 스킬처럼 후보 선택 시스템.

## 적용

6개 지형에 각각 2개, 총 12개 구현. 기본 배치 72개. 먹이 공급·회복·보호막·이동 보조·동상 저항·체력 비용 효과를 실제 접촉 판정에 연결했다. F1에서 후보 선택, 종류별 배치 개수, 개별 수치 조정, 기기 저장, JSON 내보내기/가져오기, 기본값 복구를 제공한다. 후보 원본은 비활성화해도 보존한다.

상세 수치·의도·위험·복구 정책: [기획서](../BIOME_OBJECT_CATALOG_DESIGN.md).

## 검증

- `node --test --test-isolation=none tests/*.test.mjs`: 313/313 통과.
- 신규 6개 테스트: 지형별 배치와 결정성, 잘못된 설정의 원자적 거절, 후보 선택과 쿨다운 보존/먹이 상한, 접촉과 회복 상한, 실제 버프와 비용, 눈보라 먹이 배율.
- 로컬 HTTP + 실제 Chromium: 후보 12개 표시, 한 후보 해제 시 72→66개, 종류별 개수 2로 저장 후 새로고침하여 22개 복원, 단일 후보 JSON 가져오기, 잘못된 JSON 거절 후 기존 설정 유지, 기본값 복구 확인. 페이지 JS 오류 없음.
