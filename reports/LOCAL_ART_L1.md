# L1 · 승인 공 몸체와 지형 연결

2026-10-06 KST / 야간 구현 첫 단위 / 사용자 최소 컨펌·실제 리소스 반영 승인

전투 개체의 공 몸체를 평면 색·얇은 윤곽·몸 안의 아래 음영으로 바꾸고 기존 문양·방향·피격·직위 표식은 유지했다. 먹이 orb는 기존 표현을 유지한다. 6지형18 SVG·8마스크를 assets/terrain에 실제 배치하고 브라우저 로딩 후 한번 raster 캐시, 셀 좌표 기반 변형, 경계 alpha 합성을 연결했다. 경계 중간에 양쪽 색을 뒤집지 않도록 최대50%씩 혼합한다. 경계 캐시는 최대96개(200×200), 실패/OFF는 기존 단색, 디버그 패널에 지형 아트 ON/OFF 추가.
