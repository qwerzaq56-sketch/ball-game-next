# M66 방향 동기화·진행형 흡수 위험

기본 조준/시선을 이동 방향과 동기화하고 정지 시 마지막 시선을 유지한다. 모바일 드래그는 조준 방향을 우선하고 탭 회피는 현재 시선을 사용한다. PC 공격 조준 시 마우스 방향, 자동 플레이 명시적 조준은 유지한다.

흡수는 기존 제안 비용 곡선 전액을 진행률에 따라 지불하며 완료 충격 피해를 제거했다. 성공 시 실제 지불의25%를 회복한다. 작은 아군3%완료회복과 최대HP1% 생존선은 유지한다. 취소/실패는 환급하지 않는다. 성장의 자동HP회복은 제거 상태를 유지하고 총지불/회복/순비용을 로그에 기록한다. 세부 수치는 [게임 기획](../GAME_DESIGN.md)에 기록했다.

검증:

- 전체 `node --test --test-isolation=none tests/*.test.mjs`: **304/304 PASS**.
- 최대HP2000,Size400에서 건강한Size380 흡수: 절반 진행 시HP1250, 총지불1500, 완료회복375, 완료HP875. 절반 크기는 총비용20%, 성공 순비용15%. 작은 아군은 기존3%회복. 생존선에서 제한된 실제지불을 기준으로만 성공회복을 계산한다.
- 신규 방향 검증: 아래로 이동 시 시선 아래, 왼쪽 드래그 시 이동 방향을 덮어씀, 멈춘 뒤 탭 회피는 왼쪽 시선 사용.
- 실제 Chromium 네이티브 멀티터치: 오른쪽 이동 중 기본 시선 오른쪽, 공격을 아래로 드래그하면 시선 아래로 변경, 공격 해제 시 왼손 이동 유지, 회피 버튼 탭 시 설정된 현재 시선으로 회피. 취소 초기화/페이지 오류 없음. [결과](M66-browser.json), [화면](M66-mobile-dual-touch.png).

실제 iOS Safari 기기와 새 흡수 정책의 장기 밸런스는 이번 검증 범위에 포함하지 않는다. 성공회복25%는 조절 가능한 초기값이다.
