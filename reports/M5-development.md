# NEXT M5 — 생태계 관찰과 삼중 파도

2026-10-03. 기존 `codex/cloud-next-m4`에서 개발. 공개 main·통합 브랜치와 기존 ball-game은 변경하지 않았다.

## 구현

- 출생 시 고정되는 개체 이름. 표현 전용 `names` 난수, 고유 id 접미어. 점수 상위 20개체에 고정 글자 크기 표시, 이름끼리/HUD와 충돌하면 위치 조정 또는 생략.
- 현재 생존 개체의 TOP 10 점수 순위. 동점 시 기존 평가 순서 유지, apex 별표, 내 순위 하단 표시. AI 행 클릭은 F2 Inspector를 열어 해당 개체 선택.
- F4 생태계 패널: 현재 보유자·연속 보유 시간, 최근 등장/상실, 부재·단독·공존 누적 시간, 최장 보유/단독 시간. 현재 런에 한정하고 정지 시 시간도 정지. 최근 목록은 제한해 장기 메모리 증가를 막고 총계 유지.
- 이름/순위/생태계 표시 설정을 별도 `ballgamenext_presentation_v1`에 저장. 저장 불가/손상 데이터 시 안전한 기본값. 리셋은 런 기록을 지우고 표시 설정·로컬 고득점 기록은 유지.
- 파란색 3방향 파도. 중심 조준 + 좌/우 [-120°, -40°]/[40°, 120°] 방향을 시작 시 고정. 전조/발사/발동 표시가 같은 방향 사용. 시전당 10초/전조 0.6초, 길이 400·폭 180, 대상당 일반 공격 0.5배, 기존 밀침/면역 유지. 공유 피격 Set으로 중복 피해/MISS/밀침 방지. 명령도 시전당 한 번.
- 390px 좁은 화면 HUD/순위 겹침 수정, 표시 버튼/스크롤/패널 닫기 지원. F1–F4 키 반복으로 의도치 않게 여러 번 토글하지 않도록 개선. Inspector가 전체 리셋 후 이전 id의 추적 기록을 재사용하지 않도록 처리.

## 검증

`node --test --test-isolation=none`: **72/72 통과**, skipped/failed 0. 기존 56개와 이름/RNG/순위/배치/기록/저장 및 삼중 파도 회귀 16개.

UI만 추가한 중간 상태의 seed 23 / 300초 전체 측정 JSON은 이전 `reports/apex-diversity-23-300.json`과 정확히 일치했다. UI 관찰은 전투 전개를 바꾸지 않는다. 최종 삼중 파도는 **시전당 AI 난수 두 번과 추가 측면 공격 범위**로 이후 전개를 의도적으로 바꾼다.

`node tools/browser-m5.mjs`: 실제 Chromium에서 게임 초기화/리소스/이동, TOP 10/Inspector 선택, F1–F4, UI 토글 전후 게임 체크포인트 일치, 새로고침 설정 유지, 보유 시간, 이름/패널 겹침 방지, 1280×720/390×844 배치, 음소거/초기화, 실제 E키 전조/삼중 발사 통과. 페이지 오류·필수 리소스 실패 0. `reports/M5-*.png`에 화면 기록. apex 및 능력 장면은 강제 fixture이며 실제로 성장해 직위를 얻은 플레이 세션 검증과 구분한다.

`node tools/review-scenarios.mjs`: 성장형 위험감수/약한 apex 도전 두 기대 상태 일치. `git diff --check` 통과.

## 최종 시뮬레이션

기존 정지 플레이어를 생존 고정하는 60Hz 관찰. 원본 JSON은 `M5-metrics-<seed>-<seconds>.json`.

| 시드 / 초 | 공격 시작 합계 | 상태 전환 p90 | 탐색↔도주 | 다른 보유자 | 칭호 획득 / 상실 | 최장 보유(초) |
|---|---:|---:|---:|---:|---:|---:|
| 7 / 300 | 664 | 0.60 | 3019 | 3 | 3 / 0 | 178 |
| 11 / 300 | 587 | 0.58 | 3235 | 3 | 3 / 1 | 100 |
| 23 / 300 | 637 | 0.61 | 3038 | 4 | 5 / 1 | 182 |
| 23 / 900 | 1915 | 0.59 | 9055 | 11 | 35 / 30 | 782 |

300초 M4 대비: seed 7은 동일, seed 11 공격 625→587/p90 0.59→0.58/탐색↔도주 3173→3235, seed 23 공격 647→637/p90 0.59→0.61/탐색↔도주 3064→3038. 기존 M3 공격 합계 488/500/441보다 최종 664/587/637이 높고, 전환 안정성도 유지한다. 모든 구간별 증가를 주장하지 않는다.

900초 seed 23은 11개체가 칭호를 보유했고, 획득 35회/상실 30회와 최장 782초의 연속 보유가 함께 나타났다. 부재 118초·단독 142초·이후 공존 구간을 관찰했다. 장기 보유에는 측정 종료 시 진행 중인 기간도 포함한다. 이 결과가 모든 시드에서 다양한 교체/독점을 보장한다는 뜻은 아니다.

직위 확정 히스테리시스 때문에 교체 중 기존 보유자와 후보가 일시 공존할 수 있으며 이번 900초 측정에도 6개체 구간 2초가 있었다. 직위의 점수 상위 5위/크기≥100 후보 기준과 확정 규칙을 변경하지 않았다. 칭호 획득·상실은 여러 직위 출입을 포함해 직접적인 후계 교체 횟수가 아니다.

## 사용과 한계

저장소 루트에서 `python3 -m http.server 8001 --bind 127.0.0.1`. 이름/순위/생태계 버튼, F2 Inspector, F3 상태 표시, F4 생태계, apex일 때 E 특수능력. UI는 기존 정적 서버로 실행하며 새 런타임 의존성이 없다. 브라우저 검증은 환경에 설치된 Playwright와 Chromium을 사용한다.

이번 검증은 키보드/마우스 게임 및 좁은 화면 배치까지다. 모바일 터치 조작, 모든 플랫폼/폰트 조합, 사람의 장기 실제 플레이는 검증하지 않았다. 월드 확장·순환 맵·성격 비율·직위 자격 변경은 구현하지 않았다. 게시/배포는 수행하지 않는다.
