# M47 — 모래바람 수치와 AI 회피 판정 일치

F1 수치를 바꿔도 일반 AI는360/420, 대열 일부는420으로 장판을 판단하고 있었다. 실제 장판 반경을 사용해 작은 장판 바깥에서 불필요하게 행동을 멈추거나 큰 장판 안에서 위험을 무시하는 불일치를 수정했다. 진입 radius, 기억된 회피/대열 지휘/전투 보호 radius+60으로 기본360/420을 유지한다. 일반 감지320과 공격력/쿨다운은 바꾸지 않았다.

전체 **231/231** [테스트](M47-tests.log): 실제 작은/큰 반경·회피 유지/해제·지휘·대열 전투 회귀 포함. 실제 Chromium의 [E/R 키·터치·후보 복구](M47-slots-browser.json), [최소 UI·다중 터치·드래그 해제·회전 취소](M47-release-mobile-release.json) 모두 통과, 페이지 오류0. 이 브라우저 검사는 입력 회귀이며 장판 AI 판정 자체는 통제 테스트에서 확인했다.

`tools/simulate-color-cohort.mjs`로 다섯 시작 색×3시드 각300초 일반Life·HP 측정을 시작했다. 이 커밋에는 완료 전 자료를 넣지 않고 이후 완료/분석 단위에서 제공한다. 각1초에 크기/HP/좌표 유한성·직위 상한·동행 보호/구성·기록 상한을 확인하고5초마다 성장/위기/스킬을 관찰한다. 시작 색은 동족/적대 관계와 이동·생존 경로도 바꿔 단일 스킬의 인과효과로 해석하지 않는다. 설정은 시작 시 동결하고 JS 소스 해시를 기록한다. 물리 Safari 검증과 실제 사용자 체감은 미측정이다.

작업/푸시는 codex/cloud-next-m4만 수행한다.
