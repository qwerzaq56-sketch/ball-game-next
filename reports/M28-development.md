# M28 자동 탐색 목적지 유지

기본OFF 자동 플레이만 local-survival-v2로 변경한다. 무목표 이동을6초마다 방향을 바꾸는 반복 사각형에서, 크기 경계를 반영한600거리 목적지 유지/도착40거리/최대12초/최근4원점 회피로 바꾼다. 시드와 선택 순번으로 방향을 정하며 추가 난수는 소비하지 않는다. 수동 전환·재시작 시 목적지/최근 경로와 봇의 회피 대기 상태를 초기화한다. 위협/먹이/유물 우선순위,800 먹이 탐색과360 위협 감지, 일반 Life·평화·해금은 유지한다. 실제 이동이 달라져 이후 세계 전개와 난수 소비 경로는 달라진다.

먹이/적/유물/바이옴 없는 통제 월드120초에서는 종료 위치가 시작에서16.67거리였던 반복 경로에서1760거리 정도로 벗어났다. 6초마다 샘플링한500격자 구역 수7→18, 시작점으로부터 최대 거리2121→2626이었다. 이는 실제 자연 플레이가 항상 같은 구역에 갇혔다는 주장이 아니다.

테스트147개 통과. 실제 Chromium에서 성장·Life3 유지·키보드/마우스 수동 전환·정지·JSON·초기화OFF와 실제 터치 수동 전환/모바일 표시가 통과했다.

동일 M25 런타임/시드에서 두 정책을 각각600초 일반 Life로 비교했다. 세 실행 모두 Life3/패배0이었고 전체 직위는 최대3이었다. 방문 지역 다양성과 점수는 다른 지표다.

모든 시드의 점수를 개선했다고 주장하지 않는다. 이전 v1 장기 실행과 v2를 혼합해 해석하지 않는다. 관찰 집계M27이 추가되어도 세계를 보정하지 않는다. 이번10분 원본은 M27 관찰 집계를 포함한 런타임이며 측정 도구의 byPhase 출력 추가 전 실행이어서 파일에는 해당 필드가 없다. 원본과 비교 정책은 reports/M28-natural-before.json, reports/M28-natural-autoplay.json.

## 실행 기반시설 중단

이전 실제 브라우저 세 실행은 프로세스가 사라진 상태로 발견되어 완료PASS가 아니라 INTERRUPTED_PROCESS로 보존했다. M15 이전코드7866.65초, M24/v1 1900.86초, M26/v1 1086.96초가 마지막 기록이다. 정확한 프레임/검사/오류는 각 partial JSON에 있다. 원인은 확정하지 않았다. 응답하지 않는 로컬 서버를 파일 로그를 사용하는 지속 세션으로 복구하고 이후 코호트의 표준출력도 파일로 보관한다. 최신 코호트 결과는 정오에 별도 기록한다.
