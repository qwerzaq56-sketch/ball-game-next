# M23: 자동 플레이 실험·밸런스 관찰

CLOUD_HANDOFF.md 후속 순서6의 자동 플레이/밸런싱 도구를 AUTO_PLAY_DESIGN.md 기준으로 구현했다. F1에서 명시적으로 켜는 기본OFF 실험 기능이다. 새로운 런/초기화에서는OFF, 일반 Life/피해/해금/쿨다운/동행 평화를 유지하며 Game Over에서 멈춘다. 키보드 게임 입력·마우스/화면/터치 조작은 수동으로 전환하고, P/H 및 창 전환 정지는 봇도 멈춘다.

최근600개 초 단위 관찰과 누적 공격 시작/자동 조작 시간을 보관한다. F1의 최근 크기 그래프·현재 통계·JSON 저장은 읽기 전용이다. 시드/현재 설정/정책/샘플/직위 이력/Era 이벤트를 저장하며 외부 전송은 없다. 추가 자동 선택 난수는 사용하지 않지만 실제 플레이 행동이 바뀌면 세계 전개도 달라진다.

## 검증

- 테스트139개 통과: 기본OFF/지역 먹이/도주/난수 무소비, 동행 평화, 일반 Life와 Game Over, 관찰 주기/600샘플 제한/누적 총계, 내보내기 무변경·복사 독립성.
- Chromium: 자동 성장(크기20→25.06, 점수10), Life3 유지, 키보드/마우스 수동 전환, 정지 중 완전 스냅샷 유지, JSON 실제 다운로드/무변경, 초기화OFF. 실제 터치 조이스틱/화면 전환·모바일 관찰 패널 검증도 통과했다. 통제 장면이며 자연 생존 결과가 아니다.
- 자동 플레이OFF 시드23/600초 비교: 관찰 메타데이터와 미구현 기능 표기만 제외한 핵심 스냅샷·생태계/능력/Era 이벤트·아군 통계·world/ai/physics 다음 난수 값이 b878a59와 정확히 일치했다. reports/M23-disabled-parity.json.
- 실제 Game.update의 자연 Life 정책으로 세 시드 각각10분 가속 자동 플레이를 완료했다. 체력/생명을 보충하지 않았다.

유물 획득10회/시드는 전체 개체 합계이며 플레이어 획득 수가 아니다. 이 봇은 최적 전략이나 사람이10분 살아남는다는 증거가 아니다. 첫apex가 없다고 희소/독점 목표 실패로 판단하거나 직위 획득을 강제하지 않는다. 정확한 정책/샘플은 reports/M23-natural-autoplay.json에 있다.

표현 개선M22와 자동 관찰M23을 구현했으며 전체 벡터 표현팩의 모든 미정 자산까지 완료했다고 주장하지 않는다. 다음 작업은 실제 자동 플레이 장기 관찰·새 지역/전쟁/유물의 다중 시드 검증과 발견되는 경계 문제 수정이다.
