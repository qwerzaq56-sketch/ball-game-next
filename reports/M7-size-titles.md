# M7 크기 기준 직위 검증

아군 연결은 ALLY_CHAIN_DESIGN.md 기획만 작성했다. 거리·버프 수치는 제안이며 미구현이다.

apex 후보는 생존 개체의 크기 상위 5위 중 크기≥100. 점수/성장 계산, 2초 평가·2회 확정·사망 즉시 상실·부활 재확정은 유지한다. 점수 순위와 크기 순위 UI는 별도로 유지한다.

검증: `node --test --test-isolation=none` 81/81 통과. 크기/점수 역순, 동점 유지, 최소 크기·6위 제외, 직위 확정·사망/부활 회귀 포함. `node tools/browser-size-titles.mjs`로 실제 브라우저의 큰 개체 직위와 점수/크기 HUD 분리를 확인했다. 페이지 오류 0. `git diff --check` 통과.

정지 플레이어 생존 고정, 60Hz 측정. 직위가 바뀌면 능력·관계·성장 전개가 달라지므로 이전 시드 결과와 달라지는 것은 예상되는 변화다.

최장 기간에는 측정 종료 시 진행 중인 보유도 포함한다. 칭호 획득/상실은 여러 직위의 출입을 포함하며 직접 후계 교체와 다르다.

원본 JSON과 `M7-size-titles.png`를 보존했다. 기존 안정적 직위 확정 때문에 순위가 바뀐 즉시 별표가 사라지는 것은 아니며, 이 전환 중 직위가 일시적으로 5명보다 많을 수 있다. 크기 기준 변경만으로 생태계 다양성을 보장한다고 주장하지 않는다. 실제 사람의 장기 플레이는 미검증이다.
