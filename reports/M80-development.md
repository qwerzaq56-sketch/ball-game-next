# M80 · 시뮬레이션 룸과 기획자 의견 팝업

계측 대상만 초기 소환하는 별도 페이지를 구현했다. 방 크기·시드·종족·크기·HP·거리·대상 수·고정/실제 AI·최상위 상태를 설정한다. 실제 Game 전투·흡수·스킬 코드를 공유하며 자연 소환·환경·자동 직위 교체를 제거했다. 스킬 자체의 소환은 효과로 남는다. 일반 플레이 기본값과 저장값을 수정하지 않는다.

A 기준 수치를 고정하고 B 수치를 변경한 뒤 동일 조건·행동을 1~60초 비교한다. 0.1초 표본의 HP·흡수 진행·누적 피해 비율 그래프, 실제 피해·최종 크기·잔존 대상 비교표, 조건/설정/표본 JSON을 제공한다. 보기 확대는 물리 수치에 영향을 주지 않는다.

AI 질문은 `data/designer-questions.json`에 작성해 배포하면 30초 내외에 의견 대화창으로 요청할 수 있다. 직접 호출 API도 제공한다. 질문 동안 게임을 정지하고 입력을 비우며 이전 정지 상태를 복구한다. 질문과 답변·맥락을 로컬 저장하고 내보낸다. 답변 서버 전송이나 AI 채팅 자동 연결은 이번 범위에 없다.

## 검증 결과

- 전체 Node 테스트 356개 통과.
- 동일 시드·조건 재실행 결과 일치. 실제 AI·기본/최상위 스킬 해금, 외부 개체 미생성, 실험 수치 복제, 부상 흡수 단축 검증.
- PC/모바일 Chromium 오류 0건. 기본 피해 10→250만 변경한 10초 1회 충전 공격: 실제 HP 누적 피해 77.24→343.94. 이는 수치 작용 검증용 극단값이며 일반 플레이에는 미적용.
- 흡수 완료·성장, 답변과 A/B 조건 저장, JSON 다운로드, 배포 질문 수신/답변 중복 방지, 일반 텍스트 표시, 팝업 입력 초기화/이전 정지 상태 복구 검증.
