# 몸체 단독 상태 비교 준비

`tools/character-effects-review.html`에 몸체 비교 원클릭 프리셋을 추가했다.

버튼은 현재 READY에 대응하는 combat `idle`, status `none`, size `100`, color `all`, direction `0`을 설정하고 기존 `build()`를 호출한다. 지역·줌·몸체/효과/지형 ON/OFF 선택은 유지한다. build가 이동 및 수혜 probe를 해제하고 통제 장면을 다시 만든다. READY/상태 없음이므로 차징·공격·회피·피격·보호막·강화·동상·성장 중첩을 제거해 현재 몸체 비교가 가능하다.

종족 식별 문양은 별도로 숨기거나 바꾸지 않았다. 실제 Game.render, 캐릭터 모듈, 게임 판정/수치/RNG 변경 없음. 몸체 OFF를 기존 폴백과 비교하고 기존 상태 선택으로 효과를 하나씩 추가할 수 있다.

초기 공 원화·정확 프롬프트와 5색×3단계 exact crop 15개 좌표/SHA manifest 및 기존 분석 메모 링크를 추가했다. 링크는 원본을 재작성하지 않는다.

검증: HTML module Node 문법 검사 통과. 실제 브라우저 버튼 동작 및 동일 조건 최종 몸체 시각 비교는 부모 검수 대상이다. 이 통제 장면은 자연 플레이/FPS 검증이 아니다.
