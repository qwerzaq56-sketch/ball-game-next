# M32 — 가로 중심 모바일 UI·흰색 중심 조준 화살표

사용자 요청: 가로 화면 기본 기획 반영 및 진행, 중심에서 벗어난 공격/회피 표시 수정,
단순한 흰색 화살표 디자인.

- 가로/세로 orientation 자동 배치. 가로는 양쪽 아래 조작부와 한 줄 최소 HUD,
  전체 HUD는 조작부 위 영역에서 스크롤. 세로 최소 모드에는 가로 권장 안내.
- 고정 HTML 조준선을 제거하고 캐릭터 중심 월드 좌표에 흰색 화살표를 그린다.
  기존 화면 좌표 오버레이는 캔버스 표시와 별도 배치였으며, 사용자 환경의 정확한
  어긋남 원인을 재현했다고 주장하지 않는다. 새 구현은 몸체와 같은 변환을 사용한다.
- 조준 중 작은 방향 삼각형 중복 제거. 조준 종료 후 기존 방향 표시 복원.
- 100dvh와 실제 캔버스 표시 크기 및 visualViewport 갱신. 회전/화면 변경 시 조준 취소.
- 게임 내 도움말·기획서 갱신. 기존 공격/회피 해제 실행과 전투 규칙 유지.

검증:

- 전체 테스트 149개 통과.
- `browser-mobile-landscape.mjs`: 844×390 → 390×844 → 812×375 자동 배치,
  가로 안내 전환, 양쪽 조작부 간격, HUD와 조이스틱 비중첩, 전체 HUD 스크롤 확인.
  최소 HUD 높이36px. 카메라를 몸체에서 벗어나게 하고 zoom=.65에서 렌더링한
  화살표 시작점과 `worldToScreen(player)` 오차 0.001px 미만, 중심 주변 흰색 픽셀 확인.
- `browser-mobile-release.mjs`: 실제 CDP 터치로 공격/회피/화면 드래그 해제,
  단순 탭 무공격, 이동 동시 조작, 취소·정지·회전 오발 방지 및 UI 저장 통과.
- 실기기 회전 잠금 해제와 브라우저 화면 회전은 운영체제 설정을 따른다.
  실제 휴대폰 하드웨어 검증은 하지 않았다.

산출물: M32-landscape-check.json, M32-landscape-white-arrow.png,
M32-mobile-release.json 및 모바일 가로/세로 스크린샷.

Safari 스크린샷 후속: 상단 주소창/탭 표시줄은 브라우저 UI라고 안내하고 iOS
홈 화면 웹앱 실행 메타데이터와 게임 내 추가 안내를 제공했다. 실제 Safari의
표시줄 숨김 및 홈 화면 실행은 실기기에서 미검증이며 Chromium 결과와 구분한다.
