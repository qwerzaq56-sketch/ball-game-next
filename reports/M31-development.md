# M31 — 모바일 화면 점유와 드래그 후 전투

사용자 요청: 모바일 최소 UI 토글, 공격·회피 버튼 및 빈 화면 드래그 후 손을 떼어 실행.

- 모바일 기본 최소 표시: HP/LIFE/일시정지와 터치 조작. 전체 UI 버튼은 항상 접근 가능.
  선택을 저장하며 표시 전환은 기존 순위/지도/관찰 설정을 변경하지 않는다.
- 버튼 드래그 방향을 고정한 해제 입력을 한 번 소비한다. 이동 조이스틱과 독립적인
  회피 방향을 적용하며 공격 유지 입력을 만들지 않는다. 화면은 8px 이상 드래그만 공격.
- 금색 공격/하늘색 회피 조준선. 취소·정지·초기화·회전·백그라운드 시 오발 방지.
- 기획서와 게임 내 도움말 갱신. 데스크톱 조작과 전투 수치 변경 없음.

검증:

- `node --test --test-isolation=none`: 149/149 통과.
- `tools/browser-mobile-release.mjs`: Chromium CDP 실제 터치, 이동+공격 동시 조작,
  버튼을 누르는 동안 스택 유지, 공격/회피 해제 시 한 번 소모 및 방향 확인,
  화면 드래그 공격/단순 탭 무공격, 취소·정지·회전 후 무공격, UI 전환·저장.
  390×844 및 844×390 최소 HUD 높이 100px 미만. 페이지 오류 0.
- 기존 모바일 검증: E 시전/발사, 해금 안내, 동행 제한, 조준, 회피, 다중 터치 통과.
- 데스크톱/기존 조작 검증: 일시정지·도움말·초기화·동행 HUD 통과. 도움말 검증은
  M30의 Space 버튼 활성화를 고려해 비버튼에 포커스를 두고 게임 키 차단을 확인한다.
- 실제 휴대폰 하드웨어 조작감은 아직 확인하지 않았다.

산출물: `M31-mobile-release.json`, `M31-mobile-minimal.png`, `M31-mobile-landscape.png`.
기존 정오 장시간 코호트는 M28 핵심 코드 대상이며 이 모바일 변경의 검증과 구분한다.
