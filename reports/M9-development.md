# M9: 대열 안정화와 플레이 편의

사용자의 컨펌 없이 후속 개발 요청에 따라 M8에서 관찰한 동행 움직임과 조작 피드백을 개선했다. 최상위 3명, 확률·연결 버프·모래바람 피해 기준은 유지한다.

- 위협 진입 320/해제 400, 모래바람 진입 360/해제 420으로 도주와 복귀의 경계 반복을 줄였다. 죽거나 적대성이 사라진 위협은 즉시 잊는다.
- 기존 AI 대열에 플레이어가 합류하면 플레이어를 선두로 바꾼다. AI 리더는 가장 느린 구성원의 속도 기준으로 배회하고 월드 경계에서 안쪽으로 돌린다.
- 동행 진입 즉시 시전자 유지 장판뿐 아니라 나가는 흡수 연결도 취소한다. 명령 능력은 평화로운 동행자를 수신자로 고르지 않는다. 빙결/회피/회복 중인 이웃과 가득 찬 대열은 합류 후보에서 제외한다.
- HUD에 대열 인원·공격 제한을 표시하고, 특수능력 이름과 실제 사용 불가 이유를 보여준다. 연결선 표시 설정과 접근성 상태를 저장·즉시 반영한다.
- P/버튼으로 일시정지. H/버튼으로 플레이 안내. 안내를 닫으면 원래 진행/정지 상태를 복원한다. 초기화 확인 중에도 진행을 멈추고 취소하면 원래 상태로 돌아간다. 정지/모달에서 공격·회피 입력이 쌓여 복귀 후 발동하지 않도록 정리한다.

## 검증

단위 테스트 **95/95 통과**. 새 회귀는 플레이어의 기존 대열 리더 인계, 느린 구성원 속도, 위협 및 장판 기억 해제, 나가는 흡수 즉시 취소, 경계 회전, 명령 수신 제외를 포함한다.

Chromium: P 정지·시간 동결·재개, H/Esc 전 상태 복원, 초기화 확인 정지/취소, 입력 대기열, 연결선 저장/재접속, 동행 HUD/스킬 제한, 390×844 모바일 안내/버튼 화면 통과. 기존 이동·순위·F1–F4·표시 RNG 독립성·설정 저장·리셋·E 삼중 파도·G 이탈 회귀 통과, 페이지 오류 없음.

| 시드/시간 | 상태 변경 p90 (초당, M8 → M9) | 도주↔동행 전환 (M8 → M9) | 최대 apex |
|---|---:|---:|---:|
| 7/300초 | 1.81 → 0.70 | 11037 → 2088 | 0 |
| 11/300초 | 2.11 → 0.80 | 12950 → 2772 | 1 |
| 23/300초 | 2.34 → 0.66 | 17092 → 2482 | 2 |
| 23/900초 | 2.66 → 0.75 | 48838 → 7700 | 3 |

상태 전환은 크게 줄었지만 신규 RNG 경로로 세계 경로도 달라졌다. 생태계 동등성이나 점유량 비감소를 주장하지 않는다. 시드 7의 5분 동안에는 아직 크기 100 조건을 통과한 apex가 없었다. 이는 희소기를 허용한 기획과 부합하며 직위 기준을 낮추지 않았다.

실제 이동·공격·회피·특수능력 입력을 시도하는 능동 플레이 검사: 시드 17/900초/60Hz와 29/300초/20Hz 모두 완료. 모든 프레임의 apex 상한, 대열 구성원·리더·평화 행동, 1초별 좌표/HP/속도 유한성·고아 대열을 검사했다. 테스트가 사망 시 목숨을 보충하므로 자연 플레이의 생존 보장은 아니다. 이 실행에서 플레이어는 apex를 얻지 못해 특수능력 입력은 발동하지 않았으며, 실제 특수능력은 별도 브라우저 검증으로 확인했다.
