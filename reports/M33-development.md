# M33 — 전투 버튼 피드백·모바일 렌더링 비용

사용자가 승인한 우선 작업: 전투 버튼 피드백, 모바일 성능 개선.

- 공격/회피 충전 횟수와 다음 충전 진행 막대. 조준 중 흰색 테두리 강조.
- 실제 canStartAttack/canStartDodge/canCast 판정과 비활성 상태를 일치시키고
  해금·빙결·충전·행동·동행·E 시전/재사용 대기를 구분. 공격 중 회피 허용 규칙 유지.
- 화면 밖 아군/흡수 선과 입자 그리기를 생략. 화면을 가로지르는 선, 확장 링,
  화면 밖 중심을 가진 큰 몸체는 유지. 이펙트 수명·게임 판정·난수 사용 변경 없음.

검증:

- 전체 테스트 **154/154** 통과. 충전/전투 판정, 상태 우선순위, 표시의 읽기 전용 성격,
  화면 횡단 연결선·큰 몸체·확장 입자 경계 회귀 테스트 포함.
- 실제 Chromium CDP 터치: 이동과 공격 동시 조작, 공격/회피/화면 드래그 해제,
  단순 탭 무공격, 취소·정지·회전 오발 방지 통과.
- 버튼 충전 수/진행률/접근성 문구, 빙결·충전·행동·동행·E 재사용 표시 통과.
- 결정론적 합성 부하: 아군 선1000개·입자4000개, 대부분 화면 밖.
  최적화 전후 최종 캔버스 이미지 SHA256 **동일**.

| 지표 | 전 | 후 |
|---|---:|---:|
| stroke 호출 | 2041 | 141 |
| arc 호출 | 4018 | 218 |
| 효과 그리기 p50 | 3.0ms | 0.2ms |
| 전체 render p50 | 3.1ms | 0.3ms |
| 전체 render p95 | 3.6ms | 0.6ms |

위 수치는 동일 합성 장면의 동기 그리기 호출 측정이며 일반 플레이 FPS나 실기기
발열 개선 수치가 아니다. 전 측정은 M32 렌더링 코드, 후는 로컬 M33 변경 코드다.

추가 활성 게임6초씩 Chromium 측정: 모바일360프레임, render p50 .4ms/p95 2.6ms,
update p95 4.7ms. 데스크톱355/디버그360프레임, 모든 페이지 오류0.
성능 도구는 HP/Life를 보충하며 생존 검증이 아니다. 실제 iPhone Safari/발열은 미검증.
