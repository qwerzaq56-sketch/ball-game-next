# M75 — 최상위 1대1·스킬 영향력

최상위 개체 1대1, 일반 AI와 전쟁 AI 정책을 분리해 실제 전투 로직으로 시뮬레이션했다. 크기 200/400/800, 모든 종족 조합, 좌우 교환과 순서 교대를 사용한다. 후보 실험 후 최종안은 일반 240경기, 전쟁 240경기, 새 검증 시드 전쟁 240경기를 측정했다.

전쟁 실험의 원본은 빨강 96승/0패, 파랑 2승/87패였다. 적용 후 무승부 제외 종족 승률은 개발 시드 44.4~55.4%, 새 검증 시드 41.5~61.9%였다. 일반 AI 승패 점수는 45.3~56.3%이며 무승부를 반승으로 계산한 점수와 확정 승률을 구분한다. 남은 크기별 극단 상성과 시드 편차는 후속 실험 대상이다.

[상세 기획과 공식](../APEX_DUEL_INFLUENCE_DESIGN.md), [승패 그래프](M75-duel-balance.png), [크기별 영향력 그래프](M75-influence-size.png).

F1에 현재 E/R의 개체 노출·면적·지속 비중·명목 피해·노출 압박 표시를 추가했다. 불쾌도 0~5와 현재 계수를 기기에 저장·JSON 내보내기 할 수 있다. 잠재 지표이며 실제 사용자 불쾌도의 검증된 최적값은 아니다. 삼중 파도와 큰 토러스 원형 면적은 상한으로 표시한다. 보조 스킬의 간접 공격은 전투 실험으로 따로 평가한다.

검증: 전체 테스트 320개 통과. 범위/피해 기대값을 조정안에 맞게 갱신하면서 한 번만 타격, 빙결, 면역, 밀침, 대열 합류와 방어 보너스 회귀 검증을 유지했다. 새 검증은 영향력 공식의 유한값·독립 면적/개체 지표·부채꼴 실제 대상·동맹 제외·재현 가능한 듀얼·무승부 보존을 확인한다. 실제 Chromium에서 표시 수치, 평가 3 저장, JSON 다운로드, 페이지 JS 오류 없음 확인. [화면](M75-influence-ui.png).

실제 단말과 사용자 체감 데이터는 아직 수집하지 않았다. 자연 월드, 다른 성향·지역·시간 제한, 60Hz 정책은 별도 검증 범위다. 개발 브랜치만 푸시한다.
