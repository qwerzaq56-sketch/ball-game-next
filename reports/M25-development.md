# M25 전선 표시와 몸체 테두리

전쟁기의 색별 목적지를 월드 색 깃발과 F5 지도 네모로 표시한다. F4는 실제 전선 이동 개체 수를 표시한다. 기존 목적지 좌표/이동 규칙/직위는 유지한다. 표시와 실제 좌표가 같고, 전쟁 종료 시 제거되며 읽기 전용임을 Chromium과 모바일390×844로 확인했다.

벡터 표현 검증에서 Canvas save/restore가 현재 path를 복원하지 않아 문양/성장 링/방향 화살표가 몸체 테두리 경로를 덮는 문제를 발견했다. 몸체를 채운 직후 테두리를 먼저 그린다. 몸체 반경40(크기80)의 fill과 흰 테두리를 실제 Chromium에서 확인했다. AI의 검은 테두리와 플레이어 흰 테두리도 장식이 있는 실제 drawEntity 호출로 검증한다. 난수/전투를 추가로 변경하지 않는다.

테스트143개 통과. reports/M25-browser-war-fronts.json 및 desktop/mobile 이미지 참조. 단순 표현 단위이며 미정 전체 벡터 자산팩 완료라고 표현하지 않는다.
