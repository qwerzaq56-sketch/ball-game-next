# M26 정지와 인스펙터 입력 일관성

F2가 켜진 상태의 Shift+클릭은 자동 플레이를 끄지 않고 AI만 선택한다. 이전 pointerdown 수동 전환이 인스펙터의 mousedown 선택보다 먼저 실행되어 읽기 전용 선택이 자동 모드를 끄던 문제를 해결했다. 일반 화면 클릭은 계속 수동으로 전환한다.

일시정지 중 G와 동행 이탈 버튼은 대열 상태를 바꾸지 않는다. 버튼은 비활성화되고 이벤트 처리에도 정지 조건을 적용한다. 재개 후 G는 정상 이탈한다. 정지 중 게임 입력에 의해 자동 모드를 수동으로 전환하는 정책 자체는 유지한다.

실제 Chromium에서 Shift 선택 전후 전체 스냅샷 동일/자동 ON 유지, 일반 클릭 OFF, 정지 중 G/버튼 차단, 재개 후 이탈을 확인했다. 기존 아군 연결/평화/G/모래바람 브라우저 통합 시나리오도 통과했다. reports/M26-inspection-inputs.json. 세계 규칙과 난수 변경 없음.
