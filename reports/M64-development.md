# M64 개발/검증

하늘색 E를 보호막, R을 지연 냉기 폭발과 누적 빙결 장판으로 교체했다. 이전 냉기 찌르기/즉시 빙결 휘두르기는 별도 후보 ID와 실행 코드로 보존했다. 최신 규칙과 수치는 [게임 기획](../GAME_DESIGN.md), 복구 후보는 [스킬 후보 목록](../SKILL_CATALOG_DESIGN.md)에 기록했다.

- E: 자신의/근처 동료 최대HP15% 보호막6초,9초 쿨다운. 방어 뒤 피해 차감, 재시전은 합산하지 않고 큰 값 갱신, 만료/사망 해제.
- R: 직접0.35배→1.2초 표식→대상의 현재 위치에0.35배 폭발→5초 장판.0.5초마다0.6배, 장판별3회 성공 타격 시1.2초 빙결(한 번). 범위 성장 비례. 피해자는 생명 교체 시 표식 취소.
- 최상위 자격에 현재 생존 최대Size의50% 조건 추가. 상대 기준 미달은 다음2초 주기 평가에서 즉시 해제. HUD/F3/인스펙터는 내부 프레데터 역할 대신 특별 직위를 표시한다.
- 흡수 연결이 걸린 AI는 충전이 있으면 회피로 탈출한다. 일반 도주·플레이어 수동 입력 유지.
- 화면 몸체 크기를 감쇠 스프링으로 보간한다. 실제 성장/충돌/순위는 즉시 적용하고 공격 범위는 실제Size로 표시한다. 연속 성장 시 움직임을 초기화하지 않는다.

전체 `node --test --test-isolation=none tests/*.test.mjs`: **301/301 PASS**. 마지막 장판 틱 피해 조정 후 새 기능6개 테스트도 재통과했다. 기존 후보의 피해/빙결/프리셋 테스트는 해당 후보를 명시적으로 선택해 복구 가능성을 계속 검증한다.

신규 검증은 보호막 차감/갱신/만료, 이동한 대상 위치 폭발/3회 빙결/장판 만료, 생명 경계 표식 취소, 최대Size 절반 자격과 해제, AI 회피 탈출, 시각 성장 수렴을 포함한다.

실제 Chromium에서도 E/R 신규 후보 적용, 보호막150, 장판 생성과 빙결1.2초, HUD 최상위 표시를 확인했다. 성장은 시각Size200→0.05초에206.82→최종244로 수렴했다. 페이지 오류 없음. [결과](M64-browser.json), [화면](M64-frost-shield.png).

실제 Safari 기기와 신규 냉기/보호막 정책의 장기 성장·전투 밸런스는 이번 검증 범위에 포함하지 않는다. 저장한 사용자 스킬 프리셋은 기존 선택을 유지하므로 새 기본 후보를 사용하려면 기본값 복구 또는 후보 선택이 필요하다. 여러 대상이 만드는 장판은 중첩 가능하며 추후 실측할 밸런스 변수다.
