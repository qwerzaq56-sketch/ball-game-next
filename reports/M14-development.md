# M14: 성장 목표와 초기/동적 스택 일관성

HUD에 현재 크기에서 가장 가까운 공격/회피 해금 또는 추가 스택 목표와 진행 막대를 표시한다. 목표는 현재 임계값 설정을 읽고 점수와 분리한다. 모든 일반 능력이 해금되면 최상위의 별도 조건(크기 100/상위 3위)을 알려준다.

재현한 두 문제를 수정했다. 스택을 모두 쓴 상태에서 용량을 낮추면 플레이어/AI의 스택이 -1이 되던 문제를 0–용량 범위로 보정한다. 초기 성장값이 양수이면 첫 먹이 전에도 크기·HP·해금 상태를 성장 공식과 일치시킨다. 기본 초기 성장 0의 동작은 유지한다. F1 스킬 임계값 변경은 플레이어와 생존 AI에 즉시 반영하며, 용량 증가 때는 새로 생긴 슬롯만 충전한다. 숫자 설정은 유한한 값만 받는다.

검증: **103/103 단위 테스트 통과**. 초기 성장 400→크기52/HP260/공격·회피 각1스택, 용량 감소의 빈/사용한 스택 보정, 증가 슬롯 보상, 설정별 성장 목표 포함. Chromium에서 실제 F1 입력으로 용량 감소/증가 즉시 반영과 음수 방지, 단계별 목표, RNG/snapshot 독립성, 모바일 HUD를 확인했다. 기존 이동·순위·관찰 패널·설정·리셋·삼중 파도와 다중 터치/가로 화면 회귀 통과.
