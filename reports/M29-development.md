# M29 F1 시드 재시작

F1 관찰 도구에 재시작 시드를 입력할 수 있다. 입력/검증/취소는 현재 게임의 시드나 세계를 바꾸지 않는다. 기존 초기화 확인 창의 문구에 선택한 시드를 보여주고, 확인할 때만 적용해 이름/색상 선택으로 돌아간다. 관찰 기록과 자동 모드는 새 런으로 초기화하며 일반 초기화 버튼은 기존 시드를 유지한다. 새 실행에서도 기본OFF다. 0 이상 안전 정수만 허용한다.

같은 시작 배치를 비교하는 도구다. 전체 전개 재현은 코드/설정/색상/입력/시간 간격도 같아야 한다. 저장된 전역/로컬 랭킹의 동작은 기존 초기화 경로를 사용한다. 새로운 설정 저장 키나 자동 외부 전송을 추가하지 않는다.
