# M65 모바일 조작·AI 충전·냉기 지속

모바일 왼쪽 화면에서 시작한 터치를 이동으로, 오른쪽에서 시작한 터치를 충전 공격으로 처리한다. 플로팅 조이스틱은 터치 위치에 표시하고 해제 시 숨긴다. 이동/공격 포인터는 독립이며 중앙을 넘어도 역할을 유지한다. 기존 버튼 조준/회피/스킬/흡수/달리기를 유지한다. 가로 최소 도구를 왼쪽 아래로 옮겨 흡수 버튼과 겹침을 제거했다.

AI는 목표 거리로30~100% 충전량을 정하고 플레이어와 같은0.9초 완충/거리/피해 계수를 사용한다. 준비 중 흰색 게이지와 실제 충전량에 해당하는 예상 거리가 커지고 종료하면 돌진한다. 목표가 없는 직접 호출은 기존75% 기본값을 유지한다. 기존 회피/빙결 취소와 공격 간격 제한은 유지한다.

냉기 지속 요청은 하늘색 R 장판 수명을5→15초로 반영했다. 빙결 시간1.2초와 표식 지연1.2초는 유지한다. 프리셋 장판 편집 범위는30초까지 지원한다.

- 전체 `node --test --test-isolation=none tests/*.test.mjs`: **302/302 PASS**. 신규 AI 거리별 충전/게이지/완충 피해 테스트와15초 냉기 만료 검증 포함.
- 실제 Chromium 모바일 viewport/네이티브 멀티터치 입력: 왼쪽 플로팅 조이스틱 표시/이동, 오른쪽 충전 조준, 오른손만 해제 시 공격하면서 왼손 입력 유지, 취소 시 이동0/조이스틱 숨김. 페이지 오류 없음. [결과](M65-browser.json), [두 손가락 화면](M65-mobile-dual-touch.png).

실제 iOS Safari 기기/장기 AI 밸런스와 냉기15초 정책의 성장 그래프는 이번 검증 범위에 포함하지 않는다. 상세 현재 규칙은 [게임 기획](../GAME_DESIGN.md)에 기록했다.
