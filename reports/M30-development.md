# M30 CSV 관찰 저장과 버튼 키보드 입력

관찰 JSON 버튼을 Space로 활성화하면 창의 Space 회피 처리에서 기본 동작을 막고 자동 모드를 꺼 버렸다. 통제 Chromium 장면에서 다운로드0/자동OFF/스냅샷 변경을 재현했다. 포커스된 버튼의 Space/Enter는 기본 버튼 활성화로 처리하고 게임의 회피/수동 전환 입력으로 처리하지 않는다. 일반 게임 화면 Space 회피는 유지한다. 명시적인 동행 이탈 버튼은 G 키처럼 수동 모드로 전환한다.

F1은 최근 최대600샘플을 UTF-8 BOM/CRLF CSV로 저장한다. 시드/정책/시간/점수/크기/HP/AI/직위/동행/시기/지역/역할/누적 공격/자동 여부17개 열을 제공한다. 사용자 이름은 CSV 열에 넣지 않는다. JSON에는 현재 이름·색상과 아군 흡수 토글도 포함해 조건을 확인할 수 있다. 현재 조건/관찰 자료이며 입력과 설정 변경 이력이 포함된 완전한 리플레이 파일은 아니다. 샘플이 없으면 CSV 버튼은 비활성화한다.

테스트149개 통과: CSV 숫자/Unicode/따옴표·줄바꿈 처리/빈 목록/600행 상한, 상태·난수 무변경 및 JSON 설정 복사. Chromium에서 Space로 JSON·CSV를 실제 다운로드하고 자동ON/전체 스냅샷 유지, 현재 색상 포함, 명시적인 동행 이탈/자동OFF와 모바일390×844 배치를 확인했다. before/after 원본과 통제 예제 CSV는 reports/M30-*.

세계 규칙·봇 정책·관찰 집계 변경은 없다. 진행 중인 정오 코호트는 M28 핵심 런타임이며 이 UI/내보내기 변경은 별도 통제 검증이다.
