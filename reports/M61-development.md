# M61 개발/검증 보고

요청한 최상위 스킬 적극 사용, 성장 비례 범위, 충전 공격, 흡수 위험, 사막 이동 모래바람과 조작/순위 UI를 구현했다. 최신 세부 규칙은 [게임 기획](../GAME_DESIGN.md)과 [바이옴 기획](../BIOME_DESIGN.md)에 기록했다.

## 실제 검증

- `node --test --test-isolation=none tests/*.test.mjs`: 288/288 PASS. 충전 거리/피해/즉시 돌진, AI 충전, 범위 스케일, 스킬 우선순위, 실제 흡수 비용·회복, 모래바람 생성/이동/만료/노랑 방어, UI 저장값 이전과 기존 회귀 검증 포함.
- 실제 Chromium PC와 모바일 viewport: F3 기본OFF 및 토글, 시작 안내/20초 종료, 이전 Score 기본값의 Size 이전, 최소UI의 투명 텍스트 순위표, 기본 공격과 모래바람 확인. 페이지 오류 없음. [브라우저 결과](M61-browser.json).
- Size400 수동 공격: 무충전 선딜0/거리18/피해0.35배, 완충 선딜0/거리600/피해2배. 실제 최종 피해는 방어력을 반영한다.
- 최대HP2000, Size400의 건강한 흡수 대상: Size380 비용1500(75%), Size200 비용400(20%), Size40 완료 회복60(3%). 성장 자동 회복으로 비용이 상쇄되지 않는 것을 확인했다. 흡수의1% 생존선 유지.
- `node tools/measure-apex-cadence.mjs`: 통제30초의 R/E 시전 횟수는 하늘색3/5, 파랑3/4, 초록1/4, 빨강2/4, 노랑3/4. 초록R은 생존 소환체2명 상한에 도달하여 추가 소환하지 않는다. 준비된 R이 사용할 수 없는 상태에서도 E는 계속 사용한다. [측정 원본](M61-apex-cadence.json).

## 검증의 범위

스킬 빈도는 정지·무적 적과 아군1명을 배치하고 일반 공격을 끈 사용 가능성 검증이다. 자연 전투/장기 성장 시뮬레이션이나 실제 Safari 기기 검증은 이번 결과에 포함하지 않는다. 기존 M57 밸런스 그래프는 이전 정책 측정 결과다. 공개 raw.githack URL은 클라우드 프록시 제한으로 직접 브라우저 검증하지 못했고 동일 파일을 로컬 HTTP에서 확인했다. 멀티플레이는 기존 기획 단계이며 서버 기능을 구현한 것은 아니다.
