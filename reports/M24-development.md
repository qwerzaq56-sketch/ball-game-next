# M24 성장 후 경계와 생성 위치

공의 지름이 맵 한 축보다 크면 해당 축의 중심을 맵 중앙에 둔다. 크기/점수에 상한을 추가하지 않는다. 일반 크기는 기존 경계 계산을 유지한다.

적 생성은 기존 후보와 크기 추첨 후 실제 몸 반경을 반영해 플레이어와 최소 max(350, 두 반경 합+80) 거리를 확보한다. 안전하지 않은 후보만 최대10회 재추첨한다. 공간 자체가 부족하면 가장 먼 합법적인 모서리로 배치한다. 좁은 맵에서 불가능한 안전 거리를 보장했다고 주장하지 않는다. 안전하지 않은 생성과 경계 근처의 배치는 달라지며 추가 world 난수 소비로 이후 전개가 달라질 수 있다.

테스트141개 통과. 직사각형 맵의 한 축 초과/양 축 초과/일반 경계, 커진 플레이어의 생성 간격, 공간 부족 시 유한 종료를 검증했다.

tools/browser-native-autoplay.mjs는 내장 자동 플레이의 실제 브라우저 장기 검증이다. 기존 Life 보충형 QA와 달리 체력/생명을 보충하지 않고 자연 Game Over에서 종료한다. 실행 결과는 완료 뒤 별도 기록한다.

후속 경계 일관성: 파도 밀림/동행 자리/자동 조작 목적지/AI 탐색/환경 우회가 같은 축별 경계를 사용한다. 직사각형 맵에서 한 축이 더 작아도 다른 축의 실제 반경은 유지한다. 테스트142개 통과. 실제 Chromium에서 크기6000 렌더의 중심2500/2500 유지와 플레이어 크기1800 주위 생성100회의 간격·몸체 경계를 확인했다. reports/M24-browser-world-bounds.json.
