# M67 영역·모바일 UI 검증

노랑 모래바람 기준 반경360→288, 빨강 오오라 반경Size×0.6(직경1.2배), 같은 반경의 빨강 R 집결을 적용했다. 기존 빨강 R 테스트는 축소 범위 안에 동료를 배치해 정원 제한 없이 실제 범위의 모든 아군을 집결시키는 동작을 계속 검증한다.

가로 화면은 viewport-fit=cover/고정 전체 캔버스로 콘텐츠 영역을 채우며 HUD 안전영역은 유지한다. 지도·생태계·순위·밸런싱·인스펙터·도움말 제목줄과 하단 바의 빈 부분을 드래그할 수 있다. 버튼/선택창/본문 스크롤은 유지하고 이동·회전 시 화면 안으로 위치를 제한한다.

플로팅 이동 조이스틱144px,손잡이64px,입력 반경48px로 확대했다. 표시 원을 화면 안쪽으로 보정하되 입력 원점은 실제 최초 터치 위치를 유지한다.

전체 `node --test --test-isolation=none tests/*.test.mjs`: **304/304 PASS**. 빨강 집결 범위와 대형 스킬 성장 회귀도 통과했다.

실제 Chromium 모바일 가로 viewport/네이티브 터치: 144px 조이스틱, 이동+드래그 공격, 탭 회피/취소, 지도 제목 드래그 확인. 캔버스는 x0/y0/844×390의 전체 영역, 페이지 오류 없음. [결과](M67-browser.json), [화면](M67-mobile-dual-touch.png).

실제 iPhone Safari의 상단 검은 부분 원인은 기기에서 재현하지 못했으므로 이번 화면 채움 대응으로 확정적으로 해결되었다고 판단하지 않는다. 브라우저 자체 UI는 게임이 숨길 수 없다. 영역 축소의 장기 전투 밸런스는 이번 검증 범위에 포함하지 않는다.
