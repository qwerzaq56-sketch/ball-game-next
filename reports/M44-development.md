# M44 — 스킬 수치 편집·저장·복구와 실제 범위 확인

F1에 후보별 수치와 해금/영역/공격 시간 배율 편집을 제공했다. R의 판정·미리보기·파도·지속 장판·강화·소환을 시전 당시 후보 정의와 연결했다. 별도 [규칙](../SKILL_CATALOG_DESIGN.md)과 `js/skillRules.js`에 허용 수치/범위를 둔다. 아직 실행 미구현인 대기 컨셉은 선택 메뉴에 넣지 않는다.

- 기기 저장/새로고침 적용, JSON 내보내기/가져오기, 기본값 복구. 가져오기를 모두 검증한 뒤에만 적용한다. 저장 오류/불가능한 JSON은 기본 실행 또는 기존 설정을 유지하고 이유를 표시한다.
- 실제 범위 안의 적·모집 가능한 동족을 확인한 자동 E/R 선택. AI 역시 후보 범위/파도 길이·폭을 확인한다. 수동 조준 실패는 허용한다.
- 시전/파도/장판은 당시 수치로 완료한다. 진행 중인 소환체를 새 수명/크기로 바꾸지 않는다. 수치 변경으로 합계가 섞이면 관찰/그래프에 표시하고 처음 시전의 수치를 보존한다.
- 노랑 E는 자기 방어 장막이고 주변 피해 범위가 아니다. 큰 원 대신 자기 몸의 장막 테두리로 표시한다. 직위 상한0이면 성장 안내에 OFF를 표시한다.

검증: 전체 **221/221**, 마지막 표시/안내 변경 후 관련45개 재검증 통과. [전체](M44-tests.log), [마지막 확인](M44-last-verify.log). 실제 Chromium 수치 편집·저장/새로고침·프리셋 JSON 다운로드/불러오기·기본 복구·잘못된 파일 거부 통과. 소환1명/재사용25초 설정을 실제 시전으로 확인했다. 기존 E/R 키·터치·후보 교체/회전과 관찰/그래프 필터도 통과, 페이지 오류0. [프리셋](M44-browser.json), [슬롯](M44-slots-browser.json), [그래프](M44-metrics-browser.json), [편집 화면](M44-skill-settings.png). 물리 iPhone/Safari는 직접 시험하지 않았다.

## 원인과 같은 시드 비교

M42 코드의 정적 복사본을 별도 경로에서 같은 동결 설정·시드로900초 실행했다. main/통합 브랜치는 수정하지 않았다. M43 E 병행 사용은 시드별 성장 결과가399→490,519→470,547→469로 일관되게 좋아지지 않았다. E 완료27/39/35회 대비 직접 명중은3/2/1회였다. 사거리 밖 요청이 가능한 코드와 통제 재현을 확인해 M44의 범위 검사를 추가했다. 이것이 모든 실패의 유일한 원인이라는 뜻은 아니다. 대상은 예고 중에도 이동/회피하며 다른 사건과 성장 경로도 달라진다.

M44의 기존 기본 피해/재사용 수치는 바꾸지 않은 상태에서 같은3시드·정상Life·보충 없이900초 관찰했다. [M42](M43-m42-comparison.json), [M43](M43-skill-balance.json), [M44](M44-skill-balance.json), [M44 요약](M44-summary.json). 설정은 M43-experiment-config.json이다. 노랑 E 자기 테두리는 시뮬레이션 시작 뒤 정리한 표시 변경이며 게임 결과를 바꾸지 않는다.
