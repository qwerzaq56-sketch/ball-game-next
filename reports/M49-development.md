# M49 — 모바일 R 조준·해제 시전

R 접근성 안내에는 드래그 후 해제라고 쓰여 있었지만 실제 입력은 누르는 즉시 시전했다. R을 공격/회피처럼 해제 시전으로 맞췄다. 이동을 유지하며 방향을 드래그할 수 있고, 붉은/노랑은 캐릭터를 기준으로 드래그한 지점과 실제 범위의 미리보기를 제공한다. 시전 판정과 같은 범위/토러스 제한 함수로 지점을 계산하고 해제 순간 세계 지점과 방향을 저장한다. 키보드 R은 기존 마우스 방향/지점, E는 기존 탭을 유지한다.

취소·일시정지·회전·창 전환·해제 시 시전 불가에는 쿨다운을 소비하지 않는다. 빙결 중 R 요청은 해제 후 뒤늦게 실행하지 않는다. 미리보기가 피해·시전·RNG를 만들지 않는다. 흰색 화살표의 캐릭터 중심 출발은 유지한다.

전체 **234/234** [테스트](M49-tests.log): 캡처한 방향/지점 유지, 일회 소비, 빙결 요청 폐기, 편집 범위와 세계 경계 제한 및 RNG/개체 비변경 포함. 실제 [다중 터치 R](M49-browser.json), [기존 E/R 슬롯](M49-slots-browser.json), [공격/회피·최소UI](M49-release-mobile-release.json) 모두 통과, 페이지 오류0. [R 조준 화면](M49-R-aim.png). 노랑 장판, 붉은 실제 표식, 초록 탭 소환과 취소/일시정지/회전 무소비를 확인했다. 고정한 조준점은 렌더 이전 위치가 아니라 실제 손가락 해제 이벤트에서 검사했다.
