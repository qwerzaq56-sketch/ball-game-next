# M43 — E/R 관찰·자동 사용·성장 안내

우선순위 계획서의 밸런스 관찰 보완을 구현했다. 자동 탐색은 R이 재사용 중이면 E를 선택하며 한 행동에서는 하나만 요청한다. F1과 JSON/밸런스 페이지에 종족/슬롯/후보/시전자 종류/시전 당시 크기·성향·지역별 시작·완료·취소·직접 명중/실제 잃은HP/HP비율합·모집/소환/강화/표적 수를 기록한다. 취소는 현재 시전과 다른 참조가 되는 순간 한 번만 집계하고 활성 참조를 해제한다. 발사된 파도는 소유자가 죽어도 기존 시전으로 기록한다. 직접 피해만 포함하므로 지원 스킬의 가치를0으로 평가해서는 안 된다.

성장 안내는 일반 E 해금과 현재 최상위 상한을 사용한다. 오래된 ‘상위3위’와 관찰의‘2–3명’ 설명을 현재 규칙에 맞게 수정했다. 스킬 원자료가 없는 이전 파일은 미측정으로 표시하고, 새 파일은 기존 대상/크기/성향/지역 필터를 적용한다. F1 집계는 열었을 때 종족/슬롯 요약만 그려 세부 문맥별 행의 DOM 증가를 피한다.

검증: 전체 **213/213**, 실제 Chromium 라이브 집계·관찰 내보내기·그래프 가져오기·기존 파일 호환·대상 필터 통과, 페이지 오류0. 원자료: [테스트](M43-tests.log), [브라우저](M43-browser.json), [사용 그래프](M43-skill-frequency.png), [직접 피해 그래프](M43-skill-damage.png). 그래프 이미지는 기능 검증용 통제 시나리오이며 일반 플레이 밸런스 표본이 아니다.

`node tools/simulate-balance.mjs 900 reports/M43-skill-balance.json reports/M41-baseline-config.json M43 7,11,23`로 일반 Life·보충 없이3시드 각900초를 관찰했다. 당시 코드는 M43이고 설정은 [동결 설정](M43-experiment-config.json)이다. [전체 원자료](M43-skill-balance.json), [요약](M43-summary.json).

플레이어가 이제 직위 보유 기간에도 E를 실제로 사용한다. 소환 횟수는 연속 수명/재사용을 통틀어 누적된 수이며 동시 개체 수가 아니다. 직접 피해 총량은6152/1664/12650으로 시드에 따라 크게 달랐다. 이것만으로 종족의 강약을 확정하지 않는다. 싸움 횟수·시전자 수·지역 노출·사망과 다중 대상이 섞여 있다. 같은 설정·시드의 이전 M42 코드 비교는 별도 실행하며 결과가 완료되기 전 개선 효과를 확정하지 않는다.

기존 성능 도구6초×3화면에서 update p95는11.3~13.1ms, render p95는2.2~2.5ms였다. [원자료](M43-performance.json). 클라우드 Chromium·정지/HP 보충 성능용 조건이며 실제 휴대폰이나 정상 Life의 생존 측정은 아니다. 병행 CPU 작업의 영향이 있어 작은 시간 차이를 회귀나 개선으로 단정하지 않는다. 실제 iPhone/Safari는 직접 검사하지 않았다.

M43은 관찰을 완성한 단계이며 플레이어 체감의 이상적 수치를 확정하지 않았다. 추가 개발은 스킬 수치를 실제 판정/표시와 연결하고 재현 가능한 설정 저장/복구를 제공하는 순서로 진행한다.
