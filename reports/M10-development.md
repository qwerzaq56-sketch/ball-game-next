# M10: 터치 이동·전투 조작

모바일에서 실제 플레이할 수 있도록 터치 조이스틱·공격 유지·회피·특수능력 버튼을 구현했다.

- 왼쪽 조이스틱은 방향과 기울기에 따라 이동한다. 중심 5px 이내는 정지, 최대 기울기 36px. 대각선/키보드와 함께 입력해도 이동 속도 상한을 넘지 않는다.
- 화면 터치로 조준하며, 조준 터치만으로 공격하지 않는다. 오른쪽 공격 버튼을 유지하면서 이동할 수 있고 별도 손가락으로 회피/E를 누를 수 있다.
- 포인터 취소·손 떼기·창 이탈·숨김·화면 회전·일시정지·리셋 때 입력을 정리한다. 동행 중 공격/E는 막고 회피는 허용한다. 잠긴 능력과 스킬 쿨다운은 버튼에도 반영한다.
- 터치 장치에서만 컨트롤을 표시한다. 가로 화면 HUD를 두 열로 압축하고 정지/안내/이탈 버튼을 우선 배치해 조이스틱을 가리지 않는다. 이름 표시는 터치 컨트롤 영역을 피한다.
- 플레이 안내에 터치 사용법을 추가했다. 게임 전투·점수·직위·동행 확률은 변경하지 않았다.

검증: 단위 테스트 **96/96 통과**. Chromium CDP의 실제 다중 터치 이벤트로 이동+공격, 회피, E 전조/삼중 발사, 조준만 하기, pointercancel, 정지 입력 해제, 화면 회전 입력 해제를 검사했다. 세로 390×844/가로 844×390에서 조작과 버튼 배치를 검증했다. 실제 휴대폰 하드웨어의 프레임 성능은 측정하지 않았다. 기존 데스크톱 이동·TOP10·F1–F4·표시 상태 독립성·설정 저장·리셋·E 발동과 정지/안내 회귀도 통과했다.
