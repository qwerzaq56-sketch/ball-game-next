# NEXT M38 개발·검증 기록

작업 브랜치: `codex/cloud-next-m4`. main·통합 브랜치는 변경하지 않는다.

## 변경

- 대열도 외부 적을 공격·회피하고 특수능력을 사용할 수 있다. 같은 색 피해/동행자의 흡수는 금지한다. 가까운 대열 구성원의 체력과 크기를 합산해 더 강한 적에게 도전하고 리더 3표/일반 구성원 1표로 도전형·기회형·회피형을 정한다. HUD와 인스펙터에 성격/가중치를 표시한다. 관찰용 계산은 상태·난수를 변경하지 않는다.
- 먹이/채집자/포식자 모두 충전·체력이 있으면 비슷한 크기의 적과 싸운다. 큰 위협의 공격 후 빈틈에는 한 번 반격하고 다시 도주한다. AI 행동 간격 2.5→1.8초, 일반 전투 선택 가중치 2배/전쟁 3배.
- 초록 최상위 스킬은 같은 색 대상(플레이어 포함)을 모집한다. 시전자 리더, 최대 6명, 접근을 위한 연결 단절 유예 5초. 수동 조작과 확률 이탈을 유지한다.
- 최상위 포식자 기본 최대 5명, 크기 순/최소 크기/확인 규칙 유지. F1의 Ecology 입력으로 0~50 조절한다.
- 맵 8,000×8,000. 200 단위 시드 지형, 초원 베이스와 다른 5종의 넓은 불규칙 경계, 빈 바이옴 없음. 지형 표시·판정·미니맵·보상·사막 유물 위치가 같은 셀 지도를 따른다. 유물 비활성화가 지형을 제거하지 않는다.
- 설원 눈보라 움직임과 얼음꽃 개화(최대 12개/보상 2배). 화산은 흐르는 용암 강으로 표시하며 실제 강 선분/끝점 거리로 피해를 판정한다.
- 돌진 경로의 캡슐 영역 표시, 모바일 공격 조준 중 미리 표시, 숨은 거리 20% 여유 제거. 몸 접촉을 프레임 사이 경로까지 검사하고 공격 중 몸 외곽과 상대 피격 점멸/입자로 표현한다. 큰 상대 몸 반지름도 후보 검색에 포함한다.
- 웹 최소 UI 버튼과 U 단축키. 모바일/웹 기본값과 저장 키를 구분하고 최소 상태에서 HP/LIFE/Era/일시정지를 유지한다. 입력칸의 U를 게임 단축키로 처리하지 않는다. 모바일 동행 중 빈 화면 공격도 허용한다.
- 기획의 이전 평화 동행/3명 상한/원형 바이옴 규칙을 M38로 대체한다. 동행 선호도 축은 **미구현 제안**으로 별도 기록한다.

## 검증

- `node --test --test-isolation=none`: **175/175 통과**. 대열 투표·근거리 전력·강한 적 도전/회피·동행 회피/동작 유지·먹이 반격 간격·모든 역할 교전·정확한 접촉/통과 방지·경계 돌진·모집/용량/플레이어 조작·실시간 직위 상한·지형 전체 덮음/시드/경계·눈보라 보상·용암 피해와 우회·바이옴 보상 상한을 검증했다. 기존 평화 계약은 최신 요구에 맞게 수정했고 기존 5,000 경계 검사는 명시적인 테스트 월드로 유지한다.
- 실제 Chromium 데스크톱: 버튼/U 토글, 입력칸 보호, F1 입력, 초록 모집과 대열 성격, 6종 지형·용암 강 표시. 페이지 오류0. `M38-browser.json`과 스크린샷 참조.
- 실제 Chromium 터치: 이동과 조준 동시 입력, 공격/회피/빈 화면 공격의 손 뗄 때 실행, 동행 중 화면 드래그 공격, 취소/일시정지/회전에서 오발 방지, 세로/가로 최소 HUD와 선택 저장. 페이지 오류0. `M38-mobile-release.json` 참조.
- 활성 Chromium 데스크톱/디버그/터치 각6초, 각360프레임. render p95 각각1.3/1.3/1.2ms, 페이지 오류0. `M38-performance.json` 참조. 이는 클라우드 Chromium에서 HP/Life를 보충한 성능 측정이며 실기기 Safari FPS·발열 검증이 아니다.
- 3시드(7/11/23) 각각300초,30Hz: 일반 Life·보충 없이 좌표/체력/대열/직위/유물/기록 상한 확인. 최종 원자료 `M38-invariants-300.json` 참조. 장기 생존이나 체감 밸런스의 보장을 의미하지 않는다.
