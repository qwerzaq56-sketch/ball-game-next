# 공 기반 생태계 성장 게임 기획서

문서 버전: 0.25 / 개정일: 2026-10-03 / 상태: 제출된 계획 전체 승인 반영, 기타 미정은 초안 유지

## 1. 기획 목표

먹이 섭취, 동족 흡수, 공격·회피로 성장하는 기존 게임에 지역과 시대, 포식 관계를 추가한다. 플레이어는 작은 개체에서 최상위 포식자로 성장하면서 할 수 있는 행동과 세계에 끼치는 영향이 달라진다.

핵심 경험은 세 가지다.

1. 성장할 때 몸과 행동, 보이는 세계가 함께 달라진다.
2. 위험한 영역에 접근하거나 피하는 선택으로 플레이어가 난이도를 조절한다.
3. AI와 환경의 변화에 대응한 선택이 매번 다른 생존 서사를 만든다.

초기 목표는 원안 시스템의 상호작용을 검증하는 것이다. 발표 자료 마지막 장의 능력 선택·빌드 조합은 관련 확장 후보로 보관하며, 이번 초기 구현에 자동으로 포함하지 않는다.

## 2. 기존 게임의 기준

발표 자료에 따르면 WASD 이동, 좌클릭 공격, Space 회피를 사용한다. 같은 색의 작은 공은 흡수 대상이며, 다른 색의 공은 공격·회피로 싸워 처치 보상을 회수한다. AI끼리도 흡수와 전투를 수행한다.

기존에 보고된 문제는 성장 수치 대비 작은 외형, 먹이 부족과 후반 성장 정체, 넓은 공격 판정과 큰 공의 느린 움직임이다. Claude는 구현 전에 현재 코드에서 해결 여부를 확인한다. 신규 시스템이 이 문제를 악화하는지 함께 관찰한다.

## 3. 핵심 플레이 흐름

탐색 → 먹이 섭취 또는 대상 선택 → 성장 → 행동 해금 → 지역·영역 선택 → 전투 또는 회피 → 보상 회수 → 더 큰 영향력 획득.

초반에는 쉽게 성장하고, 중반에는 색·크기·환경을 읽어 행동을 선택한다. 후반에는 최상위 포식자의 영역과 특수능력으로 주변 개체의 움직임에 영향을 준다. 사망·재시작 규칙은 기존 구현을 조사한 뒤 별도로 명시한다.

## 4. 성장과 카메라

제안 008 사용자 컨펌 완료. 원안은 사용자 직접 제안, 배경 형상·표시와 검증 규칙은 Codex 제안이다.

### 1. 목표와 최소 범위

몸이 커지는 것과 함께 공간을 이해하는 범위도 넓어진다. 작은 때에는 눈앞의 먹이·전투에 집중하고, 성장 후에는 바이옴 경계와 큰 지형의 연결을 보고 이동 방향을 고를 수 있게 한다.

이번은 기존 자동 카메라와 배경 지형의 결합이다. 미니맵·수동 줌·전체 맵 열기·새 능력 해금·별도 성장 레벨은 추가하지 않는다. 카메라가 성장에 따라 넓어져도 AI 감지 거리를 늘리지 않는다.

### 2. 카메라 — 기존 동작을 먼저 활용

현재 구현 기준은 source 4e552a6의 js/game.js updateCamera와 config/gameBalance.json이다. 실제 플레이 체감은 아직 측정하지 않았다.

- 절대 size(지름)를 사용한다. 시작 크기 대비 성장 배수로 줌을 정하지 않는다.
- 기존 식 zoom = 1 / min(2, 1 + size × 0.003)을 초기값으로 유지한다. size 20 약 0.943, 100 약 0.769, 200은 0.625, 약 333.3부터 0.5 상한이다. 큰 개체가 계속 성장해도 시야가 무한히 넓어지지 않는다.
- 기존 시간 기반 부드러운 추적·줌을 유지한다. size 100이나 최상위 획득 순간 별도 급격한 줌 전환은 넣지 않는다. 사망·부활도 현재 크기에 맞춘 목표 배율을 사용한다.
- 화면 크기가 달라도 같은 크기에서 같은 배율을 사용한다. 보이는 월드의 폭·높이는 화면에 따라 달라지므로 모든 기기에서 같은 전체 지형이 보인다고 보장하지 않는다.
- 시야가 맵보다 넓으면 해당 축은 맵 중심으로 고정하고 맵 바깥은 낮은 대비 배경으로 채운다. 경계 밖으로 카메라가 잘못 쏠리지 않아야 한다.

### 3. 거대한 배경 요소

네 바이옴에 각각 대표 배경 형상 하나를 배치한다. 효과 구역과 혼동되지 않는 낮은 대비의 선·면으로 그리며, 이동·충돌·피해·먹이 생성에 영향을 주지 않는다.

| 바이옴 | 배경 형상 제안 | 작은 시야 → 넓어진 시야 |
|---|---|---|
| 바다 | 큰 산호초 능선 | 굽은 능선 일부 → 산호초의 이어진 윤곽 |
| 설원 | 빙하의 균열과 층 | 균열 일부 → 갈라진 빙하의 전체 구조 |
| 숲 | 거대한 나무의 뿌리 무늬 | 뿌리 한 갈래 → 중심에서 뻗은 뿌리망 |
| 화산 | 분화구와 지층 고리 | 고리 일부 → 분화구의 원형 구조 |

전체를 보기 위해 큰 바이옴을 강제로 생성하지 않는다. 기존 생성 결과 중 형상이 들어갈 수 있는 연결 지역을 골라 내부에 배치한다. 형상 폭은 해당 지역에 맞춰 600~900 월드 단위를 초기 목표로 하되, 좁은 지역에서는 줄인다. 같은 종류의 모든 바이옴에 복제하지 않아 탐색의 기준점이 되게 한다.

형상은 고정된 월드 좌표에 붙인다. 화면에 맞춰 크기를 바꾸거나 개체 성장 시 새로 생성하지 않는다. 성장에 따른 카메라 변화로 원래 있던 형태가 자연스럽게 드러나게 한다. 가까이 가지 않은 형상의 위치를 HUD나 화살표로 알려주지는 않는다.

바이옴 경계와 배경 형상을 함께 볼 수 있어야 한다. 다만 배경 고리·균열은 안전/위험 경계로 오인되지 않도록 효과 구역과 다른 표현을 사용한다. 마그마·해류는 기존 정확한 판정 표시를 우선한다.

### 4. 정보 가독성과 설원 예외

공·먹이의 몸체와 충돌 범위는 실제 월드 크기로 표현한다. 작아 보인다는 이유로 몸체만 확대하지 않는다. 공격 전조·환경 경계의 선은 화면 기준 최소 2px를 목표로 유지하되 판정 범위를 바꾸지 않는다. 진영 색·피해 위험·전조가 배경보다 먼저 읽혀야 한다.

눈보라 중에는 승인된 반경 300 가림을 배경 형상에도 적용한다. 카메라는 그대로 넓어지지만 멀리 있는 배경·개체를 볼 수 없다. 눈보라가 끝나면 원래 시야로 돌아온다. 확대 시야를 얻은 뒤 환경으로 일시적으로 잃는 경험을 의도하며, 원거리 위험 표시로 이를 우회하지 않는다.

### 5. 자체평가

- **성장 보상이 충분한가:** 현재 size 20→100의 가시 폭 증가는 약 22.6%다. 첫 최상위에 도달했다고 갑자기 지형 전체가 보이는 효과는 약할 수 있다. 우선 같은 위치·화면에서 size 20/50/100/200/334의 비교 화면을 확인한다. 형태 이해가 거의 달라지지 않으면 형상 크기·구도를 먼저 조정하고, 줌 수치 변경은 별도 수정안으로 제출한다.
- **시점이 적절한가:** 첫 배경 발견, 부분 형태 인식, 전체 형태 인식 때의 시간과 size를 기록한다. size 100 등장 시간·희소성 측정과 연결하되, 랜덤 시작 size가 큰 개체는 처음부터 더 많이 보는 것이 정상이다. 시작 크기별 결과를 분리한다.
- **탐색 판단으로 이어지는가:** 배경과 바이옴 경계를 보고 다음 지역·먹이 경쟁 회피 방향을 선택하는지 실제 플레이로 확인한다. 전체 형태를 봤다는 감상과 실제 경로 선택은 구분한다. 원형 지형이 이동 장애물로 오인되면 표현을 수정한다.
- **넓은 화면만 유리한가:** PC 가로 화면·작은 가로 화면·세로 화면에서 같은 장소와 size를 비교한다. 작은 화면에서 공격 전조가 읽히는지, 배경 구조의 변화가 관찰되는지 확인한다. 조작 방식의 디바이스 호환은 별도 백로그이며 이번에 구현 완료로 표시하지 않는다.
- **너무 많은 정보가 보이는가:** 최저 줌에서 공·먹이·영역·바이옴 경계가 구분되는지 확인한다. 먹이를 찾기 어려워지거나 배경이 전투를 가리면 배경 밀도·대비를 줄인다. 장식 때문에 줌 보상을 제한하지 않는다.
- **큰 바이옴과의 관계:** 현재 크기 상한을 유지한다. 추후 큰 바이옴 예외를 검토할 때, 전체 형태를 파악하는 즐거움과 오래 빠져나오지 못하는 부담을 함께 평가한다. 이 제안의 배경을 넣기 위해 상한을 해제하지 않는다.

### 6. 완료 조건과 제출 결과

네 대표 형상이 월드에 고정되고 이동·충돌·자원 규칙에 영향을 주지 않는다. 같은 초기 맵의 같은 위치에서 크기별 비교 화면, 화면 크기별 비교, 눈보라 전/중/후 비교를 보고서에 포함한다. 원거리 개체나 배경이 눈보라 밖에서 노출되지 않아야 한다.

줌 변화 중 마우스 월드 좌표·공격 방향·카메라 경계 처리와 화면 크기 변경을 확인한다. 배경 켜기/끄기로 렌더링 비용을 비교하고, 실측 기기·개체 수·화면 크기를 기록한다. 기존 줌 수치는 코드 확인값이며 재미·가독성은 미검증 가설이다.


## 5. 최상위 포식자와 영역

### 컨펌된 최소 구현 규칙 — 제안 002-r2

출처: 직위·영역·위험 분포의 원안과 자체평가 관점은 **사용자 직접 제안**. 세부 규칙·수치·성장 기회 기반 접근은 **Codex 제안 · 사용자 컨펌(2026-10-02)**. 이 절은 아래 초기 초안보다 우선한다. 상세 기준은 [승인된 제안 002-r2](../02_기능/01_생태계/06_최소기획_제안_002.md)에 보존한다.

- 크기 단위는 코드의 지름 `size`다. 살아 있는 플레이어·AI의 점수 상위 5마리 중 `size >= 100`만 직위를 부여한다. 미달 개체를 건너뛰어 6위 이하를 승격하지 않는다.
- 모든 개체 점수는 생성 시 0이다. 기존 플레이어 점수식을 공통 적용한다. 먹이는 `round(growthValue)`, 동족 흡수는 `round(흡수 growth)`, AI 전투 처치는 `round(직접 성장 보상) + 100`이다. 보상 먹이 수거 점수도 별도 획득한다. 현재 플레이어 처치 보상 예외는 유지하고, HUD·로컬 Top 10은 플레이어 점수에 연결해 이중 가산을 방지한다.
- 2초마다 평가하고 자격 변경 후보가 두 번 연속 유지되면 변경한다. 최초 배정은 즉시, 사망·플레이어 패배 시 직위와 영역은 즉시 해제한다. 플레이어 Life 부활은 기존 점수·크기를 유지하되 직위 재획득에 두 번 연속 평가를 요구한다. AI 신규 생성 및 전체 초기화 시 점수는 0이다. 동률은 이전 순서, 신규 동률은 ID 순으로 처리한다.
- 영역은 소유자를 따라가는 **고정 반경 600**의 원이다. 겹침을 허용하고 중복 유인은 없다. 맵 경계를 잘라 표시한다. 얇은 진영색 경계·옅은 내부·직위 아이콘을 표시하며 진입 HUD는 가장 가까운 소유자를 안내한다. 통과 제한·피해·점령 효과는 없다.
- 전역 집결과 일반 영역 직접 유인은 사용하지 않는다. 제안 004에서 승인한 종속·도전형의 거리 600 이내 동행·관찰은 예외로 추가한다. 국소 먹이 접근은 유지하며 세부 규칙은 7절을 따른다.
- `size >= 70` 프레데터가 체력 50% 초과이고 추격·회피·흡수 중이 아닐 때, 기존 감지 안에서 자신이 먹을 수 있는 먹이를 중심 거리 120 이내 묶음으로 평가한다. growthValue 합 80 이상 묶음이 있으면 기존 배회보다 우선하고 가까운 묶음을 선택한다. 실제 목표는 그 묶음의 가장 가까운 먹이 한 개다. 판단 주기마다 재평가하며 먹이 소멸·섭취 불가·범위 이탈 시 해제한다. 기존 생존·전투 우선순위를 유지한다. 집계는 현재 공간 검색을 재사용하고 비용을 측정한다.
- 기대 서사는 교전 → 보상 먹이 → 수확 기회 접근 → 경쟁이다. 교전 빈도 자체를 이번에 추가로 높이지 않는다. 특수능력과 기존 공격 거리 감소는 6절의 제안 007-r2로 승인됐다. 구현·검증 전에는 전체 기능을 완료 처리하지 않는다.
- 초기 등장 목표는 **게임 시간 3~6분에 첫 등장, 초기 1~2마리**다. 이는 합의된 검증 목표이며 실측 사실이 아니다. 고정 등장 금지 시간이나 인위적 개수 제한은 추가하지 않는다.
- 자체평가에서 최초 size 100 도달·직위 획득·플레이어 조우 시간을 분리하고 성장/생성 원인을 기록한다. 1·3·5·10분의 크기 조건 충족 수·직위 수·비율·교체 시간을 기록한다. 시드 10개 × 10분과 실제 플레이 최소 3회 관찰을 초기 실험으로 제안하며 미수행·조기 종료를 명시한다. 현재 시드 제어가 없으므로 재현 자동 비교 전 난수와 시간 제어를 추가한다.
- 완료 검증은 점수 가산·size 99/100 경계·순위·사망/부활·겹침/경계·먹이 동기·기존 전투 유지다. 분포는 R=600의 안쪽/바깥쪽 평균 크기를 비교한다. 유효 표본이 있는 3개 시드 중 2개 이상에서 안쪽 평균 크기가 높아야 한다. 성장 기회 기반 접근으로 이 분포가 나타나지 않으면 후속 수정안을 제출한다. 영역 밖의 성장 경로와 작은 개체의 생존도 함께 검토한다.

### 원안과 초기 초안 — 위 컨펌 규칙에 따라 대체·보완

**원안:** 점수 상위 5마리 중 일정 크기 이상인 개체에 직위를 부여한다. 주변 영역을 시각화하고, 근처에는 큰 적이, 멀리에는 작은 적이 분포하도록 조율한다. 기존 공격 이동거리는 줄이고 색별 특수능력을 부여한다.

**초안 제안 규칙**

- 순위는 살아 있는 플레이어와 AI를 포함해 계산한다. 상위 5위라도 최소 크기 미달이면 직위를 부여하지 않아 최상위 포식자가 5마리보다 적을 수 있다.
- 순위 평가 간격과 직위 유지 유예를 설정값으로 두어 경계 순위에서 영역이 반복 점멸하지 않게 한다. 사망하면 즉시 해제한다.
- 영역은 소유자의 현재 위치를 따라가며, 겹친 영역은 허용한다. 초기에는 고정 영토나 점령 시스템을 추가하지 않는다.
- 큰 개체의 자연스러운 이동과 생성 가중치로 위험 분포를 유도한다. 기존 개체를 순위 변화 때 강제 이동시키지 않는다.
- 작은 개체가 이동할 수 있는 영역 밖의 공간을 남긴다. 어디서든 큰 적에 둘러싸이는 상황은 실패 사례로 기록한다.
- 직위·영역·특수능력 상태는 플레이어에게도 동일하게 적용한다.

점수와 크기의 관계, 최소 크기, 영역 반경, 평가 간격, 유예 시간, 공격 이동거리 감소량은 미정이다. 초기 설정을 Claude가 제안하되 근거와 플레이 결과를 기록한다.

## 6. 최상위 능력 — 제안 007-r2 승인

2026-10-02 사용자 컨펌 완료. 능력은 **발동형(직접 피해·상태·버프·장판)**과 **행동 강제형(AI 목표 명령)**으로 분리한다. 색별 한 번의 시전에서 해당 효과와 명령이 함께 발생한다. 기본 공격 거리 제약도 함께 적용한다.

출처: 색별 원안·모래바람·하위 개체 행동 강제·파랑 동족 포식·초록 수확 구분은 **사용자 직접 제안**. 수치·판정·명령 예외는 **Codex 제안 · 사용자 컨펌**이다. 상세 승인 이력은 [제안 007-r2](../02_기능/02_종족_능력/13_최소기획_제안_007_최상위_능력.md)에 보존한다. 초기값은 검증용이며 코드 구현·실측 완료를 뜻하지 않는다.

빨강은 이번 승인 범위에서 전투 집결 명령만 제공하며 별도의 직접 발동 효과를 임의로 추가하지 않는다. 아래 명령·버프·상태 조건은 일반 성격 선택과 기존 공격 조건의 명시적 예외다.

### 1. 공통 규칙

- 최상위 직위 보유자만 자기 색 능력 하나를 사용한다. 플레이어는 E, 방향은 마우스 조준을 사용한다. AI는 같은 판정·전조·효과·쿨다운을 사용한다. 일반 공격·회피 입력은 유지한다.
- 특수능력은 별도 재사용 대기시간이며 일반 공격 스택을 소비하지 않는다. 공격·회피 진행 중, 동결 중에는 새 능력을 시작하지 못한다.
- 직위 획득 시 재사용 대기 5초 후 최초 사용 가능. 직위 상실·사망 즉시 새 사용 금지·본인 전조 취소·본인 유지 장판/명령/버프 종료. 남은 쿨다운은 생존 중 유지하며 재획득 시 `max(남은 쿨다운, 5초)`로 재설정해 반복 승격으로 초기화하지 않는다.
- 전조 중 정상 이동은 허용하되 새 일반 공격은 금지한다. 회피 입력은 전조를 취소한다. 특수 쿨다운은 전조 시작 시 소비하며 취소돼도 환불하지 않는다. 피해만으로 전조를 취소하지 않되 사망·직위 상실·동결은 취소한다.
- 판정 크기는 월드 단위다. 원·부채꼴 범위는 개체 중심 기준이며 발동 시 범위 이탈은 빗나갈 수 있다. 전조와 실제 판정 형태를 일치시킨다.
- 피해는 해당 능력 계수 × 기존 일반 공격의 원시 피해를 계산한 뒤 기존 방어·최소 피해 보정을 적용한다. 적의 회피 무적 중에는 적 피해·동결·밀침을 적용하지 않는다. 같은 색과 먹이 orb는 적 피해 대상이 아니다.
- 명령 대상은 범위 내 **같은 색의 작은 AI, 최상위 직위 없음**이다. 플레이어 이동·공격은 명령으로 강제하지 않는다. 아래 초록 버프 자체는 같은 색 플레이어도 받을 수 있다. 명령은 포레이저·프레데터 관계 행동 등보다 우선하지만 환경 위험·흡수 탈출·회복·피격 회피는 우선 유지한다.
- 중첩 명령은 먼저 받은 명령을 유지한다. 갱신으로 무한 연장하지 않는다. 종료 후 3초 동안 새 명령을 받지 않는다. 명령 중 자기 성격·관계는 저장 상태를 유지하며 끝나면 정상 판단으로 복귀한다.

### 2. 기본 공격 거리 제약

최상위의 **돌진 이동거리만 기존의 70%**로 줄인다. 이동 시간은 기존 값 그대로라 실제 돌진 속도도 70%가 된다. 피해·스택·회복·공격 전조 시간·회피 거리는 유지한다.

현재 코드의 `attackRange`는 돌진 거리와 추가 타격 폭·AI 공격 판단에 함께 쓰인다. 이를 분리해 이동거리만 줄이며 타격 폭까지 우연히 축소하지 않는다. AI의 접근·공격 시작 판단은 감소한 돌진 도달거리로 조정한다. 전조 역시 실제 이동거리를 보여준다.

size 100에서는 기존 돌진 약 314가 약 220이 된다. 먼 거리 추격력은 줄고 주변 영향력은 늘리는 목적이다. 직위 상실하면 다음 일반 공격부터 기존 거리로 복귀한다. 이미 시작한 일반 공격은 시작 때 상태를 고정해 중간에 이동거리가 바뀌지 않는다.

### 3. 능력 유형 구분

- **발동형:** 직접 피해·상태·버프·장판을 발생시키는 효과. AI의 목표 선택을 명령으로 바꾸지는 않는다. 동결·밀침은 이 분류의 상태·물리 효과다.
- **행동 강제형:** 하위 AI에게 포식·수확·전투 목표를 지시해 잠시 기존 행동 선택을 덮어쓰는 효과.

분류와 판정은 따로 관리한다. 현재 제안에서는 색별 E 시전 한 번으로 해당 발동형과 행동 강제형을 함께 발생시키고 전조·쿨다운은 공유한다. 별도 버튼·별도 쿨다운 능력 두 개로 나누는 변경은 이번에 추가하지 않는다.

| 색 | 발동형 | 행동 강제형 |
|---|---|---|
| 하늘색 | 냉기 휘두르기 | 없음 |
| 파랑 | 파도 | 동족 포식 지시 |

직접 피해·상태로 인해 AI가 도망치는 일반 대응은 행동 강제 명령으로 분류하지 않는다. 빨강의 집결 신호·대상 표시는 명령 전조이지 별도 피해 능력이 아니다.

### 4. 발동형

| 색 | 효과 | 초기 범위·효과 |
|---|---|---|
| 하늘색 | 냉기 휘두르기 | 반경 260·각도 120° 부채꼴, 피해 0.5배·동결 1초 |
| 파랑 | 파도 | 길이 400·폭 180, 피해 0.5배·전방 밀침 120 |
| 초록 | 사기 진작 | 반경 350 동색·본인, 5초 공격 원시 피해 +15% |
| 빨강 | 없음 | 전투 집결만 제안된 상태 |
| 노랑 | 모래바람 | 반경 220·5초, 초당 0.3배 피해·본인 장판 안 25% Miss |

#### 하늘색 — 냉기 휘두르기

휘두르는 호형 효과가 발동 때 한 번 판정한다. 동결 중 정상 이동·새 공격·회피·특수 시전을 금지하며 현재 공격/회피는 중단한다. 무적 중 적중은 동결시키지 않는다. 진행 중 흡수 연결도 해제한다.

동결 종료 후 2초 동안 동결 면역을 준다. 동결은 성장값·쿨다운·명령 시간을 멈추지 않는다. 동결 자체는 별도 AI 성격 변경이 아니다. 피해·넉백 등 다른 기존 물리 이동은 허용하며 맵 경계 처리를 따른다.

#### 파랑 — 파도

파도는 지정 방향으로 0.5초 동안 진행하며 개체당 한 번만 맞는다. 적은 전방으로 총 120을 0.2초에 걸쳐 밀리며 경계에서 제한한다. 직전 파도 강제 이동 종료 후 1초 동안 같은 파도 밀침에 면역이다. 피해와 이동 판정은 분리한다.

#### 초록 — 사기 진작 버프

범위 안의 동색 플레이어·AI와 시전자에게 5초 버프를 적용한다. 버프는 공격을 실제로 할 때 피해에만 적용하며 공격 해금·스택·체력·성격을 바꾸지 않는다. 같은 버프는 중첩하지 않고 남은 시간이 더 긴 것을 유지한다. 효과가 적용될 때 시전자와 연결해 직위 상실·사망 시 해당 버프를 종료한다.

#### 노랑 — 모래바람

시전자 중심에서 350 이내 조준 지점에 장판을 둔다. 지점은 맵 안으로 제한하며 설치 뒤 따라 움직이지 않는다. 0.5초마다 현재 안에 있는 다른 색에게 원시 피해 0.15배를 적용해 초당 0.3배로 만든다. 이산 피해마다 방어·최소 피해를 적용한다. 같은 시전자의 장판은 하나이며 같은 종류의 장판이 겹치면 대상당 그 틱의 가장 큰 원시 피해 하나만 적용한다.

시전자 본인이 장판 안에 있을 때 적의 일반 공격 또는 직접 적중형 특수능력 피해마다 한 번 25% 확률로 Miss 처리한다. Miss이면 그 타격의 피해·동결·밀침·흡수 취소를 모두 막고 MISS를 표시한다. 이미 회피 무적이면 난수를 소비하지 않는다. 모래바람 지속 피해와 환경 피해·동족 흡수에는 Miss가 없다. 다른 동색에게 Miss 보호를 주지 않는다.

장판 위험은 AI가 읽을 수 있게 하고 해당 지역 안에서 피해를 입으면 빠져나오는 환경 위험 대응을 우선한다. 위험 장판 때문에 추격·집결이 중단될 수 있다.

### 5. 행동 강제형

| 색 | 명령 | 대상·기간 | 핵심 판정 |
|---|---|---|---|
| 파랑 | 동족 포식 | 반경 350 작은 동색 AI 최대 4마리·4초 | 자신보다 작은 동족. 후보 size 70 미만 80%, 이상 20% 수락 |
| 초록 | 먹이 수확 | 반경 350 작은 동색 AI 최대 4마리·5초 | 현재 감지 안의 먹을 수 있는 orb 우선 |
| 빨강 | 전투 집결 | 반경 450 작은 동색 AI 최대 4마리·4초 | 500 이내 지정 적, 명령 AI 공격 가능·상대 size 최대 1.5배 |

하늘색·노랑은 별도 행동 명령이 없다. 공통 명령 대상·생존 해제·중첩 방지·3초 재수락 제한은 1절을 따른다. 플레이어는 자동 명령을 받지 않는다.

#### 파랑 — 동족 포식 지시

발동 순간 반경 350 안의 작은 동색 AI 최대 4마리(가까운 순)에 **4초 동족 포식 지시**를 준다. 시전자 자신이 즉시 흡수하는 기술이 아니라 명령받은 AI가 자기보다 작은 동족에게 접근·흡수를 시도하는 기술이다.

- 후보는 명령받은 AI의 기존 흡수 감지 400 안에서 실제로 흡수 가능한 작은 동색 개체다. 시전자와 최상위 직위 보유자는 제외한다. 플레이어는 자동 명령을 받지 않지만 기존 동족 흡수의 피해 대상이 될 수 있다.
- 후보 size가 **70 미만이면 80%, 70 이상이면 20%** 확률로 이번 명령의 포식 대상으로 수락한다. 70은 기존 회피 2스택 단계와 맞춘 절대 크기 기준이며, 명령받은 AI보다 작은 조건을 먼저 만족해야 한다.

## 7. 역할·공통 성격·프레데터 관계

2026-10-02 사용자 승인에 따라 분류를 통합했다. **역할은 성장하며 바뀌고, 성격은 유지되며, 프레데터 관계 유형은 별도로 작동한다.** 이 절이 과거 제안 001·004·005의 분류와 상충하면 이 절을 우선한다. 변경하지 않은 전투·점수·직위 규칙은 유지한다.

### 7.1 세 가지 분류

| 분류 | 답하는 질문 | 구성 |
|---|---|---|
| 역할 | 생태계에서 어느 위치인가? | 프레이·포레이저·프레데터 |
| 공통 성격 | 기회와 위협에 어떻게 반응하는가? | 성장 추구형·리스크 회피형·기회주의형 |

최상위 포식자는 별도 직위다. 종족은 색상별 특성으로 이 분류와 별개다. 포레이저의 채집·사냥·탐색은 고정 유형이 아니라 상황별 행동으로 통합한다. 기존 방랑자·보수형·균형형·공격형은 별도 성격으로 중복 구현하지 않는다. 원안은 로그와 최초 원안에 보존한다.

### 7.2 역할과 배정

- 살아 있는 플레이어·AI를 실제 size 내림차순으로 정렬한다. 상위 floor(N × 0.2)는 프레데터, 하위 floor(N × 0.4)는 프레이, 나머지는 포레이저다. N < 5면 모두 포레이저다.
- 최초 역할은 즉시 배정한다. 이후 2초마다 평가하고 새 후보가 두 번 연속 유지되면 전환한다. 동률은 이전 순서, 신규 동률은 ID 순이다.
- AI 생성 시 공통 성격 하나를 배정한다. 초기 확률은 기존 프레이 설정을 공통화한 성장 추구형 34%·리스크 회피형 33%·기회주의형 33%다. 역할 변화로 재추첨하지 않고 사망 후 신규 개체만 새로 배정한다.
- 프레데터 관계 유형은 처음 프레데터 진입 때 종속형 40%·도전형 30%·독립형 30%로 배정한다. 역할 이탈 시 중단하고 재진입 시 유지한다.
- 성격은 최상위 승격 후에도 저장·유지한다. 관계 유형의 동행·관찰은 승격 중 중단한다. 직위를 잃고 프레데터이면 관계 행동을 재사용한다.
- 플레이어는 역할·직위를 표시하지만 성격이나 관계로 자동 조작하지 않는다. AI 분류는 디버그에서 확인한다. 생성 확률과 생존 개체 비율을 혼동하지 않는다.

### 7.4 공통 판단과 유지하는 초기값

- 환경 위험·흡수당할 때 도주·피격 회피를 최우선 처리한다. 체력 30% 이하에서 새 교전·위험 감수를 중단하고 회복하며 60% 이상이면 정상 선택으로 복귀한다. 이미 시작된 공격·회피는 기존 상태 흐름을 따른다.
- 일반 감지 320·동족 흡수 탐색 400, 기존 판단 주기·스택·해금·색상 관계를 유지한다. 감지되지 않은 세계 정보를 사용하지 않는다.
- 위협은 일반 감지 안에서 자기 size 1.2배 이상인 다른 색이다. 안전한 성장 대상은 감지된 위협과 중심 거리 160 이상 떨어져 있어야 한다. 실제 흡수 연결은 같은 색이어도 도주 대상이다.
- 안전 대상이나 유리한 사냥이 없으면 기존 배회로 새 기회를 찾는다. 포레이저 탐색형만의 100% 배회 속도 예외는 폐기하고 기존 배회 속도를 공통 적용한다.
- 먹이 군집은 중심 거리 120 이내의 먹을 수 있는 orb 성장값 합으로 평가한다. 합 80 이상을 풍부한 기회로 본다. 실제 목표는 가까운 먹이 한 개이며 매 판단 때 재평가한다. 회복 중에도 안전한 먹이는 섭취할 수 있다.
- 프레이 성장 추구형은 자기 체력 60% 이상일 때 풍부한 먹이 접근을 위해 일괄 도주를 제한적으로 무시할 수 있다. 위협이 160 이내이거나 자기 size 1.5배 초과이면 도주가 우선한다. 가치 80 미만 또는 자기 체력 50% 이하이면 위험 감수를 중단한다.
- 리스크 회피형의 능동 동족 흡수 대상은 프레이에서 자기 size 0.7배 이하, 포레이저·프레데터에서 0.8배 이하이며 안전한 위치여야 한다. 그 외 성격의 흡수는 기존 규칙을 사용한다. 이 선택 조건은 중앙 흡수 가능 판정이나 우연한 근접 흡수를 금지하지 않는다.
- 일반 사냥은 포레이저 성장 추구형에서 공격 가능·체력 60% 이상, 상대 size 0.8배 이하를 조건으로 한다. 프레데터는 상대 size 0.8배 이하 조건을 유지한다. 리스크 회피형은 대상 위치가 안전할 때만 사냥하고 기회주의형은 아래 막타·보상 기회를 일반 사냥보다 우선한다. 프레이의 일반 능동 사냥은 금지한다(피격 후 반격은 아래 일반 반격 규칙의 예외).
- **일반 반격(v0.25, 2026-10-03 사용자 직접 지시):** 어떤 역할·색의 AI든 다른 색 개체(AI·플레이어)에게 피해를 받으면 공격자를 3초 기억한다. 환경 장판 틱 피해는 기억하지 않는다. 위의 생존 규칙(위험·흡수 탈출·회복·위협 도주) 뒤에서, 공격 가능(스택 있음)·체력 30% 초과·공격자가 위협(자기 size 1.2배 이상)이 아님·공격자가 일반 감지 320 이내이면 공격자에게 반격한다. 리스크 회피형은 공격자 위치가 다른 위협으로부터 안전해야 한다. 공격자 사망·감지 이탈·3초 경과 때 해제한다. 일반 사냥 후보·해금·프레이 능동 사냥 금지·파랑 회피 후 반격은 바꾸지 않으며, 일반 반격은 일반 사냥의 size 0.8배 제한의 예외다. 출처: 공개본 v0.6의 피격 반격을 복원한 것이며 범위·기억 시간은 Codex 정리(수치는 조정 가능). 검증: 피격 후 반격 비율, 반격 후 도주 복귀·왔다갔다 횟수(상태변경/10초), 프레이 자살 반복 여부.
- 기회주의형 막타는 공격 가능, 자기 체력 60% 이상, 상대 size 최대 1.2배, 상대 공격 후딜 중·현재 공격 범위 안·무적 아님을 모두 만족할 때 한 번 시도한다. 상대 HP가 현재 공격 피해의 방어·최소 피해 보정 결과 이하여야 한다. 후보 탐색을 위한 범위 밖 추격은 없다. 자기 체력 50% 이하 또는 가까운 큰 위협이 있으면 개입하지 않고 철수·회복한다. 명중·처치는 보장하지 않는다.
- 최상위 직위 보유자도 공통 생존·성격 판단을 사용한다. 특수능력은 6절을 따른다. 직위 획득으로 성격을 재배정하지 않는다.

### 7.5 프레데터 관계 유형

관계 유형은 **누구 주변에 머물 것인가**, 성격은 **거기서 기회·위협에 어떻게 반응하는가**를 결정한다. 생존·실제 성장/전투 기회가 관계 이동보다 우선한다. 도전 기회 공격만 일반 사냥 크기 조건의 명시적 예외다.

- 종속형: 거리 600 안의 같은 색 최상위를 발견하면 중심 거리 450~600을 유지하며 느슨하게 따라간다. 동족 흡수 규칙은 유지한다. 상대 흡수 유지거리 +80보다 가까우면 물러나고 필요한 안전거리가 600 초과이면 동행을 포기한다.
- 도전형: 거리 600 안의 다른 색 최상위 주변 450~600에서 탐색한다. 자기 체력 60% 이상·상대 30% 이하·상대 size 최대 1.5배에서 도전할 수 있다. 상대 체력 40% 초과 또는 자기 40% 이하이면 도전 추격을 해제한다. 리스크 회피형은 대상 위치의 안전 조건도 요구하고, 기회주의형은 도전 대상의 후딜 또는 국소 막타 기회를 기다린다. 성장 추구형은 기본 도전 조건 충족 시 시도한다.
- 독립형: 이전 이름 배회형을 대체한다. 최상위를 목적지로 삼지 않되 먹이·사냥·성격 행동은 사용한다. 단순히 항상 돌아다니는 유형이 아니다.
- 적격한 가장 가까운 최상위를 선택하며 대상 사망·직위 상실·600 밖 이탈 시 해제한다. 일반 전투 감지 320을 확대하지 않는다. 관계 구간에서는 기존 배회 속도를 쓰고, 경계에서 유지 가능한 지점이 없으면 관계 행동을 해제한다. 강제 순간이동·전역 추적은 없다.

예: 리스크 회피형 도전자는 약해진 상대라도 위험한 위치면 개입하지 않는다. 성장 추구형 종속자는 동색 강자를 따르다가 보상 군집을 발견하면 수확을 우선한다. 기회주의형 독립자는 특정 강자를 따르지 않아도 근처의 취약한 상대에 개입한다.

### 7.6 종족별 행동 특성 — 제안 006 승인

출처: 종족별 행동 방향과 하늘색 이동 감소는 **사용자 직접 제안**, 세부 적용·수치·보라색 교체는 **Codex 제안 · 사용자 컨펌(2026-10-02)**. 종족은 역할·공통 성격·관계의 허용 범위 안에서 선택 경향을 조절한다. 생존 판단과 성격의 고정 우선순위를 무시하지 않는다.

이번에는 종족별 공격력·HP·moveSpeed 스탯 차이를 추가하지 않는다. 하늘색의 무목표 배회 계수만 명시적으로 변경한다. 플레이어에게 종족 AI의 자동 행동을 적용하지 않는다. 특수능력은 6절의 승인 규칙을 따른다.

#### 승인된 5종족 구성

현재 보라색을 **하늘색으로 교체하고 총 5종족을 유지**한다. 기존 blue는 파란색, 새 cyan은 하늘색으로 구분한다. 설정·표시·선택·동족 판정·효과의 색 정의를 함께 맞춘다. 구현 시 데이터에 purple이 저장되는지 조사해 필요하면 호환 처리한다. 냉기 등 특수능력은 다음 별도 기획이다.

| 종족 | 최소 행동 특성 | 초기값 |
|---|---|---|
| 초록 | 동족을 먹기보다 공존하는 경향 | AI의 동족 흡수 시작 수락률 50% |
| 빨강 | 유효한 전투 기회를 더 자주 선택 | 경쟁하는 일반 사냥 선택 가중치 ×1.5 |
| 파랑 | 회피 후 유리한 상대에게 반격 | 회피 종료 후 1초 반격 기회 |
| 노랑 | 기회가 없는 장소에서 이동 방향을 오래 유지 | 무목표 탐색 방향 유지 4~6초 |
| 하늘색 | 좁은 범위에서 기회를 오래 활용하는 정착 경향 | 무목표 배회 속도만 기존의 ×0.7 |

#### 최소 적용 규칙

##### 초록 — 동족 흡수 시작을 실제로 줄임

현 코드는 AI 목표 선택과 별개로 중앙 소비 처리에서도 동족 흡수를 시작한다. 추격 확률만 낮추면 실제 흡수가 줄지 않을 수 있으므로 **시작 판정까지 연결**한다.

- 초록 AI가 동족과 흡수 가능한 크기·거리 관계에 새로 들어올 때 그 상대에 대해 한 번만 50% 확률로 수락한다. 거절하면 같은 만남에서 재추첨·추격·흡수 시작을 하지 않는다.
- 상대가 흡수 유지거리 밖으로 나가면 해당 만남 판정을 해제한다. 상대 사망 또는 크기 관계 역전도 해제한다. 관계가 새로 성립하면 재판정한다.
- 수락했어도 성격·생존·크기·거리 조건을 만족해야 시작한다. 수락은 목표 강제 선택이 아니다. 이미 시작한 흡수의 속도·저항·탈출 규칙은 바꾸지 않는다.
- 이 규칙은 초록 AI가 흡수하는 쪽일 때만 적용한다. 초록이 다른 동족에게 흡수되지 않는 보호 효과는 아니다. 플레이어는 기존 동족 흡수 토글로 직접 선택한다.

이는 기존 ‘중앙 흡수 판정은 유지’에 **초록 AI의 시작 의사 조건**을 추가하는 명시적 변경안이다. 50%는 최종 흡수 횟수가 절반이라는 보장이 아니다.

##### 빨강 — 허용된 선택 안에서 공격적

먹이·동족 흡수·다른 색 일반 사냥 중 선택 가능한 후보가 동시에 있으면, 기본 가중치를 각각 1로 두고 일반 사냥만 1.5로 정규화해 선택한다. 후보 종류별 하나의 유효 행동을 비교한다. 같은 색별 비교 기준은 이 선택 가중치를 1.0으로 둔다.

성격의 고정 우선순위·생존 조건·막타·도전 등 특별 기회는 이 추첨보다 먼저 적용한다. 성격이 일반 사냥을 허용하지 않으면 사냥 후보 자체가 없다. 따라서 무조건 공격하거나 프레이에게 능동 사냥을 해금하지 않는다. 사냥만 있는 상황은 종족 때문에 달라지지 않는다.

##### 파랑 — 회피 후 반격 기회

공격 전조를 보고 회피한 경우 그 공격자를 기억한다. 회피가 끝난 뒤 최대 1초 동안 공격자가 현재 감지·공격 범위 안에 있고 현재 역할·성격이 공격을 허용하면 다른 일반 기회보다 반격을 우선한다. 공격 스택이 없거나 체력·위협 조건상 불리하면 반격하지 않는다.

공격자 사망·감지 범위 이탈, 기억 만료 시 해제한다. 막타·도전·일반 반격의 예외 조건을 만족하지 않는 프레이에게 추격을 추가하지 않는다. 플레이어에게 자동 회피·반격 입력을 만들지 않는다.

##### 노랑 — 유형 추가 없이 탐색 경향 강화

목표 없는 탐색 때만 기존 1~3초 방향 전환 대신 4~6초 동안 방향을 유지한다. 이동속도는 기존 배회 속도를 유지한다. 먹이·상대·위협을 발견하면 즉시 일반 판단을 한다. 관계 동행·관찰·추격에서는 이 시간을 적용하지 않는다. 맵 경계에 닿으면 기다리지 않고 방향을 다시 선정한다.

##### 하늘색 — 정착 경향

- 무목표 배회 속도만 기존 배회 속도의 70%로 낮춘다. 현재 코드의 기존 배회 계수 0.55에 곱하므로 실제 속도는 moveSpeed ×0.55×0.7이다. moveSpeed 자체를 변경하거나 70%를 정상 이동속도 기준으로 해석하지 않는다.
- 현재 역할·성격이 허용한 먹이 후보 안에서는 가까운 먹이를 먼저 수확한다. 먹이 군집·막타·도전·생존의 기존 우선순위를 낮추지는 않는다.
- 먹이 추적·사냥·동족 흡수 추격·도주·회피·공격 돌진·프레데터 관계 이동에는 0.7을 적용하지 않는다. 피격 대응도 유지한다.
- 주변 먹이가 없어지면 느린 배회라도 계속 다른 장소를 탐색한다. 같은 지점에서 정지하거나 자원 재생을 기다리는 상태는 추가하지 않는다. 맵 경계에서는 기존 방향 재선정을 따른다.
- 설원의 이미지에 맞춘 종족 특성으로 모든 지역에서 적용한다. 설원에만 적용되는 환경 효과와는 별개다. 냉기 특수능력은 6절을 따르며 파랑과 구분되는 색상·이름을 표시한다.

상세 검증은 [승인된 제안 006](../02_기능/02_종족_능력/12_최소기획_제안_006_종족별_특성.md)을 따른다. 초록 만남 판정·중앙 흡수 시작, 빨강 유효 후보 정규화·공격 금지 유지, 파랑 기억·회피 종료·만료, 노랑 경계·기회 발견, 하늘색 무목표 배회 0.385와 도주·사냥 속도 유지, 색상 교체 판정을 통제 검증한다. 종족별 생존·성장·교전·흡수·반격·이동·먹이 발견·최상위 도달을 역할·성격·초기 size·생존시간과 함께 비교한다. 초기값은 검증용이며 실제 균형은 미측정이다.

### 7.7 AI 조합 검증

공통 성격 확률 34/33/33을 종족별로 동일하게 유지해 초기 종족 효과를 분리한다. 별도 방랑자 성격은 추가하지 않는다. 역할 변화에도 성격이 유지되는지, 관계가 적격 역할·직위에서만 작동하는지 확인한다. 역할×성격과 프레데터 성격×관계의 통제 시나리오를 수행한다. 공통 판단과 조건을 재사용하며 조합마다 별도 상태기계를 추가하지 않는다.

기존 먹이·체력·크기·거리·공격 후딜·무적·피해 경계 검증도 유지한다. 생존·성장·섭취·막타·동행·도전·철수, 첫 최상위 등장과 직위 교체·영역 분포를 비교한다. 행동 차이가 이름만 남거나 특정 조합이 반복 자살·정체하면 수정안을 제출한다.
## 8. 지역과 환경 이벤트

제안 003-r2 사용자 컨펌 완료. 지역 전용 조우는 제안 009-r1로 승인됐다. 아래 4종 배치는 초기 구현 단계이며, 제안 013의 6종 확장에서는 면적·분산 조건을 해당 승인 규칙으로 대체한다.

### 목적과 범위

지역마다 이동·정보·먹이 경쟁·체류 위험 중 하나의 판단을 바꾼다. 종족 특성은 모든 지역에서 유지하며 같은 색 지역에 들어갔다고 추가 면역이나 강화는 주지 않는다. 이번 범위는 지형 배경, 환경 효과, AI 대응, 측정이다. 장애물·경로 탐색, Era, 파멸 이벤트, 지역 전용 오브젝트는 다음 단계다.

### 배치와 공통 규칙

5000 × 5000 맵에 네 종류 바이옴을 여러 개의 불규칙한 덩어리로 섞어 배치한다. 숲·설원·바다·화산은 각각 여러 장소에 반복해서 나타난다. 바다는 건널 수 있는 환경이며 벽이나 막다른 길이 아니다. 부활점 (2500,2500) 중심 반경 400은 환경 효과가 없는 시작 구역으로 유지한다. 전투·흡수는 그대로 가능하다.

배치의 핵심은 **진입 후 되돌아가지 않아도 계속 진행하면 다른 바이옴이 나오는 것**이다. 경계는 직선 격자 대신 굴곡을 주되 이동을 막지 않는다. 최소 생성안은 분산된 점 주변으로 불규칙 영역을 만들고 인접 영역에 바이옴을 배정하는 방식이다. 노이즈만 적용해 거대한 같은 종류 지역이 우연히 이어지게 두지 않는다.

초기 생성 조건은 다음과 같다. 아래 크기는 절대 월드 단위이며 개체의 시작 크기와 무관하다.

- 개별 바이옴의 대표 폭은 600~1000을 목표로 한다. 같은 종류가 붙으면 하나의 연결 지역으로 평가하며, 그 지역의 최대 두 점 거리는 1400 이하로 제한한다. 이 조건을 넘으면 다른 바이옴으로 분할하거나 재배정한다.
- 같은 종류가 맵의 한쪽부터 반대쪽까지 이어지는 띠를 만들지 않는다. 각 종류의 총 면적은 전체의 20~30%를 목표로 하고, 각 종류가 최소 4개 독립된 지역으로 분산되게 한다.
- 맵 내부에서 어느 방향으로 직진해도 같은 연결 바이옴 안에 연속 1400을 넘게 머물지 않도록 검증한다. 맵 바깥 방향은 유한 맵 경계 때문에 제외하고, 가장자리에서는 맵 안쪽으로 진행해 다른 바이옴에 도달할 수 있어야 한다.
- 최소 크기 이동속도 기준으로 바이옴 통과 시간을 측정한다. 1400은 기하학적 상한이지 통과 시간 보장이 아니다. 실제 이동 시간이 과도하면 바이옴 크기를 먼저 줄인다.

효과 판정은 개체 중심 좌표로 한다. 배경 경계는 너비 100으로 부드럽게 전환하되 실제 판정 범위를 확대하지 않는다. 진입 시 지역 이름을 짧게 표시하고 종족 색은 보존한다.

해류·먹이 군집·마그마는 해당 바이옴의 내부에만 둔다. 전체 목표는 종류별 3개이며 서로 다른 연결 지역에 하나씩 분산한다. 원 전체가 해당 바이옴과 맵 안에 들어가고 시작 구역과 겹치지 않는 위치를 사용한다. 세 구역을 배치할 수 없는 생성 결과는 다시 만든다. 마그마끼리 이어져 통로 전체를 막는 배치는 허용하지 않는다.

##### 바다: 이동 변화

해류 화살표로 방향과 범위를 표시한다. 공격 돌진·회피·넉백·빙결 중에는 적용하지 않는다. 이동 후 맵 경계 안으로 제한한다. 바다 전체에 감속을 주지는 않는다. AI는 기존 목적지 판단을 유지한다.

##### 설원: 정보 제한

첫 눈보라는 게임 시간 60초에 시작한다. 플레이어는 반경 밖의 개체·먹이·공격 전조를 볼 수 없으며, 화면이 이미 더 좁으면 시야를 넓히지 않는다. 월드 위치를 표시하는 UI도 가려진 적의 위치를 노출하지 않는다. 점수·직위·자기 상태 HUD는 유지한다.

설원 안의 AI는 눈보라 중 모든 자동 표적·위협·먹이·흡수·최상위 관계 탐색 반경을 기존 반경과 300 중 작은 값으로 제한한다. 범위 밖 상대의 현재 위치를 추적하거나 공격 결정을 새로 내리지 않는다. 마지막으로 확인한 지점으로 이동은 가능하지만 도착 후 상대가 안 보이면 다시 탐색한다.

능력 시전 때 받은 목표 지점은 유지할 수 있으나, 보이지 않는 목표의 위치 갱신은 하지 않는다. 파란색 회피 후 반격도 현재 감지가 필요하다. 이미 시작한 공격·파도·장판의 실제 충돌 범위나 피해는 줄이지 않는다. 자기 공격 전조는 보이고, 다른 개체의 전조는 가시 범위 안 부분만 표시한다.

##### 숲: 성장 기회와 경쟁

초기 자연 먹이 배치와 이후 자연 생성에 같은 분포를 적용한다. 총 초기 수량·생성 주기·상한·먹이 성장값은 기존 값을 유지한다. 처치·흡수 결과로 나온 먹이는 재배치하지 않는다.

숲 진입 자체로 AI를 모으지 않는다. AI가 기존 탐색으로 먹이를 발견한 결과 접근하도록 한다. 초록 수확 명령도 기존 감지 안의 실제 먹이를 사용한다. 큰 개체가 먹이를 독점하는지 확인하기 위해 지역별 자연 먹이·섭취량을 따로 기록한다.

##### 화산: 노출과 탈출

피해는 체류 1초를 넘긴 시간에 비례해 적용한다. 이탈하면 노출시간을 초기화한다. 환경 피해는 방어력·회피 무적·노란색 장판 내 회피 확률로 막지 못하며, 넉백·처치 보상을 발생시키지 않는다. 피해 발생 시 기존 회복 대기를 재설정한다. 사망·부활 시 노출시간도 초기화하고 환경 사망으로 기록한다.

AI는 마그마 안의 먹이·추격 지점을 일반 이동 목표로 새로 선택하지 않는다. 일반 이동 경로가 마그마 원을 가로지르면 가장 가까운 접선 쪽 경유점을 사용한다. 복잡한 장애물 탐색은 넣지 않는다. 안에 들어가면 원 중심에서 바깥 방향의 경계 + 여유 30 지점을 탈출 목표로 잡고 다른 행동보다 우선한다. 정확히 원 중심이면 현재 진행 방향을 사용한다.

이미 시작한 공격·회피·넉백은 끝까지 처리하고, 제어가 돌아오면 탈출한다. 빙결 중에는 이동할 수 없어 환경 피해가 계속된다. 최상위 행동 명령도 환경 탈출을 중단시키지 않는다.

### 구현과 표시

모든 시간은 일시정지를 제외한 게임 시간이다. 지역 효과는 각각 켜고 끌 수 있게 한다. 눈보라·마그마 피해·해류·먹이 편중의 설정을 분리한다. 마그마와 해류 경계는 관찰 가능한 범위에서 정확히 표시하고, 눈보라 경고와 마그마 노출 표시를 제공한다. 효과만으로 종족 색과 공격 전조가 묻히지 않도록 강도를 조절한다.

### 자체평가와 검증

현재 수치는 정적 코드 분석에 기반한 시작값이며 플레이 실측 결과가 아니다.

- **최상위 희소성:** 숲의 성장 가속 때문에 size 100과 첫 최상위가 너무 빨리 나올 수 있다. 환경을 끈 기준선과 같은 초기 상태·난수 흐름으로 비교하고 첫 size 100 시간, 첫 최상위 시간, 1·2·3·6분 시점 개체 수를 기록한다. 기존 목표 3~6분과 비교하되 편차·미등장도 함께 보고한다.
- **자연스러운 집결:** 숲의 실제 먹이 발견 → 접근 → 경쟁 흐름이 보이는지 확인한다. 최상위가 숲에 머문 것과 최상위를 따라간 것을 구분해 접근 원인·직전 목표를 기록한다. 지역이나 최상위 위치를 몰래 아는 AI는 금지한다.
- **먹이 편중:** 균등 전역 배치를 가정하면 숲의 실제 면적 비율을 f라 하면 숲은 자연 먹이의 약 25% + 75% × f를 받는다. 예를 들어 숲 면적이 25%면 약 43.75%다. 다른 지역은 각 면적 비율의 75%를 받는다. 이는 면적 대비 편중이며 총 먹이 증가는 아니다. 지역별 섭취·남은 먹이·성장 정체·최상위 점유를 비교한다.
- **해류 강도:** 초당 35는 AI 일반 이동 104~156보다 작지만 배회 속도에는 영향이 크다. 경계에 밀림, 역방향 정체, 공격·회피 거리 변화가 없는지 확인한다.
- **설원 공정성:** 기존 일반 감지 320·흡수 400·관계 600을 300으로 줄인다. 큰 개체의 넓은 카메라 시야를 제한하면서 성장에 따른 조망 보상도 약해질 수 있다. 작은/큰 개체와 화면 크기별로 전조 식별·추적 종료·시야 복원을 확인한다.
- **화산 대응:** 회복을 제외하면 진입 후 약 26초에 최대 HP만큼 피해를 받는다. 노출 0.9/1/1.1초, 이탈·재진입·부활, 회복 대기, 환경 사망 보상 없음, 원 중심 탈출, 경유점 우회와 명령 중 탈출을 검증한다. AI가 마그마 앞에서 영구 정체하지 않아야 한다.
- **출구와 선택권:** 여러 생성 시드에서 연결 바이옴 크기·면적·분산 조건을 확인한다. 맵 내부 출발점과 여러 직진 방향을 표본 검사하고, 가장자리에서는 안쪽 출구를 확인한다. 플레이어 크기별 통과 시간과 다음 바이옴까지의 거리를 기록한다. 숲을 떠나거나 눈보라를 벗어나려다 같은 지역을 오래 횡단하는 일이 반복되면 크기·인접 배치를 조정한다. 성장하기 좋은 숲이 한 구석에 몰리지 않아야 한다.
- **체험과 비용:** 지역 첫 진입 시간, 체류시간, 환경 사망률, AI 우회·탈출 성공, 프레임 비용을 기록한다. 최소 10회 비교 실행의 중앙값·범위를 보고하며 효과별 켜기/끄기로 원인을 분리한다. 무작위 초기 상태를 재현할 수 없으면 재현 한계를 보고한다.


큰 바이옴을 드물게 허용할지는 후속 자체평가 대상이다. 현재 크기 상한은 유지하며, 채택 시 별도 최소기획과 컨펌을 거친다.

### 지역 오브젝트·보상 조우 — 제안 009-r1 승인

고정 반복 지점 대신 랜덤 위치의 일회성 오브젝트를 사용한다. 사용자 원안·고착화 문제 제기와 Codex 세부안을 컨펌해 반영했다.

#### 1. 지역 오브젝트

| 지역 | 오브젝트 | 전조와 보상 연출 |
|---|---|---|
| 바다 | 해저 분출공 | 기포가 모인 뒤 먹이가 주변에 흩어짐 |
| 설원 | 얼음 속 먹이 주머니 | 균열이 밝아진 뒤 얼음이 갈라지며 먹이가 드러남 |
| 숲 | 씨앗 저장 둥지 | 씨앗이 떨린 뒤 바깥으로 퍼짐 |
| 화산 | 광물 분출구 | 빛과 작은 분출 뒤 먹이가 주변으로 떨어짐 |

고정 오브젝트를 맵에 미리 배치하지 않는다. 이벤트마다 위치를 먼저 무작위로 정하고, 그 지역에 맞는 일회성 오브젝트가 나타난다. 기존 대표 배경 형상과는 별개이며 충돌 장애물이 아니다. 전조 → 먹이 방출 → 오브젝트 소멸 순서로 끝나고, 먹이는 별도 수명 동안 남는다.

연결 바이옴 내부에서 반경 180 보상 구역 전체가 들어갈 수 있는 위치를 고른다. 시작 구역·마그마·해류와 겹치지 않고, 보상 구역에서 바이옴 경계까지 최소 100의 여유를 둔다. 화산 보상을 얻으려면 반드시 마그마를 통과해야 하는 배치는 피한다.

직전 성공한 이벤트의 보상 원과 겹치는 위치는 다음 이벤트에서 제외한다. 취소된 전조는 성공 이력에 넣지 않는다. 고정된 소수 후보 지점을 순회하지 않고, 유효한 영역 안에서 매번 새 위치를 표본 추출한다. 최근 위치의 추가 제외 기간·범위가 필요하면 고착화 실측 후 재제안한다.

조건에 맞는 위치를 찾지 못하면 그 지역은 이번 후보에서 제외한다. 모든 지역에 위치가 없으면 10초 후 다시 시도하고 생성 한계를 기록한다. 바이옴 크기 제한·안전 조건·최근 위치 제외를 몰래 완화하지 않는다.

#### 2. 발생과 보상 — 초기값

- 최초 후보 선정은 게임 시간 90~150초 중 무작위, 이후 발생 종료부터 90~150초 간격이다. 일시정지 중에는 시간이 흐르지 않는다.
- 유효한 위치가 있는 지역 종류 중 하나를 균등 선택하고, 그 지역의 유효한 면적 안에서 위치를 무작위로 선정한다. 같은 지역 종류가 연속 선택될 수 있지만 직전 성공 위치 주변은 제외한다. 플레이어·최상위 위치나 크기에 맞춰 보상을 따라붙게 하지 않는다.
- 전역에서 동시에 하나만 활성화한다. 총 먹이 상한 600 안에 24개를 넣을 여유가 있을 때만 3초 전조를 시작한다. 여유가 없으면 오브젝트 없이 10초 후 다시 확인한다. 전조 종료 때 여유를 다시 확인하고, 부족하면 보상 없이 오브젝트를 소멸시키고 10초 후 재시도한다. 기존 먹이를 삭제하거나 옮겨 자리를 만들지 않는다.
- 전조 종료 시 기존 자연 먹이와 같은 크기 8~16·성장값 5~21·색/섭취 규칙의 먹이 24개를 반경 180 안에 무작위 생성한다. 원 안 면적 기준 균등 분포를 사용하고 한 점에 겹쳐 뿌리지 않는다. 시각적인 낙하·퍼짐은 짧은 장식이며 먹이 위치·섭취 가능 범위는 생성 시 확정한다.
- 보상 먹이만 45초의 수명을 갖는다. 모두 먹히거나 45초가 지나면 이벤트가 끝난다. 만료는 추가 점수·폭발·재분배를 만들지 않는다. 오브젝트는 먹이 방출 직후 사라지며, 이벤트 종료는 남은 먹이를 기준으로 판정한다.
- 보상 먹이도 기존 총 먹이 상한과 자연 생성 개수 판정에 포함한다. 일시적으로 자연 생성이 늦어질 수 있으며 종료 후 정상 복귀한다. 숲의 25% 자연 배치 규칙에는 포함하지 않는 별도 이벤트 생성이다.
- 별도 획득 보너스·마지막 먹이 보너스·처치 보너스는 없다. 보상은 실제 먹은 먹이의 성장과 기존 공통 점수뿐이다.

#### 3. 발견·AI·생존

전역 위치 알림·목표 화살표·자동 집결을 넣지 않는다. 화면에 들어온 오브젝트의 전조와 생성된 먹이를 보고 플레이어가 판단한다. 눈보라에서는 기존 가시 반경 300을 적용한다. 화면 밖에서 전조 소리만으로 정확한 위치를 알려주지 않는다.

AI는 오브젝트를 보았다는 이유만으로 목적지를 바꾸지 않는다. 생성된 먹이가 실제 감지 범위 안에 들어왔을 때 승인된 먹이 군집·성격 규칙으로 평가한다. 성장 추구형은 위험을 감수할 수 있고, 회피형은 안전한 먹이를 고르며, 기회주의형은 유리한 상황을 노린다. 새 이벤트 전용 성격이나 전역 기억은 만들지 않는다.

최상위가 근처에 있으면 같은 보상에 접근하는 과정에서 관계·전투가 생길 수 있다. 최상위의 존재 자체로 이벤트가 생성되거나 모든 프레데터가 끌려오지는 않는다. 초록 수확 명령은 감지된 보상 먹이를 일반 먹이처럼 대상으로 삼을 수 있다. 도주·회복·마그마 탈출과 눈보라 정보 제한은 그대로 우선한다.

플레이어가 보상을 놓쳐도 불이익이나 진행 제한은 없다. 이벤트와 무관한 먹이 성장 경로를 유지한다.

#### 4. 자체평가

- **성장과 희소성:** 먹이 24개의 기대 성장량은 약 312이며, 현재 size 20→100에 필요한 성장 2500의 약 12.5%다. 가능한 총 보상은 120~504다. 한 개체가 전부 먹는 경우를 포함해 첫 size 100·첫 최상위 시간과 독점률을 비교한다. 기존 목표 3~6분이 너무 앞당겨지면 수량·주기를 수정안으로 제출한다. 전체 크기가 즉시 12.5% 커진다는 뜻은 아니다.
- **우연한 발견인가, 허탕인가:** 발견률·첫 발견 시간·발견부터 도착까지의 시간·만료 전 섭취 비율·아무도 못 본 이벤트 비율을 기록한다. 넓은 맵에서 아무도 발견하지 못할 수 있다. 전역 안내를 바로 추가하기보다 배치·국소 전조·주기 중 원인을 먼저 검토한다.
- **자연스러운 서사:** 먹이 발견 → 접근 → 경쟁자 조우 → 섭취/교전/도주를 실제로 관찰한다. 보상이 생기기 전부터 AI가 이벤트 위치로 몰리면 정보 누출이다. 최상위 관련 접근은 먹이 동기와 기존 관계 동기를 구분해 보고한다.
- **동등한 기회와 지역 차이:** 네 지역에서 발생·발견·섭취·사망률을 비교한다. 설원은 눈보라, 화산은 주변 위험 때문에 이용률이 낮을 수 있다. 지역별 보상량 차등은 이번에 넣지 않고 먼저 차이를 측정한다. 발생 위치가 지형 조건 때문에 특정 좁은 구역에 몰리는지도 확인한다.
- **자원 부작용:** 이벤트의 추가 공급과 상한 때문에 자연 생성이 줄어드는 효과를 함께 기록한다. 상한 부족 재시도 횟수·대기시간을 포함해 이벤트가 사실상 발생하지 않는지 확인한다. 숲 군집·초록 수확·보상 군집의 중첩으로 독점이 생기는지도 평가한다.
- **고착화:** 고정 지점 반복안과 랜덤 일회성안을 비교해 동일 지점 체류, 발생지 순회, 연속 보상 독점, 발생 위치 분포를 확인한다. 최근 위치 제외만으로 충분한지, 랜덤 분산으로 발견률이 지나치게 낮아지는지 함께 평가한다.
- **반복성:** 네 오브젝트는 초기에는 같은 보상 규칙을 공유한다. 표현만 달라 장소 선택이 단조로우면 지역별 촉발·위험·보상 형태 차이를 후속 제안한다. 확인 전에 네 종류를 모두 독립된 게임플레이로 평가하지 않는다.

#### 5. 검증과 완료 조건

가능한 초기 상태·난수 흐름을 재현해 이벤트 켜기/끄기 최소 10회 비교 실행을 수행한다. 재현 불가능한 부분은 보고한다. 발생 시점·지역·위치·생성/섭취/만료 수·성장값·섭취자 역할/크기/색·주변 교전·사망·첫 최상위 시간과 프레임 비용을 기록한다.

먹이 여유 23/24개, 전조 중 자연 생성, 상한 재시도, 유효 지역 하나/없음, 직전 원과 겹치는 위치 제외, 취소 후 이력 유지, 모든 먹이 조기 섭취, 45초 만료, 일시정지, 게임 재시작에서 상태를 확인한다. 상태와 먹이 수명은 재시작 시 초기화한다. 일회성 오브젝트가 방출·취소 후 사라지고 환경 판정·이동을 막지 않으며 눈보라 가림을 따르는지 확인한다.


### 초원·사막 확장 — 제안 013 승인

사용자 지역 원안·사막 유물 파밍에 Codex 세부 규칙을 제안해 컨펌받았다. 기존 4종 구현/검증 이후 6종으로 확장한다. 새 지역의 파멸 사건 종류는 아직 별도 미정이다.

#### 1. 6종 바이옴 배치

기존 분산 배치·직진 출구·대표 폭 600~1000·연결 지역 최대 두 점 거리 1400 제한은 유지한다. 5000² 맵에 초원·사막을 섞고, 총 6종의 면적 목표는 종류별 10~25%로 바꾼다. 각 종류 최소 3개 독립 연결 지역을 목표로 한다. 총합은 100%이며 시작 중립 구역은 해당 위치의 지역 효과를 억제하는 별도 영역이다.

이는 승인된 4종의 면적 20~30%·최소 4개 분산을 확장 시 대체하는 신규 제안이다. 사용자 컨펌으로 확장 시 배치 기준에 반영했다. 거대한 바이옴 예외는 여전히 후속 평가 대상으로 남긴다.

기존 해류·마그마·숲 먹이 군집과 대표 배경의 배치 조건을 모두 만족하는지 검사한다. 새 지역을 넣기 위해 기존 효과 구역을 억지로 압축하거나 바이옴 상한을 해제하지 않는다. 유효 배치 실패·재생성 횟수를 보고한다.

자연 먹이는 기존 전역 배치를 유지하므로 두 지역에서도 생성된다. 숲 25% 편중과 자연 먹이 총량·상한은 유지한다. 숲 실제 면적 f에서 받는 기대 비율은 25% + 75%×f이므로 확장 전후 실제 숲 면적·먹이 밀도를 다시 측정한다.

#### 2. 초원 — 분산 성장과 이동 선택

낮은 대비 풀 결·완만한 언덕 무늬로 표시한다. 기본 감속·피해·시야 제한·추가 회복·스탯 버프는 없다. 먹이는 전역 자연 배치로 분산되며 숲처럼 고정 군집을 추가하지 않는다. 적 전투·흡수는 정상적으로 가능하다.

목적은 먹이 밀집 지역을 피해서 분산 성장하거나 위험 지역 사이를 통과할 선택지를 제공하는 것이다. 안전을 보장하거나 초원 전체를 시작 중립 구역으로 취급하지 않는다. 기존 관계·최상위 영역·전쟁 이동이 초원에서도 발생한다.

단순한 배경만으로 차이가 충분한지 확인하고, 차이가 없으면 지역 오브젝트 등 후속 기믹을 제출한다. 최초 최소 범위에서 모든 지역에 위험 효과를 강제로 채우지 않는다.

#### 3. 사막 — 유물을 찾는 탐색 공간

사구와 낮은 대비 피라미드 윤곽을 배경으로 사용한다. 피라미드는 충돌 장애물·고정 아이템 공급소가 아니다. 사막 전체에 기본 피해나 시야 제한은 추가하지 않는다. 배경과 실제 획득 가능한 유물은 형태·밝기로 구분한다.

**일회성 유물 초기 규칙:**

- 첫 후보 선정은 게임 시간 120~180초 중 무작위, 이후 유물 획득/만료부터 같은 무작위 간격이다. 동시에 하나만 존재한다.
- 사막 내부 유효 면적에서 매번 다른 위치를 무작위로 선택한다. 시작 구역·활성 지역 보상·환경 위험과 겹치지 않는다. 직전 성공 출현점의 반경 180 안은 다음 출현에서 제외한다. 위치가 없으면 10초 후 재시도하고 조건을 완화하지 않는다.
- 3초의 국소 모래빛 전조 뒤 유물이 나타나고 45초 동안 유지한다. 전역 위치 알림은 없다. 플레이어·최상위를 따라 생성하지 않는다. 전조는 가까운 개체를 움직이거나 밀지 않는다.
- 플레이어와 모든 역할·색 AI가 획득 가능하다. 획득은 개체 중심이 유물 중심 반경 20에 들어오면 성립한다. 같은 갱신에 여러 개체가 들어오면 가까운 중심 거리, 동률은 고유 ID 순으로 한 개체만 얻는다. 성장 먹이의 크기 조건과 별개의 아이템 판정이다.
- 효과는 **8초 동안 일반 이동속도 +10%**다. 성장·score·maxHP·공격·회피·돌진·넉백·감지 범위는 바꾸지 않는다. 기존 일반 이동속도에 곱하며 하늘색 무목표 배회 계수와도 곱한다. 해류 같은 외력은 증폭하지 않는다.
- 효과는 중첩하지 않는다. 남은 시간과 새 효과 중 긴 시간만 유지한다. 유물은 획득 즉시 소멸하고 효과는 사망/새 게임에서 종료한다. 체류 지역이 바뀌어도 남은 시간 동안 유지한다.
- 같은 색 아군에게 효과가 전파되거나 오브젝트에서 반복 지급되지 않는다. 만료 유물은 성장·처치 보상을 만들지 않는다.

AI는 기존 감지 범위 안에서 유물이 보일 때만 획득 목표로 평가한다. 환경 탈출·도주·회복·능력 명령·기존 전투 우선순위를 유지하며 유물 때문에 생존 판단을 건너뛰지 않는다. 유효한 먹이/성장 목표가 있으면 이를 유지하고, 무목표 탐색보다 유물 접근을 우선한다. 리스크 회피형은 기존 안전 위치 조건을 추가로 요구한다. 유물 소멸·감지 이탈·위협 발생 시 목표를 해제한다.

이 유물은 최소 아이템 효과를 검증하는 시작점이다. 백로그의 공격력 3배·자석·스킬트리·색 변화·복제는 별도 기획이며 이번에 추가하지 않는다. 효과 종류를 늘리기 전 이동·공격·회피 스탯에 영향이 분리되는지 확인한다.

#### 4. 기존 사건과 연결

승인된 국소 먹이 이벤트가 지역 종류를 선택할 때 초원·사막도 포함한다. 같은 24개 먹이·90~150초·45초 규칙을 사용하며 초원은 씨앗 덩어리, 사막은 묻힌 먹이 주머니가 일회성으로 드러나고 소멸한다. 기존 4종 발생 빈도가 줄어드는 효과를 함께 평가한다.

사막 유물은 먹이 보상과 별도의 한도를 사용하지만 두 사건의 활성 범위는 겹치지 않게 한다. 같은 프레임의 배치 요청도 이미 확정된 구역을 확인한다. 승인된 파멸의 위험 범위 제외를 연결하고, 새 지역의 파멸 종류는 별도 제출한다.

#### 5. 자체평가·검증

- **지역 선택:** 초원이 낮은 위험의 분산 성장 경로로 사용되는지, 그냥 먹이 없는 통로가 되는지 확인한다. 사막 유물에 접근할 가치가 있는지·평균 발견/획득/만료율·발견부터 도착까지 시간을 기록한다.
- **성장과 최상위:** 확장 전후 첫 size 100·첫 최상위·숲 점유·각 지역 먹이 잔량을 비교한다. 면적 분산 때문에 기존 성장 경로가 막히거나 숲에 더 집중되는지 평가한다. 유물 획득 자체는 성장 보상을 주지 않는다.
- **공정성과 독점:** 역할·size·색별 유물 획득률과 큰 개체의 길목 점유를 본다. 중심 기반 획득이 몸체가 큰 개체에서 부자연스럽게 보이는지 확인한다. 반경 20은 몸체 반경이 아니라 획득 표식의 범위로 표시한다.
- **효과 체감:** +10%·8초가 알아차리기 어려운지, 전투 추격/탈출에 과도한 영향을 주는지 실제로 확인한다. 부드러운 화면 추적과 버프 시간·상태 표식으로 효과를 읽을 수 있어야 한다. 부족하면 효과 수치 변경을 별도 제안한다.
- **고착화:** 피라미드와 유물 위치를 암기해 반복 대기하는지, 랜덤 위치가 좁은 사막 구역에 몰리는지 기록한다. 유물 때문에 전체 플레이가 사막 순회로 바뀌면 위치·주기·보상을 재검토한다.
- **6종 배치:** 종류별 면적·연결 영역 수·직진 통과 시간·기존 효과 구역 배치 실패를 여러 시드에서 확인한다. 조건이 과도해 맵 생성이 느려지면 후보 생성 방법/면적 목표를 재제안한다.

가능한 동일 초기 상태로 4종/6종 비교와 유물 켜기/끄기 비교를 한다. 지역별 체류·먹이·교전·첫 최상위 시간과 렌더링 비용을 기록하며 유효 생성 시드 최소 10개를 확인한다. 강제 시험으로 동시 획득·타이·만료·효과 중첩·사망·지역 이탈·회피/공격 거리 불변·일시정지·재시작·위치 불가·사건 중첩을 확인한다. 현재 체감과 수치는 미측정 가설이다.


## 9. 시대(Era) 시스템 — 제안 010 승인

시대 원안은 사용자 직접 제안, 아래 수치·전환·선택 규칙은 Codex 제안·사용자 컨펌이다. 개별 백로그 이벤트는 미승인 의견으로 백로그에 유지한다. 전쟁 집단 이동·최상위 결투는 제안 011로 승인됐고, 파멸 수정안 012-r1도 승인됐다. 파멸은 아래 승인 규칙대로 기본 순환과 별도의 활성 상태로 적용한다.

### 1. 시대 진행과 랜덤 진입

새 게임마다 세 시대 중 하나를 균등 선택한다. 초기 시대 경과시간은 0~60초에서 무작위로 정한다. 다음 순서는 고정 순환이며 매번 시대를 무작위로 다시 뽑지는 않는다.

각 시대 진입 시 전환 검사 시작 시간을 90~150초에서 뽑는다. 이 시간 이후 아래 조건을 10초 연속 만족하면 다음 시대로 전환한다. 최대 180초에는 조건 미충족이라도 다음 시대로 넘어가며 강제 전환을 기록한다. 시대 시간은 게임 시간 기준이며 일시정지 중 정지한다. 첫 시대만 무작위 경과시간으로 인해 실제 체류가 짧을 수 있다.

| 현재 시대 | 다음 시대 | 조건 |
|---|---|---|
| 번성 | 안정 | 살아 있는 AI가 60개 이상 |
| 안정 | 전쟁 | 살아 있는 AI가 50개 이상이며, 최근 30초 중 먹이 수가 120개 미만이었던 시간이 총 10초 이상 |
| 전쟁 | 번성 | 살아 있는 AI가 40개 이하 |

조건은 번성의 개체 회복 → 안정 중 자원 경쟁 → 전쟁의 소모라는 가설이다. 인위적 조건값을 숨기지 않고 발생 이유·빈도를 실측한다. 플레이어는 AI 개수 조건에서 제외한다. 모든 시대로 진입할 수 있도록 최대시간을 두되, 매번 최대시간만 타면 조건이 작동하지 않는 것으로 평가한다.

초기 개체는 기존 초기 생성 방식과 승인된 역할 배정을 사용한다. 사전 시뮬레이션은 이번에 추가하지 않는다. 따라서 전쟁기로 시작해도 이미 오래 싸운 생태계가 생성되지는 않는다. 랜덤 시대 진입과 기존 세계에 중도 입장하는 경험은 구분해 보고하며, 필요하면 사전 시뮬레이션을 후속 제안한다.

### 2. 시대별 차이 — 초기값

| 항목 | 번성 | 안정 | 전쟁 |
|---|---|---|---|
| 자연 먹이 생성 빈도 | 기존의 1.5배 | 기존 유지 | 기존 유지 |
| 먹이 목표 선택 가중치 | 2 | 1 | 1 |
| 일반 사냥 목표 선택 가중치 | 0.25 | 1 | 1.5 |
| 동족 AI 흡수 시도 확률 배율 | 0.5 | 0.5 | 1 |

자연 먹이 기본 주기 0.25초라면 번성은 약 0.167초다. 먹이 상한 600·초기 450개·개별 성장값·숲 편중은 유지한다. AI 생성 주기와 상한도 유지하며 살아 있는 개체 수·크기를 시대 전환 때 강제로 보정하지 않는다. 기존 값을 이후 조정하면 배율은 그 기준값에 적용한다.

가중치는 현재 성격과 종족 규칙에서 **이미 허용된 먹이 목표와 일반 사냥 목표가 동시에 경쟁할 때만** 곱하고 정규화한다. 빨강의 일반 사냥 가중치 1.5 등 승인된 종족 배율과 곱한다. 결정 난수는 후보 선택 때 사용하고, 같은 유효 목표를 프레임마다 재추첨하지 않는다. 기존 목표 종료·상실이나 생존 우선행동 이후 새 목표 선정 시 적용한다.

환경 탈출·도주·회복·회피·허용된 막타와 파랑 반격의 우선순위, 대상 크기/HP·감지·공격 해금 조건을 바꾸지 않는다. 회피형이 전쟁기라고 불허된 상대를 공격하거나 프레이가 일반 사냥을 시작하지 않는다. 플레이어의 공격 선택·스탯은 자동으로 바뀌지 않는다.

동족 흡수 배율은 목표당 한 번의 흡수 시작 수락 판정에 적용한다. 기본 수락 확률 1이라면 번성·안정 0.5, 초록 기본 0.5라면 0.25다. 거절 후보는 추격과 중앙 자동 흡수 시작 모두 차단하고, 재판정 조건은 기존 초록 규칙처럼 감지/유효 거리 이탈·사망·크기 관계 역전 때 갱신한다. 동일 후보를 매 프레임 재추첨하지 않는다. 진행 중 흡수는 전환 때문에 끊지 않는다.

파랑 포식·초록 수확·빨강 집결은 승인된 능력의 수락 확률·우선순위를 유지하며 위 시대 배율을 추가하지 않는다. 동족 흡수 감소는 같은 색이 함께 남아 있을 가능성을 높이는 초기 수단이다. 같은 색 군집 형성이 보장되는 규칙이나 크기 비율 고정 기능은 아니다. 최상위끼리의 의도적 교전 빈도·전쟁 집단 이동은 다음 제안에서 추가한다.

### 3. 기존 지역 조우와 시대 전환 표시

승인된 일회성 보상 군집은 모든 시대에서 기존 90~150초 주기·24개·수명을 유지한다. 시대 전환이 진행 중 이벤트를 취소하거나 추가 생성하지 않는다. 첫 비교에서는 자연 공급·AI 선택 변화와 이벤트 공급 효과를 분리한다.

전환 시 시대 이름과 한 줄 설명을 짧게 보여준다. 번성은 먹이 풍부, 안정은 자원 경쟁, 전쟁은 교전 증가를 알린다. 현재 시대는 HUD에서 확인할 수 있다. 전환 전 5초 경고는 최대시간에 의한 전환에만 제공한다. 조건 전환은 발생 시 알리고, 확정되지 않은 조건 충족을 미리 예고하지 않는다. 화면 색 변화가 종족 색·눈보라·공격 전조를 덮지 않도록 한다.

### 4. 자체평가

- **첫 size 100·최상위 희소성:** 첫 진입 시대별 첫 size 100·최상위 시간, 1/2/3/6분 등장 수·직위 교체를 비교한다. 번성 공급 1.5배와 군집 보상이 합쳐 기존 목표 3~6분을 지나치게 앞당기는지 확인한다. 늦은 최초 시대만 보여 주는 선택적 집계를 피한다.
- **시대 차이가 실제로 보이는가:** 분당 섭취·일반 사냥 시작·동족 흡수·처치·환경 사망·크기별 개체 수·먹이 잔량을 시대별 기록한다. 가중치가 달라도 허용 조건 때문에 전쟁 교전이 늘지 않을 수 있다. 생존 규칙을 몰래 약화하지 않고 원인을 보고한다.
- **인위적인가:** 개체가 시대가 바뀌었다는 이유로 전역 적 위치를 알거나 최상위로 몰리지 않아야 한다. 먹이·경쟁 조건이 접근과 교전으로 연결되는지 실제 플레이로 확인한다. 전쟁 시작 직후 같은 상황의 행동 변화가 너무 급하면 효과 적용의 완만한 전환을 후속 제안한다.
- **순환이 작동하는가:** 조건 전환/최대시간 전환 비율·체류시간·저인구 지속시간을 측정한다. 모든 전환이 시간 만료로만 일어나거나 번성에서도 개체 회복이 안 되면 임계값과 기존 생성/교전 원인을 재평가한다. 조건 때문에 무한 정체하지는 않아야 한다.
- **비율과 군집:** 같은 색 근접 체류·동족 흡수와 크기별 생존을 비교한다. 순위 기반 역할 비율이 유지되는 것과 실제 size 구간 분포가 안정적인 것은 다른 지표다. 안정기의 실제 군집·크기 분포를 확인하기 전 원안 전체 구현 완료로 표시하지 않는다.
- **랜덤 진입:** 초기 시대·경과시간 조합으로 시작 경험이 지나치게 불리한지 비교한다. 사전 시뮬레이션 없는 초기 세계가 시대의 설명과 어긋나는지도 실제로 확인한다. 무작위로 전쟁에 진입했다고 준비 없이 즉사하는 현상을 검토한다.
- **이벤트 독립성:** 지역 보상 켜기/끄기를 별도 비교하고, 추후 거대화·변이·버프가 추가되면 기본 시대 효과와 따로 측정한다. 여러 사건을 한꺼번에 추가해 원인을 알 수 없게 하지 않는다.

### 5. 검증과 완료 조건

가능한 동일 시드와 초기 상태로 시대 효과 켜기/끄기 비교, 각 시작 시대 최소 5회 실행과 최소 두 번의 전체 순환 관찰을 수행한다. 재현 한계를 보고한다. 설정으로 시대 강제 진입·효과 개별 끄기를 지원해 경계 조건을 검증한다.

조건의 10초 연속 유지/중간 해제, 무작위 검사 시작 시점, 최대 180초, 낮은 AI 수, 먹이 임계값, 일시정지·재시작, 진행 중 흡수·명령·지역 이벤트의 전환 유지와 전역 정보 누출 여부를 확인한다. 최근 30초 지표가 부족한 초기 구간은 실제 확보된 시간만 집계하고 부족 시간을 0으로 꾸며 채우지 않는다. 동족 거절 후보·이력·시대 타이머는 새 게임에서 초기화한다.


### 전쟁 집단 이동·최상위 교전 — 제안 011 승인

사용자 원안의 집단 이동·최상위 교전에 Codex 세부 조건을 제안해 컨펌받았다. 아래 규칙은 010의 기본 효과에 추가한다. 파멸은 아래 제안 012-r1 승인 규칙을 따른다.

#### 1. 사건 동기

풍부했던 먹이가 줄어듦 → 근처 동색 개체 일부가 다른 먹이 위치로 이동 → 이동 중 다른 집단/최상위와 조우 → 경쟁·교전·철수의 흐름을 만든다.

전쟁기는 전투만 강제하는 상태가 아니다. 이동이 다른 지역으로 탈출하거나 새로운 먹이를 발견하는 결과로 끝날 수도 있다. 플레이어에게 이동·참여를 강제하지 않는다.

#### 2. 집단 이동 — 최소 초기값

전쟁기 중 30초마다 이동 후보를 검사한다. 전역 동시 집단은 최대 2개, 한 집단은 선도 AI 포함 최대 5개다. 검사 때 새 집단은 최대 하나만 구성한다. 전쟁 종료 시 이동 목표를 해제하되 진행 중 공격·회피·흡수는 기존 흐름을 따른다.

선도자는 프레데터 또는 최상위 AI 중 자기 HP 60% 이상이며 생존 우선행동·공격·흡수·능력 명령·기존 집단 이동 중이 아닌 개체다. 최근 10초 안에 실제 감지했던 먹이 군집(거리 120 내 성장 합 80 이상)이 먹이 감소 때문에 더 이상 적격하지 않은 경우에만 후보가 된다. 단순 감지 밖 이탈은 고갈로 기록하지 않는다. 후보 중 하나를 무작위 선택한다. 조건 미충족이면 이동 사건 없이 넘어간다.

목표는 선도자가 최근 10초 안에 직접 본 다른 먹이 군집의 마지막 확인 지점이다. 현재 감지 밖이면 남아 있는 먹이를 안다고 가정하지 않는다. 다른 기억이 없으면 현재 방향을 중심으로 맵 안의 450 거리 탐색 지점을 무작위 선택한다. 위험 원을 가로지르면 기존 화산 우회 규칙을 적용한다. 목적지·적 위치를 전역 검색하지 않는다.

참가자는 선도자 감지 320 안의 동색 AI 중 더 작고 HP 60% 이상이며 능력 명령·생존행동·흡수·전투 중이 아닌 개체다. 관계 독립형 프레데터와 리스크 회피형은 새 집단 합류에서 제외한다. 나머지는 가까운 순서로 최대 4개 선택한다. 생존·성격을 통째로 지우지 않으며 선도자는 소집 때 목표 지점만 근처 참가자에게 공유한다. 눈보라 중 실제 감지 상한을 적용한다.

참가자는 선도자 뒤에서 느슨하게 따라가며 기본 배회 이동속도를 사용한다. 기본 추종 간격은 중심 거리 200~300, 실제 선도자의 흡수 유지거리 +80이 더 크면 그 거리를 사용한다. 필요한 안전거리가 450을 넘거나 선도자와 450 이상 떨어지면 합류를 포기한다. 선도자는 참가자를 흡수 대상으로 새로 선택하지 않으며 참가자도 서로를 집단 이동 목적의 흡수 목표로 선택하지 않는다. 기존 우연한 중앙 흡수는 면제하지 않으므로 안전거리 유지가 필요하다.

최대 12초, 목적지 도착, 선도자 사망·전쟁 종료 때 집단 이동을 끝낸다. 각 개체는 위협·환경·회복·실제 성장/공격 기회가 생기면 개별 이탈한다. 빨강 집결 등 승인된 능력 명령을 받으면 집단 이동에서 이탈하고 명령을 따른다. 해산 후 같은 개체는 30초 동안 새 집단에 합류하지 않는다. 단체 순간이동·적 전역 추적·이동 자체의 공격 버프는 없다.

최상위가 없거나 먹이 고갈 경험이 없는 초기 전쟁기에는 집단이 안 생길 수 있다. 이를 실패/미발생으로 기록하며 무조건 발생시키기 위해 가짜 기억을 넣지 않는다. 최초 최대 5개 집단이 충분한 규모로 보이는지 검증한 뒤 확대 여부를 제안한다.

#### 3. 최상위 간 교전 — 명시적 전쟁 예외

현재 일반 사냥의 상대 size 0.8배 제한만으로는 비슷한 크기의 최상위가 잘 싸우지 않는다. 아래는 **전쟁기 최상위 AI만의 제한적 신규 예외**이며 기존 프레데터 도전형 규칙을 대체하지 않는다.

일반 전투 감지 범위 안에서 다른 색 최상위를 직접 발견하고, 자기 HP 70% 이상·상대 size가 자기의 0.8~1.2배·공격 해금/스택 보유 조건을 만족해야 한다. 자기 회복·위협 대응·명령 중에는 새 결투를 시작하지 않는다. 더 큰 적이 160 안에 있거나 마그마 안 목표이면 시작하지 않는다. 감지 반경이나 공격 도달 범위는 늘리지 않는다.

성장 추구형은 적격 조우마다 한 번 50% 확률로 결투 추격을 선택한다. 실패하면 같은 상대가 감지 밖으로 나갔다 다시 들어오기 전에는 재추첨하지 않는다. 리스크 회피형은 새 결투를 먼저 시작하지 않고 기존 허용된 반격/생존행동을 사용한다. 기회주의형은 기존 국소 막타 규칙을 유지한다. 상대가 먼저 공격해도 무조건 정면 대응을 강제하지 않는다.

추격은 최대 5초이며 자기 HP 50% 이하, 상대 size 1.2배 초과, 더 큰 근접 위협, 환경 탈출 필요, 상대가 감지 밖/사망/직위 상실이면 끝낸다. 실제 공격은 기존 사거리·전조·스택·회피·방어를 따른다. 서로 같은 색 최상위끼리의 공격은 이번에 허용하지 않는다. 플레이어의 자동 결투는 없다. AI가 상대 최상위 플레이어를 조건에 따라 대상으로 삼을 수는 있다.

동일 상대에 대해 결투 종료 후 10초 재시작 대기를 둔다. 전쟁 종료 시 신규 결투와 추격은 해제하고 이미 시작한 공격은 완료한다. 직위 상실 시 예외도 해제한다. 집단 이동 선도자가 결투를 시작하면 그 집단은 해산하며 하위 참가자에게 자동 공격 명령은 주지 않는다. 교전 참여는 각자의 기존 성격·관계·능력 명령으로 결정된다.

안정기의 최상위 신규 결투는 비활성, 번성도 동일하다. 기존 허용된 일반 사냥·막타·반격·도전은 유지한다. 모든 최상위 조우가 교전으로 이어지는 전쟁은 의도하지 않는다.

#### 4. 표시와 이벤트 연결

집단 이동에는 선도자와 참가자 위 짧은 이동 상태 표시를 제공하고, 화면에 실제 보이는 구성원만 표시한다. 맵 전체 이동 경로나 위치 알림은 제공하지 않는다. 선도자/참가자 ID·원인·목표·이탈 이유는 디버그와 보고서에 기록한다. 백로그의 일반 적 경로 표시 토글과는 별도이며 기존 표시 변경은 승인 없이 섞지 않는다.

일회성 보상 군집을 실제로 발견했다면 집단의 이동 동기가 될 수 있으나 이벤트 위치를 미리 공유하지 않는다. 백로그의 거대화·복제·전쟁 버프는 아직 후보다. 이번 집단 이동·결투에 추가 적용하지 않는다.

#### 5. 자체평가와 검증

- **서사:** 자원 소진→이동→발견/조우→교전/철수의 실제 사례를 확인한다. 출발 원인이 불명확하거나 무작위 목적지를 향한 행렬만 보이면 동기 표현과 탐색 규칙을 재평가한다.
- **규모·빈도:** 전쟁당 후보/생성/해산 수, 참가자 수·동시 집단 수·이동 거리·도착/중도 이탈을 기록한다. 생존 우선 때문에 즉시 해산해 규모가 보이지 않는지, 최대 2집단이 작은 개체를 전부 잠식하는지 확인한다.
- **긴장과 희소성:** 최상위 조우 수·적격/수락/실제 공격/처치/철수 수를 구분한다. 첫 최상위 시간·생존시간·직위 교체, 전쟁 전후 크기 분포를 비교한다. 성장 추구형 비율과 조건 때문에 50%가 전체 최상위 교전율이 되는 것은 아니다.
- **성격 보존:** 회피형과 기회주의형이 같은 전쟁 행동으로 획일화되지 않아야 한다. 작은 참가자가 자기보다 큰 선도자에게 흡수되거나 위험을 무시한 추종으로 죽는 빈도를 기록한다. 추종이 안전하지 않으면 합류 조건·간격을 수정한다.
- **인위적 추적:** 먹이와 적의 실제 감지·관찰 시점으로 목표 선정 이유를 재현한다. 눈보라·감지 밖 이동·먹이 소멸 상황에서 숨은 현재 위치를 사용하지 않아야 한다.
- **부족한 전쟁:** 최상위가 드문 초기에는 교전이 없을 수 있다. 첫 최상위를 억지로 생성하지 않고 시대 진입 시간·유효 표본을 분리해 평가한다. 최대시간으로 도달한 전쟁과 경쟁 조건으로 도달한 전쟁을 비교한다.

제안 010만 적용한 상태와 이 안을 추가한 상태를 가능한 동일 초기 상태로 비교한다. 전쟁 구간을 최소 10회 관찰하되 최상위 없는 구간도 포함하고 유효 조우 표본을 따로 적는다. 합류/거절·흡수 안전거리·감지 상실·명령 전환·직위 변경·HP 경계·전쟁 종료·재시작·재추첨/대기 처리를 검증한다. 결과에 따라 규모·확률·시간을 재제안한다.


### 파멸·지역별 사건 — 제안 012-r1 승인

사용자 원안과 숲의 미혹+산불 수정 방향에 Codex 세부 규칙을 제안해 컨펌받았다. 플레이어 행동 강제는 후속 자체평가 대상이며 현재 조작 유지 규칙을 따른다.

#### 1. 발동과 종료 — 초기값

- 살아 있는 최상위 중 절대 size 180 이상이 3개 이상인 상태가 10초 연속이면 파멸을 활성화한다. 플레이어도 같은 직위·크기 조건이면 포함한다. 일반 큰 AI는 직위가 없으면 포함하지 않는다.
- 파멸 중에는 완화 기준인 size 160 이상 최상위가 1개 이하인 상태가 20초 연속이면 종료한다. 활성화 기준과 완화 기준을 달리해 경계 진동을 줄인다.
- 최대 지속은 120초이며 종료 후 60초 재발동 대기를 둔다. 대기 이후 발동 조건을 새로 10초간 확인한다. 조건이 계속 유지돼도 끊임없는 파멸이 되지 않도록 한다.
- 사망·직위 상실은 즉시 집계에 반영한다. 재시작하면 타이머·활성 위험·이력을 초기화한다. 일시정지는 모든 시간을 멈춘다.
- 기본 Era 시간과 전환·먹이 공급·AI 성격은 계속 작동한다. 파멸 발동 때 강자를 삭제·축소하거나 생태계 수치를 강제로 초기화하지 않는다.

#### 2. 국소 배치와 사건 진행

활성화 6초 후 첫 위험을 만들고, 이후 15~25초마다 후보를 정한다. 동시에 전조/활성인 사건은 합쳐 최대 2개다. 한도가 차면 5초 후 재확인한다. 각 사건은 전조 6초, 활성 최대 16초이며 끝나면 지형을 원상 복원한다.

유효 위치가 있는 네 바이옴 중 하나를 균등 선택하고 내부에서 위치를 무작위로 고른다. 위험의 전체 범위는 반경 220 원 안에 들어가야 한다. 시작 중립 구역·맵 밖·다른 파멸 사건과 겹치지 않는다. 최근 끝난 사건 위치와 겹치는 후보는 다음 사건에서 제외한다. 플레이어나 최상위의 현재 위치를 따라붙거나 점수에 따라 표적 선정하지 않는다.

상시 마그마·보상 전조/먹이 구역과도 겹치지 않는다. 파멸 위험을 피해 기존 보상을 획득할 수 있게 한다. 반대로 새 보상 이벤트도 진행 중 파멸 구역을 후보에서 제외한다. 두 시스템이 같은 프레임에 후보를 고르면 먼저 확정된 구역을 반영해 나머지를 재검사한다.

맵 경계와 함께 탈출 통로를 막는 배치를 피한다. 후보에 맞는 위치가 없으면 사건을 생략하고 원인을 기록하며 바이옴 크기 상한이나 안전 조건을 완화하지 않는다. 파멸 종료 시 진행 중 전조·위험도 종료하고 후속 피해를 남기지 않는다.

#### 3. 지역별 위험

| 지역 | 파멸 사건 | 실제 위험과 대응 |
|---|---|---|
| 바다 | 거친 파도 | 반경 220 안을 가로지르는 길이 440·폭 120의 파도 띠가 4초에 한 번 통과. 위험 원 밖이나 띠를 피해 이동 |
| 설원 | 혹한 소용돌이 | 반경 220 전체가 혹한 피해 구역. 안에서는 월드 가시 반경을 기존 값과 180 중 작은 값으로 제한. 원 밖으로 탈출 |
| 숲 | 미혹과 산불 | 판단을 흐리는 국소 영향과 방향성 있는 산불이 함께 발생. 이상 행동을 살피며 불길의 진행 방향과 퇴로를 읽기 |
| 화산 | 연속 분출 | 반경 220 안의 반경 100 분출 지점 2개가 8초마다 교대. 다음 활성 지점을 미리 보고 이탈 |

바다 파도는 무작위 방향을 전조에서 확정하고 4초 동안 위험 원의 한쪽에서 반대쪽으로 이동한다. 띠와 원의 교집합만 피해 구역이다. 같은 방향으로 네 번 통과하며 이동·넉백 효과는 별도로 추가하지 않는다.

화산 분출 지점은 생성 때 위치를 정하고 원 전체가 사건 범위 안에 들어가게 한다. 최소 두 지점 사이 중심 거리는 200으로 해 겹치지 않게 배치한다. 첫 지점은 전조 때, 교대할 지점은 활성 2초 전부터 경고한다. 배치할 수 없으면 사건 생성을 생략한다.

네 사건 모두 실제 활성 피해 영역에 있는 동안 초당 최대 HP의 8% 환경 피해를 적용한다. 프레임 시간에 비례하고 중첩 피해를 합산하지 않는다. 계속 맞으면 회복 제외 약 12.5초에 최대 HP만큼 피해를 받는다. 숲·화산·바다는 불길/분출/파도의 위치를 보고 이동해 피해를 줄일 수 있다. 숲의 미혹 자체는 환경 피해를 주지 않으며 산불만 피해를 준다. 수치는 시작 가설이며 네 사건의 평균 위험도가 동일하다는 뜻은 아니다.

방어·회피 무적·노란 장판의 직접 공격 회피는 환경 피해를 막지 않는다. 피해마다 기존 회복 대기를 재설정한다. 환경 사망으로 처리하고 공격자 점수·처치 보상은 없다. 종족별 환경 면역은 추가하지 않는다. 사망/부활은 기존 흐름을 유지한다.

####### 숲 상세 — 미혹 + 진행하는 산불

두 효과는 같은 숲 사건으로 묶고 동시 사건 한도에서 하나로 센다. 미혹은 익숙한 행동 예측을 흔들고, 산불은 실제로 길을 바꾸는 환경 위험이다. 포자 폭발과 2초 피해/안전 박동은 대체한다.

**산불:** 반경 220 원의 한쪽에서 점화해 반대쪽으로 진행하는 폭 70의 불길 띠를 만든다. 방향은 사건 전조에서 확정하고 활성 16초 동안 원을 가로지른다. 띠와 사건 원의 교집합만 피해를 준다. 지나간 자리는 꺼져 통과할 수 있고, 불길이 다시 되돌아오거나 원 밖으로 번지지 않는다. 연소 예정 방향을 전조·불씨로 표시한다. 원을 둘러싸는 불고리·이동 장애물·지속 화상은 추가하지 않는다. 실제 불길 안의 피해는 공통 초당 최대 HP 8%다.

**미혹:** 전조가 끝난 뒤 사건 원 안에 1초 연속 노출된 AI에게 적용한다. 사건 안에서 유지되고 이탈 3초 뒤 해제한다. 재진입은 다시 노출시간을 평가한다. 사건 종료·사망·재시작 때 즉시 해제한다. 기존 성격을 재배정하거나 색·직위·스탯·공격 가능 종족을 바꾸지 않는다.

- 성장 추구형: 유효한 먹이/사냥 목표를 놓지 않으려는 집착. 일반 위험 때문에 목표를 포기할 때 최대 1초 늦게 해제한다. 목표가 사망·섭취 불가·감지 밖이면 즉시 해제한다.
- 리스크 회피형: 적의 크기를 실제보다 작게 판단하는 경향. 일반 크기 위협 기준을 자기 size 1.2배에서 1.35배로 높인다. 허용된 공격 대상 크기·감지 범위·공격 해금은 바꾸지 않으므로 적극 사냥형으로 변하지 않는다.
- 기회주의형: 막타 기회를 과대평가. 기존 국소 막타 조건 중 적 HP 기준만 실제 방어 후 예상 피해의 1.25배까지 허용한다. 실제 피해는 늘지 않아 막타 실패·노출 가능성이 생긴다. 상대 크기·후딜·거리·스택·무적 조건은 유지한다.

공통 안전 한계는 자기 HP 50% 이하 또는 자기 size 1.5배 초과 위협이 160 안에 있으면 즉시 철수다. 미혹은 빙결·회복·회피 중 행동을 강제로 시작시키거나 능력 명령을 취소하지 않는다. 환경 탈출은 기본 우선순위를 유지하되, 노출된 AI가 처음 산불 전조/활성 불길을 직접 인지했을 때만 사건당 한 번 최대 1초 판단 지연을 제안한다. 이미 환경 피해를 받거나 HP 50% 이하이면 지연을 생략하고 탈출한다. 같은 사건에서 반복 지연하지 않는다.

플레이어는 주변 개체의 미혹 행동과 산불로 압박받는다. 입력 반전·강제 이동·가짜 HP/적 위치 표시는 넣지 않는다. AI의 판단 이상은 떨리는 윤곽·미혹 상태 표식으로 나타내며 종족 색은 유지한다. 이는 AI 판단 변화와 플레이어의 환경 대응이 다른 설계임을 명시한 것이다.

위 1초·3초·1.35배·1.25배는 Codex 초기값 제안이며 사용자 컨펌된 검증 초기값이다. 정신적 파멸과 산불을 함께 넣는 사용자 방향과 세부 규칙을 승인 반영했다.

#### 4. 전조·AI·능력 연동

파멸 활성/종료를 HUD에 알리되 사건의 전역 위치는 공개하지 않는다. 국소 전조는 보이는 구역에서 실제 활성 예정 범위를 표시한다. 배경색만으로 위험을 표현하지 않고 경계·패턴·남은 전조시간을 사용한다. 눈보라와 혹한의 가림은 먼 사건 위치를 숨기되, 자기에게 적용 중인 환경 피해와 탈출 방향은 자기 상태로 표시할 수 있다. 탈출 방향은 자신이 들어간 사건의 가장 가까운 경계 방향이며 외부 적 위치를 알려주지 않는다.

AI는 실제 감지 범위 안의 국소 전조를 환경 위협으로 보고 진입 목표를 피한다. 이미 사건 안이면 전조 중부터 사건 원 밖 +30 지점을 향해 탈출한다. 중심에 있으면 현재 진행 방향을 사용한다. 위험 원을 통과하는 일반 이동 경로는 기존 마그마 원 우회 규칙을 재사용한다. 감지 밖 사건을 전역으로 알아 우회하지 않는다.

성격·관계·집단 이동·행동 강제 명령보다 탈출이 우선한다. 숲의 노출된 AI는 위 상세 규칙의 1회 판단 지연만 예외로 제안하며 실제 피해/긴급 철수 조건은 즉시 우선한다. 진행 중 공격·회피·넉백은 완료하고 조작이 돌아오면 탈출하며, 빙결 중에는 이동할 수 없다. 정상 이동속도로 탈출해 하늘색의 무목표 배회 감속이 탈출에 적용되지 않는다. 승인된 제안 011 전쟁 집단 이동에도 같은 원칙으로 연결한다.

플레이어는 자동 이동시키지 않는다. 전조와 실제 피해가 일치하고 한 방향으로 움직여 벗어날 수 있어야 한다. 파멸을 피하는 것이 강제 포식자 사냥의 유일한 해결책이 되지는 않는다.

#### 5. 자체평가

- **언제 나타나는가:** 첫 size 180, 조건 충족, 실제 활성, 플레이어 첫 위험 조우 시간을 분리한다. 첫 최상위 목표 3~6분보다 훨씬 뒤에 나타나는지, 큰 AI 생성 때문에 예상보다 빨리 3마리가 되는지 확인한다. 미발동 실행도 포함한다. 필요하면 크기·개수 조건을 재제안한다.
- **우연히 마주칠 수 있는가:** 5000² 맵에서 반경 220 최대 2곳은 작은 면적이다. 활성 횟수만 많고 플레이어/AI 조우가 드물 수 있다. 전체 면적과 실제 체류·피해·전조 발견률을 기록해 파멸이라는 이름에 비해 체감이 없는지 평가한다. 위치 추적 생성으로 해결하지 않는다.
- **유지하기 힘들지만 대응 가능한가:** 사건별 전조 발견부터 탈출 시간, 피해량·사망·AI 탈출 성공을 비교한다. 이미 낮은 HP·빙결·큰 몸체·작은 화면에서 피할 기회가 없었는지 실제로 확인한다. 경계 판정은 기존처럼 개체 중심이지만 화면 표현이 몸체와 혼동되지 않아야 한다.
- **지역 차이:** 혹한은 지속 피해, 바다는 반복 이동, 화산은 교대 분출, 숲은 판단 이상과 진행하는 산불이다. 바다와 산불이 둘 다 이동 띠로 보일 수 있으므로 반복 파도와 일회성 확산·사라진 자리를 통과하는 행동의 차이를 확인한다. 원 안에서 가만히 서 있는 피해량뿐 아니라 통과·탈출 난이도를 비교한다. 설원만 과도하게 치명적이면 수치/패턴 수정안을 제출한다.
- **순환과 반복:** 기본 Era가 진행되고, 최대 120초·60초 대기가 작동해야 한다. 조건 완화로 끝나는 비율과 시간 만료로 끝나는 비율, 재발동 빈도를 기록한다. 같은 장소 반복 체류·이동 강제·거의 상시 파멸이 되는지 확인한다.
- **불공정한 정리인가:** 큰 개체만 죽여 순위를 초기화하는 장치가 되지 않아야 한다. 역할·size·종족·성격별 피해/사망을 비교하고 환경에 작은 개체가 더 많이 희생되는지도 본다. 파멸 전후 성장 경로와 생태계 회복을 확인한다.

- **숲 결합 효과:** 미혹만/산불만/둘 다를 비교해 목표 집착·위협 오판·막타 실패·탈출 지연이 실제 사건으로 드러나는지 확인한다. 성격별 행동이 모두 같은 자살 추격으로 바뀌지 않아야 한다. 미혹 때문에 산불 사망이 사실상 확정되거나 AI만 불공정하게 희생되면 지연·왜곡 강도를 줄이는 수정안을 제출한다.

- **플레이어 미혹 행동 강제 — 사용자 추가 평가 요청:** AI만 판단이 흔들리고 플레이어는 조작을 유지하는 현재안과, 플레이어에도 제한적인 행동 강제를 주는 실험안을 비교할 가치가 있는지 검토한다. 비교 후보는 짧은 목표 집착/방향 유도이며 구체 형태·강도·시간은 아직 미정이다. 입력 의도와 실제 행동의 차이를 알아차릴 수 있는지, 저항/해제·탈출 수단이 있는지, 재미와 긴장보다 답답함·억울한 사망이 커지는지 평가한다. 산불·빙결·저HP와 겹친 상황, PC·모바일/패드 조작 차이도 확인한다. 현재 승인된 플레이어 조작 유지 규칙은 그대로 두며, 행동 강제 채택은 별도 최소기획과 컨펌 후 적용한다.

#### 6. 완료 조건

기본 Era만 적용한 상태와 파멸 추가 상태를 가능한 동일 초기 상태로 비교한다. 파멸이 나타난 실행·나타나지 않은 실행을 구분하고, 각 지역 사건은 강제 시험 모드에서 최소 3회씩 탈출·피해를 확인한다. 자연 발생은 최소 10회 활성 사례를 관찰하되 표본 확보가 안 되면 시간·이유를 보고한다.

발동/완화 크기·개수 경계와 연속시간, 최대 지속·재발동 대기, 사망/직위 해제, 활성 한도, 위치 불가, 보상과 동시 배치, 파도 이동·산불 진행/꺼진 자리·미혹 노출/회복·성격별 판단 변화·1회 지연/긴급 철수·화산 교대, 피해 겹침, 일시정지·재시작·종료 즉시 복원을 검증한다. 프레임 비용·표시 가독성·피해 원인과 미수행 항목을 보고한다.

기본 스타일은 **벡터 일러스트**다. 기준은 [컨셉002](../03_아트/art-concepts/concept-002-vector.png)와 해당 벡터 프롬프트다. v0.18의 픽셀 선택 기록은 “2번” 해석 오류로 대체한다. 평면 색·명확한 윤곽·단순 지형·절제된 발광을 사용하고 종족색·실제 몸체 크기·전조를 유지한다. 컨셉은 래스터 참고로 실제 벡터 리소스 완료를 뜻하지 않는다. 생성 지형을 장애물로 추가하지 않는다. 모든 후보 이미지·프롬프트는 보존하며 교체 구조·성장 피드백014 전체는 아래 v0.20 승인 규칙을 따른다.

### 사용자 직접 수정 지시 — v0.17

최상위 직위를 얻을 때 기능 설명을 여러 개 띄우지 않는다. 별도 획득/상실 설명 배너와 직위 아이콘을 최소화하고, 오오라·영역·실제 능력 이펙트로 변화가 드러나게 한다. 사용 키·실제 준비/쿨다운만 기존 조작 정보에서 간결하게 제공하며 자세한 설명은 선택적 도움말로 둔다. 다른 절의 추가 표식 권장과 충돌하면 이 사용자 지시를 우선한다.

아트 스타일은 Codex가 생성한 실제 컨셉 이미지를 보고 사용자 컨펌을 받는다. 텍스트 계획만으로 시각 스타일을 확정하지 않는다. 성장 피드백 제안 014의 나머지 수치·전체 규칙도 v0.20으로 승인됐다.


원안의 모션그래픽·네온·블룸·카메라 연출을 전투와 성장의 피드백에 연결한다. 평상시에는 절제하고, 성장 해금·특수능력·시대 전환처럼 중요한 순간에 강도를 높인다.

표시 우선순위는 공격 전조와 피해 위험, 대상의 색·크기, 영역 경계, 장식 효과 순이다. 화면 흔들림과 섬광 강도는 조절할 수 있게 한다. 블룸 지원 여부와 비용은 현재 렌더링 구조를 조사한 뒤 결정한다.

### 성장 피드백 — 제안 014 승인

사용자 원안·최상위 표현 축소 방향과 Codex 상세 규칙을 컨펌해 반영했다.

#### 1. 목표와 기존 구현

실제 성장과 새로운 행동 가능성을 읽을 수 있게 한다. source 4e552a6에는 먹이/처치 성장 표시·파티클·돌진 잔상·공격/회피 최초 해금 배너가 있다. 이를 재사용·보완하며 게임 규칙·성장 계수·공격 속도를 연출 작업으로 바꾸지 않는다. 현재 확인은 정적 코드 기준이며 체감 검증은 미수행이다.

#### 2. 실제 크기와 성장 표시

몸체는 실제 size/2 반지름을 유지한다. 섭취할 때 몸체를 일시적으로 크게 그려 성장이나 충돌 범위를 오인시키지 않는다. 대신 몸 바깥의 얇은 빛 고리가 0.25초 퍼졌다 사라지는 장식을 사용한다. 성장·충돌은 즉시 기존 규칙대로 반영한다.

연속 섭취 성장 숫자는 플레이어 주변에서 0.4초 동안 누적해 한 번 표시한다. 원래 성장 적용/점수 가산은 합치거나 지연하지 않는다. 자연 먹이·AI 흡수·처치 성장의 출처를 아이콘으로 구분하고, 타인에게 생긴 작은 성장 숫자는 기본 숨긴다. 처치 표시를 성장 숫자와 구분해 중복 숫자로 화면을 채우지 않는다.

HUD는 현재 size를 주 정보, growth를 보조 정보로 표시한다. 다음 해금이 있으면 필요한 절대 size와 실제 성장식에 따른 진행 막대를 보여준다. 시작 size 대비 비율을 쓰지 않고 개체의 baseSize·growth에 맞춰 계산한다. size와 growth를 같은 단위처럼 표시하지 않는다. size 100이 됐다고 최상위 직위가 확정되는 안내는 하지 않는다.

#### 3. 행동 해금·직위 피드백

| 조건 | 표시 |
|---|---|
| size 40 | 공격 사용 가능·조작과 현재 스택 표시 |
| size 50 | 회피 사용 가능·조작과 현재 스택 표시 |
| size 70 | 회피 최대 스택 증가 표시 |
| size 100 | 공격 최대 스택 증가, 최상위 최소 크기 충족 표시 |
| 실제 최상위 획득 | 오오라·영역이 나타나고 능력 사용 가능. 설명 배너 없음 |
| 최상위 상실 | 오오라·영역·능력 사용 가능 표시가 실제 상태에 맞춰 사라짐 |

수치는 기존 해금/승인 직위 규칙을 따른다. 새 능력이나 성장 레벨을 추가하지 않는다. 해금에 따른 스택 충전은 기존 규칙을 유지하며 배너 때문에 충전하지 않는다.

새 게임 시작 시 이미 충족한 능력은 처음부터 활성 상태로 HUD에 표시한다. 초기 상태를 성장해서 해금한 순간으로 취급하지 않는다. 실제로 성장하며 기준을 통과했을 때만 배너를 보이고, 한 번에 여러 기준을 넘으면 하나의 묶음 안내로 표시한다. 최초 공격/회피 배너와 기존 안내를 중복 출력하지 않는다.

일반 공격/회피 최초 해금 배너는 최대 2초의 짧은 조작 안내로 제한한다. 최상위 획득/상실 배너·기능 설명·별도 직위 아이콘은 사용하지 않는다. 여러 기준을 한 번에 넘으면 설명을 쌓지 않는다. 능력은 사용하며 효과를 느끼게 하고, 사용 키와 준비/쿨다운은 기존 조작 표시 영역에서 최소한으로 제공한다. 상세 설명은 요청해서 여는 도움말에만 둔다.

최상위는 종족색 오오라와 승인된 영역 경계로 식별한다. 준비된 능력은 오오라의 안정된 밝기, 대기 중은 낮은 밝기/서서히 회복하는 흐름으로 표현하되 밝기만으로 조작 정보를 강제하지 않는다. 실제 초기 5초·쿨다운을 준수한다. 오오라는 몸체 크기·공격 범위를 늘리거나 전조를 가리지 않는다. 이 방향 수정은 사용자 직접 지시이며 나머지 제안 014 수치와 전체안도 사용자 컨펌 후 반영했다.

#### 4. 먹이 발견·전투·환경 표시

먹이 군집은 화면 안에서 실제 먹이와 일회성 전조가 보이면 충분하다. 별도 전역 화살표나 발견 성장 보너스는 없다. 풍부한 곳을 찾았다는 연출을 위해 숨은 먹이를 표시하지 않는다. 눈보라 가림을 준수한다.

공격 전조는 범위·진행 방향을 먼저 보여준다. 성공 타격은 피격 윤곽 0.12초와 짧은 접점 효과로 표시하며, 기본 화면 흔들림·전체 화면 섬광은 넣지 않는다. 처치는 몸체가 사라지는 지점의 짧은 파편과 실제 처치 여부 표식을 사용한다. 처치 효과를 사망 전 예측해 재생하거나 화면 밖 적 사망을 전역으로 알리지 않는다.

직접 공격·환경 피해·미혹은 접점 이펙트·경계·윤곽 패턴으로 우선 구분하고 별도 아이콘은 최소화한다. 색만으로 구분하지 않는다. 산불·마그마·파도·미혹의 판정 경계/방향/상태 표시는 장식보다 우선한다. 모든 이펙트는 판정·타이머·AI 정보와 분리하고 재시작 때 초기화한다.

#### 5. 강약과 설정

기본 우선순위는 위험 전조/상태 → 개체 색·크기·행동 → 영역/바이옴 경계 → 보상/해금 안내 → 장식이다. 한 화면의 성장/처치 장식은 동시 최대 8개, 초과분은 새 장식을 생략한다. 전조·경계·필수 HUD는 이 한도에 포함하지 않는다.

장식 강도 기본/낮음/끔 설정을 제공한다. 낮음은 장식 수를 절반으로, 끔은 고리·파편을 숨기되 실제 전조/해금/직위/상태 표시는 유지한다. 전역 블룸과 추가 카메라 워크는 별도 아트 계획의 미확정 구현 옵션이며 이 최소안에 자동 포함하지 않는다.

#### 6. 자체평가·완료 조건

- 실제 크기가 커지는 느낌과 숫자 증가를 구분한다. 같은 위치에서 size 20/40/70/100/200을 비교하고 기존 성장식·줌이 체감을 약화하는지 확인한다. 연출로 해결되지 않는 성장 문제는 별도 밸런싱 수정안으로 제출한다.
- 먹이 먹기·AI 흡수·처치·해금·직위 획득을 처음 보는 사람이 구분하는지 실제로 확인한다. size 100 도달과 최상위 획득을 혼동하지 않아야 한다.
- 밀집 전투·연속 성장·산불+미혹·눈보라·작은 화면에서 전조와 탈출 방향이 읽히는지 확인한다. 위험 표시가 보상 안내 뒤로 가려지면 우선순위를 수정한다.
- 배너 반복·장식 폭주·화면 흔들림 없이도 성장 보상이 전달되는지 본다. 플레이어를 보는 대신 숫자만 보는 흐름이 생기면 정보량을 줄인다.
- 절대 size 경계 전후·다중 경계 통과·랜덤 초기 size·직위 재획득·반복 타격·일시정지·재시작·장식 설정을 검증한다. 출처별 성장 합계와 기존 실제 성장/점수 일치 여부를 확인한다.
- 기존 효과와 추가 효과 켜기/끄기를 비교하고 실제 기기·개체 수·화면 크기·프레임 비용을 보고한다. 크기별 비교 화면과 실제 플레이 관찰의 한계를 함께 적는다.


### 스타일 교체 시스템 — 구조 승인

기본 스타일은 벡터이며 다른 스타일은 보존된 비교 후보다. 리소스/설정 교체 구조는 승인됐고 실제 구현은 Claude 담당 TASK로 구분한다.

#### 공통 표현 계약

게임 상태는 size·색·위치·역할·직위·HP·공격 단계·능력·위험 범위를 전달하고, 표현 계층은 현재 스타일의 리소스/설정으로 그린다. 스타일 선택은 growth·충돌·사거리·감지·타이머·개체 수를 바꾸지 않는다.

공통 키 예시는 unit.body, unit.apexAura, food.body, attack.telegraph, biome.forest, hazard.fire, status.delusion, ui.font이다. 실제 키는 Claude가 현재 렌더 구조 조사 후 확정한다. 각 스타일은 같은 키에 이미지/스프라이트/벡터 표현 또는 코드 렌더 설정을 대응한다. 빠진 필수 전조·경계는 공통 기본 표현으로 대체한다.

리소스팩은 manifest에 스타일 ID·버전·파일 경로·팔레트·선 두께·애니메이션 프레임/시간·원점·배율·픽셀 필터 설정을 적는다. 실제 폴더/설정 파일 구조는 구현 조사 후 TASK에서 확정하며 Codex는 source를 수정하지 않는다.

#### 스타일별 차이와 불변 조건

| 스타일 | 교체할 표현 | 유지할 의미 |
|---|---|---|
| 벡터 | 평면 색·선·단순 지형·정돈된 오오라 | 실제 원형 몸체·종족색·전조 |
| 픽셀 | 낮은 해상도 스프라이트/타일·최근접 필터·픽셀 입자 | 월드 판정은 연속 좌표, 시각적 스냅이 충돌을 바꾸지 않음 |
| 아케이드 | 검은 배경·네온 윤곽·먹이 점·간단한 지형 기호 | 미로처럼 보여도 승인되지 않은 벽/경로 차단을 만들지 않음 |
| 네온/질감 | 기존 생성안의 배경 질감·발광·큰 형상 | 전투 가독성·장식 성능 한계 |

최상위는 설명보다 오오라·영역으로 나타낸다. 스타일별 몸체/오오라 경계가 공격/충돌 범위로 오인되지 않아야 한다. 미혹·빙결·위험은 종족색을 덮지 않고 형태/패턴으로도 구별한다.

#### 적용 순서

1. 같은 장면의 실제 컨셉 이미지로 스타일 방향을 비교한다.
2. 사용자 선택 후 가장 작은 비교 범위인 개체·먹이·공격 전조·오오라부터 두 스타일로 구현 가능성을 검증한다.
3. 표현 호출을 공통 계약으로 정리하고 바이옴·환경·HUD로 확장한다. 기존 기능을 한번에 다시 쓰지 않는다.
4. 선택한 스타일 리소스를 로드하고, 안전한 첫 버전은 메뉴에서 선택해 다음 새 게임에 적용한다. 플레이 중 즉시 교체는 로딩·좌표·애니메이션 상태 검증 후 별도 제안한다.

새 스타일이 계약을 만족하면 게임 규칙 코드를 고치지 않고 팩을 추가할 수 있어야 한다. 완전히 새로운 표현 기술은 어댑터가 필요할 수 있으므로 모든 차이를 이미지 파일만 교체해서 해결한다고 약속하지 않는다. 의미 키와 렌더 설정으로 가능한 범위를 먼저 정한다.

#### 자체평가와 검증

같은 초기 상태에서 스타일만 바꿔 위치·성장·공격/피해 결과·AI 행동이 같음을 확인한다. 입력/월드 좌표와 화면 비율·줌·눈보라 가림도 동일해야 한다. 스타일별 bodyBounds·원점·오오라 외곽을 검토한다.

크기/색/위험 식별·타격감·성장 조망을 실제 플레이로 비교하고, 로딩 용량·메모리·프레임 비용·누락 리소스 대체·필터·일시정지/재시작을 확인한다. 이미지 선호도와 실제 게임 가독성이 다른지 구분한다.

구현은 Claude 담당이며 이 구조는 사용자 컨펌 완료다. 구체 코드/리소스는 구현 조사와 TASK로 정한다. 이미지 생성과 구조 설계 요청은 받았으나 구체 코드 변경·성능 결과가 완료된 것은 아니다. 기본 벡터 스타일은 사용자 선택으로 확정됐다.


## 11. 자동 플레이와 밸런싱 — 제안 015 승인

사용자 피드백 루프 원안과 Codex 최소 구조를 컨펌해 반영했다. 도구·실측은 아직 완료되지 않았으며 자동 후보의 기본값 적용은 별도 승인한다.

### 1. 재현 가능한 실행

각 실행에 코드 커밋·미커밋 차이·설정 스냅샷·난수 시드·시간 간격·자동 입력 정책/버전·시작 상태·실행 환경을 함께 저장한다. 커밋만 기록하고 미커밋 변경을 누락하지 않는다. 아직 미구현인 시스템 지표는 0 대신 미구현으로 기록한다.

초기 시험은 고정 시뮬레이션 간격 1/60초를 제안한다. 렌더·음향 없이 같은 상태 갱신을 실행할 수 있는지 먼저 조사한다. 불가능하면 브라우저 기반 실행을 사용하되 프레임/시간 재현 한계를 보고한다. 일시정지·실제 실행 시간과 게임 시간을 구분한다.

게임 판단/생성 난수와 시각/음향 난수를 분리한다. 장식 설정이나 벡터/픽셀 스타일이 생태계 결과를 바꾸지 않아야 한다. 비교 실행은 동일 시드를 쓰지만 난수 소비 흐름이 달라져 같은 사건이 보장되지는 않는다. 초기 생성·먹이·AI·지역/Era별 스트림을 가능한 범위에서 분리하고 구현 난이도를 보고한다.

같은 시드·설정·입력의 핵심 집계가 반복되는지 확인한 뒤 재현 가능으로 표기한다. 위치·HP·성장·역할/직위 같은 핵심 상태 체크포인트도 비교한다. 실제 브라우저 게임과 분리된 모의 코드로 규칙을 다시 구현하지 않는다.

### 2. 자동 플레이 정책과 해석

- **정지 플레이어:** AI 생태계만 관찰하는 기준선. 플레이어가 정지해 죽거나 스폰 상한에 영향을 주는 결과를 포함하며 유저 플레이로 해석하지 않는다.
- **단순 생존/성장 정책:** 실제 시야에서 먹이 탐색·위협 회피·허용된 공격/회피/능력 사용을 수행한다. 승인된 AI 규칙을 참고하되 플레이어 입력 인터페이스를 사용하며 전역 위치/숨은 HP를 읽어 최적화하지 않는다. 구체 정책은 구현 보고서에 명시한다.
- **고정 입력 재생:** 실제 관찰용 입력을 게임 시간 기준으로 재생할 수 있으면 추가한다. 분포 비교에서 동일 입력이 다른 조건에 불리해질 수 있음을 적는다.

정책은 초안 단계에서 최적 플레이 봇이 아니다. 정책별 결과를 섞어 평균내지 않는다. 자동 결과와 별도로 실제 플레이를 확인하며 자동 승률만으로 재미를 판정하지 않는다.

1초마다 집계 스냅샷, 발생 시 성장 경계/직위/사망/사건 로그를 저장한다. 참가자 ID와 원인을 남겨 원인 분석을 재현한다. 죽은 AI 재생성은 새 ID로 기록하고, 플레이어 Life 부활은 동일 개체의 부활 횟수를 따로 기록한다. 원문 로그와 요약 CSV/JSON·짧은 보고서를 함께 보관한다. 실제 저장 경로/스키마는 TASK에서 확정한다.

### 4. 첫 실험과 목표 판정

기준선은 시드 10개 × 게임 시간 10분으로 한다. 최소 두 기본 Era 순환이 포함되지 않으면 Era 검증은 추가 시간/별도 사례로 보완한다. 자연 발생하지 않은 파멸·유물은 미발생으로 기록하고 기능 강제 시험과 생태계 자연 실행을 구분한다.

승인 목표는 첫 최상위 3~6분·초기 1~2개체다. 첫 size 100·최초 직위·플레이어 조우는 별개다. 시작 시대·player size·초기 생성 분포별 중앙값·범위·미등장 비율을 보고한다. 관찰 목표를 전체 시드에 대한 무조건 성공 조건이나 등장 금지 규칙으로 바꾸지 않는다.

먹이 잔량·크기 계층·교전의 목표 수치는 기준선 실측 후 설정한다. 이번에 미측정 이상 비율을 확정하지 않는다. 경고 사례는 긴 먹이 부족, 한 개체의 반복 독점, 크기 구간이 사라진 상태의 지속, 환경 탈출 실패, 시대 최대시간 전환만 반복, 같은 지점 고착이다. 지속시간·빈도를 보고 원인별 목표/수정안을 제출한다.

### 5. 원인 분석과 후보 수치 탐색

기준선 저장 → 이상 사례 선택 → 관련 로그/구간 검토 → 가장 작은 수치 변경 후보 → 같은 시드 비교 → 새 시드 검증 → 실제 플레이 → 적용 판단 순서다.

첫 자동 탐색은 한 번에 한 설정만 바꾼다. 후보는 현재값 주변 최대 ±20%의 자연 먹이 생성 주기, 자연 먹이 성장값 배율, AI 생성 주기 중 **실험에서 명시적으로 선택한 하나**로 제한한다. 설정별 최대 5개 후보를 비교한다. 현재값도 후보에 포함한다. 실제 코드에 없는 성장 배율은 실험 설정으로 분리하고 생산 기본값을 바꾸지 않는다.

size 임계값·역할 비율·직위 수·성격 비율·동족/색 관계·시대 순서·지역 배치·능력 수락/피해·플레이어 조작은 첫 자동 탐색 범위 밖이다. 변경이 필요하면 별도 기획 수정과 컨펌을 거친다. 기존 승인 수치 주변 실험도 실제 기본값 적용까지 자동 승인된 것은 아니다.

탐색 10개 시드와 별도로 미사용 검증 시드 5개를 사용한다. 한 지표 점수를 높이는 대신 첫 최상위 시간·먹이 부족·작은 개체 생존·독점·성능의 변화를 함께 보고한다. 기준선 대비 개선/악화·불확실성을 후보별 비교하고 선택 이유를 적는다. 아직 미정인 목표에 임의 가중치를 붙여 최적값이라고 부르지 않는다.

### 6. 적용과 협업

자동화는 보고서와 설정 후보 파일까지만 생성한다. 사용자 플레이 중 실시간 수치 변경, 기본 설정 덮어쓰기, master push/배포는 하지 않는다. 후보는 코드 커밋/설정 차이·검증 결과와 함께 검토 가능하게 제출한다. 사용자 컨펌 후 Claude가 기본 설정 반영·커밋하며 병합/배포는 기존 승인 규칙을 따른다.

로그는 개발용으로 수집하고 디버그 표시를 끄면 일반 플레이에서 화면을 가리지 않는다. 데이터 수집이 난수·게임 시간·AI 행동에 영향을 주지 않아야 한다. 중단/타임아웃 실행도 삭제하지 않고 유효 관찰 시간과 실패 원인을 적는다.

### 7. 자체평가·완료 조건

재현 집계·시간 단위·난수 분리·숨은 정보 없는 자동 정책을 검증한다. 동일 입력/시드 반복과 렌더/아트 스타일 변경으로 핵심 결과가 바뀌는지 확인한다. 다른 환경에서 동일 결과를 보장하지 못하면 지원 환경을 명시한다.

원인 로그로 실제 사례 한 개 이상을 추적해 숫자가 행동 이유로 연결되는지 확인한다. 자동 후보가 탐색 시드에서만 좋아지는지 검증 시드로 비교한다. 자동 정책의 편향으로 숲 독점/위험 회피 결과가 왜곡되지 않는지 실제 플레이와 대조한다.

10분 관찰은 장기 균형의 증명이 아니다. 유망한 후보만 더 긴 관찰을 계획하고 필요한 이유를 적는다. 미구현 시스템·표본 부족·측정 비용은 숨기지 않는다. 목표에 맞추기 위해 개체를 강제로 생성/삭제하거나 동기를 몰래 바꾸지 않는다.


## 선택적 후순위 확장 — 계열 빌드016 조건부 승인

계열 구조는 Codex 제안이며 사용자가 원래 생각한 방향과 다르다고 명시했다. 흥미로운 실험으로 반영·구현 승인하되 핵심 게임과 출시를 막지 않고 쉽게 취소할 수 있게 한다.

### 구현 방침 — 후순위·쉽게 취소 가능

사용자는 계열 아이디어가 흥미롭지만 원래 생각한 방향과는 다르다고 명시했다. 반영·구현은 승인하되 핵심 생태계·능력·지역·Era·파멸·벡터 아트·배포 분리·기본 밸런싱을 구현/검증한 뒤 착수한다. 현재의 기존 결함과 새 피드백 수정도 이 기능보다 먼저 검토한다. 핵심 게임 출시를 막는 의존성으로 만들지 않는다.

별도 선택적 모듈과 단일 기능 토글로 분리한다. 첫 적용은 기본 끔, 명시적으로 켠 실험에서 검증한다. 끔 상태에는 계열 핵 생성·포인트 부여·선택 UI·AI 핵 목표·빌드 효과·관련 효과 표시가 모두 없어야 한다. 기존 사막 유물/자연 먹이/성장 해금은 그대로 작동한다. 모듈을 제거해도 기본 스탯·저장 형식·다른 능력에 필수 필드가 남지 않도록 한다.

토글은 다음 새 게임부터 적용해 진행 중 공격/흡수의 효과를 갑자기 바꾸지 않는다. 기존 저장에 빌드 필드가 없으면 기본값으로 읽고, 끔 상태에서는 빌드 필드를 무시한다. 기존 플레이어 기록을 삭제하지 않는다. 게임 난수와 별도 빌드 생성 난수 스트림을 써, 끔 상태에서 핵심 생태계의 난수 소비를 바꾸지 않는다.

독립 커밋/PR·명시적 대상 파일·테스트 결과로 제공해 되돌리기 쉽게 한다. 공통 스탯 훅은 기본 보정1로 동작하고 기능 코드가 없어도 기본 규칙을 유지해야 한다. 사용자 취소 요청 시 기본 끔·배포 제외로 즉시 범위를 줄일 수 있고 실제 삭제/revert는 변경 영향과 다른 작업을 확인해 수행한다. 기본 켬이나 핵심 게임으로의 통합은 실측 후 별도 컨펌이다.

### 1. 포인트와 계열 해금

절대 size 40/70/100에 도달하면 각 1포인트, 한 개체 최대 3포인트를 얻는다. 경계를 반복 통과하거나 Life 부활로 다시 지급하지 않는다. 성장으로 여러 기준을 넘으면 미지급 포인트만 한 번씩 지급한다. 초기 size가 이미 기준을 넘으면 초기화 때 해당 포인트를 지급하며 성장 해금 배너를 재생하지 않는다.

포인트만 있으면 능력을 배울 수 있는 것이 아니라, 해당 **계열 핵 아이템**을 얻어 먼저 계열을 열어야 한다. 핵은 흡수/공격/회피 세 종류다. 한 번 열린 계열은 같은 개체 생애 동안 유지한다. 다른 핵을 얻으면 다른 계열도 열어 포인트를 나눌 수 있다. 이미 열린 같은 계열 핵은 다시 획득하지 않는다.

기존 공격/회피 자체의 size 해금은 유지한다. 핵을 얻었다고 공격이나 회피를 조기 사용하지 않는다. 유효 포인트는 보관하고 나중에 쓸 수 있다. 아직 열지 못한 계열 때문에 기본 먹이 성장이나 최상위 획득이 막히지는 않는다.

### 2. 세 강화 — 누적 초기값

| 계열 | 1/2/3포인트 투자 효과 | 바꾸지 않는 규칙 |
|---|---|---|
| 흡수 | 동족 AI 흡수 소요시간 기본의 95/90/85% | 색·크기 조건·수락 확률·시작/유지거리·먹이 성장값 |
| 공격 | 일반 공격 후딜 기본의 95/90/85% | 피해·충전 전조·돌진 거리/시간·스택 충전·최상위 능력 |
| 회피 | 회피 스택 재충전 시간 기본의 95/90/85% | 거리·무적·이동시간·최대 스택·일반 이동속도 |

백분율은 계열 총 투자 단계의 효과이며 단계별 곱셈 누적이 아니다. 3포인트를 한 계열에 몰거나 1+1+1/2+1로 나눌 수 있다. 종족별 선택 강제는 없다. 이동 유물과 다른 스탯을 강화하므로 사막 유물 효과를 덮지 않는다.

흡수 시간 개선은 기존 동족 흡수의 시간 계산에만 적용한다. 즉시 자연 먹이 섭취나 파랑 포식의 대상 수락/크기 확률을 바꾸지 않는다. 공격 후딜 감소는 전조를 줄이지 않아 상대의 반응 시간을 유지한다. 최상위 일반 돌진 거리 70% 규칙과 독립이며 능력 쿨다운은 줄이지 않는다.

효과는 해당 동작이 시작할 때 결정해 고정한다. 진행 중 흡수/공격/회피 충전의 완료 시점을 포인트 투자 때문에 갑자기 앞당기지 않는다. 다음 동작/충전부터 새 효과를 적용한다. 기본 스탯·종족/시대 효과·아이템/빌드 보정을 분리해 원래 값을 누적 덮어쓰지 않는다. 정확한 기존 시간 계산 지점은 구현 조사 후 보고한다.

### 3. 계열 핵 출현·획득

첫 후보 선정은 게임 시간 120~180초 중 무작위, 이후 획득/만료부터 같은 간격이다. 전역 동시 하나, 수명 45초, 국소 전조 3초다. 핵 종류는 세 계열 중 균등 선택한다. 최초 최소안은 특정 시대·사막에 묶지 않는다.

유효한 바이옴 내부에서 매번 위치를 무작위 선택한다. 시작 중립 구역·마그마·파멸·지역 보상·사막 유물의 활성 구역과 겹치지 않으며, 직전 성공 위치 반경 180은 다음 출현에서 제외한다. 위치를 찾지 못하면 10초 후 재시도한다. 플레이어/특정 개체의 미해금 계열을 알아맞춰 종류나 위치를 생성하지 않는다.

획득은 사막 유물과 같은 중심 반경 20, 동시에 접근하면 가까운 거리 후 고유 ID 순이다. 이미 해당 계열을 연 개체는 획득 후보에서 제외하고 다른 개체에 기회를 남긴다. 아이템 자체는 growth·score·HP·직위 보너스를 주지 않는다. 세 종류는 서로 다른 모양/내부 무늬로 표현하며 종족 색 의미를 덮지 않는다.

핵 생성과 사막 유물/먹이 사건은 별도 타이머지만 위치 충돌을 공통 검사한다. 여러 종류의 파밍 사건이 지나치게 많아지는지 실제 발견·분포·섭취 지표로 평가한다. 생성된 핵과 해금은 새 게임 시작 시 초기화한다.

### 4. 플레이어 선택·AI 배분·죽음

플레이어는 포인트와 해금 계열이 있을 때 작은 선택 패널을 필요할 때 열어 투자한다. 자동 일시정지·화면 전체 강제 선택창은 넣지 않는다. 패널은 사용하지 않은 포인트·열린 계열·다음 단계의 한 줄 효과만 표시한다. 최상위 획득 설명 배너와 별개이며 항상 떠 있는 아이콘 묶음을 만들지 않는다.

AI도 동일한 핵·포인트 조건을 적용한다. 실제 감지 안의 미해금 핵을 일반 탐색 후보로 평가하되 생존·능력 명령·기존 전투/성장 목표보다 우선하지 않는다. 리스크 회피형은 안전 위치 조건을 요구한다. 획득 후 가능한 계열 중 성장 추구형은 흡수→공격→회피, 리스크 회피형은 회피→흡수→공격, 기회주의형은 공격→회피→흡수 순으로 투자한다. 최상위/프레데터 관계가 성격을 재배정하지 않는다.

최초 범위는 투자 취소/재분배를 지원하지 않는다. 플레이어 Life 부활은 기존 size/growth 유지와 함께 획득 계열·투자/미사용 포인트도 유지한다. AI 사망 후 새 AI는 새 개체로 포인트/계열을 초기화한다. 죽은 AI의 핵을 전리품으로 복제하지 않는다. 일시 색 변경 등 미승인 기능의 빌드 복원은 별도 기획한다.

### 5. 자체평가

- **선택의 재미:** 세 계열이 다른 플레이를 만드는지, 단순히 가장 좋은 하나만 고르는지 실제 플레이와 정책별 관찰로 비교한다. 숫자 강화만으로 부족하면 다음 단계에서 행동 변화를 주는 능력을 제안한다. 이 최소안이 전체 스킬트리 완성은 아니다.
- **랜덤 획득의 답답함:** 첫 핵 발견/획득/첫 투자 시간과 원한 계열 미획득·미사용 포인트 시간을 기록한다. 특정 아이템 해금이 탐험 동기보다 운 때문에 막히는 부담이 되는지 본다. 필요하면 종류 선택형 핵/보완 획득 경로를 후속 제안한다.
- **성장 가속·최상위 희소성:** size 100·첫 최상위·초반 포인트 지급·핵 독점·직위 생존을 빌드 켜기/끄기로 비교한다. 최대 15% 시간 개선이 기존 목표를 과도하게 앞당기는지 검증한다.
- **크기/성격/종족 편향:** 초기 큰 AI가 포인트와 핵 접근을 독점하는지, 특정 성격의 고정 배분이 항상 유리한지, 초록 낮은 흡수 경향과 흡수 빌드가 충돌하는지 본다. 추후 AI 배분을 다양화하기 전에 결과를 확인한다.
- **읽힘과 조작:** 벡터 스타일에서 핵 세 종류가 먹이·사막 유물과 구분되는지, 전투 중 선택 패널이 방해되는지 확인한다. 실제 입력 호환은 기존 디바이스 범위와 함께 검증한다.
- **파밍 고착:** 지역 보상/유물/핵이 겹쳐 전투와 성장보다 아이템 순회가 지배하는지, 발생 위치가 일부 바이옴에 몰리는지 비교한다.

### 6. 검증·완료 조건

승인된 자동 밸런싱 기반으로 빌드 켜기/끄기 동일 초기 상태 비교를 수행한다. 탐색 시드 10개와 미사용 검증 시드 5개·실제 플레이로 성장/생존/독점/체감을 보고한다. 미구현 자동 기반이면 재현 한계와 대체 관찰을 보고한다.

초기 size·40/70/100 경계·다중 통과·동일 핵 중복·동시 획득·종류 판정·포인트 저장/투자 합계 최대3·3단계 누적·진행 중 동작 고정·Life 부활·AI 재생성·일시정지/재시작·위치 없음/만료를 확인한다. 핵 종류·성격별 분포와 실제 파밍 시간·프레임 비용을 기록한다.


기능 끔 기준선 일치·관련 생성/UI/AI/효과 없음·저장 호환·모듈 제외 빌드·독립 변경 되돌리기를 검증한다.
