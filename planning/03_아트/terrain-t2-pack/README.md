# T2 SVG 지면 팩 · 구현 전달용 초안

2026-10-05. 사용자 T2 무늬·경계 방향 승인(“ㅇㅇ ㄱㄱ”). 공 재시안 방향도 승인됐다. 이 팩은 승인 방향을 단순 SVG로 옮긴 첫 제작본이다. 게임 적용은 아직 하지 않았다.

## 내용

assets/terrain/manifest.json과 지형 6종×3변형(400×400) SVG 18개, 가장자리 4방향·코너 4방향 알파 마스크 8개. 약 43KB. build.py는 제작 재현용이며 게임 코드가 아니다. preview.html은 공 5색·흰 링·반복 타일과 경계 혼합을 보여주는 독립 비교 화면이다.

## 확인과 한계

SVG 파싱과 파일 수·용량을 확인했다. 모든 변형은 같은 지형의 바탕색과 장식 없는 가장자리를 공유한다. 단순 이음새는 동일 색으로 맞지만 이 여백이 격자로 느껴지는지는 게임 시야에서 추가 확인해야 한다. 브라우저에서 비교 화면 렌더와 배율 버튼을 확인했고 초원 위 공 5색·흰 링은 읽힌다. 모든 지형의 실제 게임 줌·동적 전조·위험 표시까지 검증한 것은 아니다.

컨셉보다 장식 밀도와 음영을 더 줄였다. 대표 배경 형상·오브젝트 아트·환경 이펙트는 포함하지 않았다. 경계 마스크는 기본 페더링 템플릿이다. 컨셉의 굴곡은 코드 합성 시 경계 위치에 적용해야 하며 토러스·셀 코너 연결은 구현 측 검증이 필요하다. 비교 화면의 경계 예시는 CSS 합성 참고이고 마스크 8개 자체를 검증한 화면이 아니다.

## 연결 요구

1. 실제 게임 키 grass/forest/lake/snow/volcano/desert에 매핑한다. 게임 지형 판정·셀 경계·충돌 수치는 바꾸지 않는다.
2. 400월드 단위(2×2셀) 단위로 한 번 렌더/캐시한다. 변형은 셀 좌표 해시로 고정 선택하고 게임 난수를 사용하지 않는다. manifest의 해시 식은 전달 예시다.
3. 경계는 이웃 지형의 패턴을 alpha로 합성한다. 패턴 좌표를 월드 좌표에 고정해 셀마다 재시작하지 않는다. 모든 15종 지형 쌍·4방향·코너·토러스 이음새를 확인한다.
4. 자산 로딩 실패/아트 OFF는 기존 단색으로 복귀한다. shadowBlur·전체 화면 필터를 추가하지 않는다.
5. 실제 공의 몸 색·흰 전조·이득/위험 표식은 지형보다 위에 그린다. 이번 공 승인은 몸체 디자인 방향이며 기존 최상위 왕관/보석 표식을 폐기하는 별도 승인으로 해석하지 않는다.

## 후속

클라우드 연결 및 T5 실제 캡처 검증을 거쳐 필요한 부분만 수정한다. T3 오브젝트 비교판은 별도 제작 차수다. 기존 게임·main·공개 배포는 이 팩 제작으로 변경되지 않았다.
