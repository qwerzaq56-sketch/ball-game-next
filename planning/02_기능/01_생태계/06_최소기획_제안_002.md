# 최소 기획 제안 002 — 최상위 포식자와 영역

작성일: 2026-10-02 / 개정: 002-r2 / 상태: 사용자 컨펌 완료, 게임 기획서 v0.3에 반영

사용자가 2026-10-02에 r2를 승인했다. 기준본은 [게임 기획서 5절](../../00_기준/01_게임_기획서.md#5-최상위-포식자와-영역)이다. 아래 컨펌 대기 문구는 당시 제출 이력이며 현재 상태는 이 상단 기록을 따른다. r2는 r1 C절의 영역 접근 가중치를 대체한다.

## 자체평가 및 수정 제안 — 002-r2

사용자 직접 제안한 평가 관점: 최상위 등장 시간·빈도가 긴장과 희소성에 부합하는가, 프레데터의 접근에 자연스러운 서사가 있는가. 아래 실험 목표와 행동 수정은 Codex 제안이다. r1의 C절 이동 유인은 현재 재검토 대상으로 두고, 컨펌 전 구현 기준으로 확정하지 않는다.

### 1. size 100은 언제 얼마나 나타나는가

현재는 알 수 없다. 코드의 성장식으로 필요한 성장량은 계산할 수 있지만 먹이 조우·흡수·전투가 비선형적으로 바뀌므로 시간을 환산할 수 없다.

- 플레이어 기본 size 20에서 100까지 필요한 growth는 2500이다.
- 초기 AI의 큰 등급 size 39.2~56에서는 약 1444~756 growth가 필요하다. 초기에 큰 AI가 플레이어보다 일찍 100에 도달할 가능성이 있다.
- 큰 AI 생성 상한은 플레이어 크기에 연동된다. 플레이어 size가 75를 넘으면 큰 등급에서 size 100 이상이 직접 생성될 수 있다. 새 AI 점수 0은 승격 가능성을 줄이지만, 점수 상위가 적거나 동률이면 크기 조건만으로도 빠른 승격이 가능하다.
- 따라서 size 100은 희소성을 보장하는 값이 아니다. 기존 해금과 맞는 검증 시작점이다.

**잠정 목표 제안:** 첫 최상위 등장이 주로 게임 시간 3~6분에 발생하고, 첫 1분 안에 반복적으로 등장하지 않도록 한다. 처음에는 1~2마리의 존재가 눈에 띄는 경험을 목표로 한다. 3~6분과 1~2마리는 아직 합의·실측되지 않은 디자인 목표다. 단순히 오래 기다리게 하기보다 등장 전 성장과 생존 선택이 충분히 있었는지도 실제 플레이로 확인한다.

측정 항목:

- 각 실행에서 처음 size 100에 도달한 시간, 첫 직위 획득 시간, 플레이어가 처음 마주친 시간은 별도로 기록한다.
- 도달 원인을 성장·신규 생성으로 구분하고, 플레이어·AI를 구분한다.
- 1·3·5·10분 시점의 size 100 이상 수, 최상위 직위 수, 전체 개체 대비 비율과 직위 유지·교체 시간을 기록한다.
- 초기 재현 실험은 시드 10개 × 게임 시간 10분으로 제안한다. 조기 종료·미등장은 별도로 표시한다. 자동 실행은 사용자 경험의 시간 추정과 구분하며, 실제 플레이는 가능한 범위에서 최소 3회 관찰한다.
- 최초에는 분포를 확인한다. 목표보다 빠르거나 흔하면 최소 size, 생성 상한 연동, 점수 자격을 각각 비교한다. 3분 고정 출현 금지나 등장 개수 제한을 검증 없이 추가하지 않는다.

**자체평가:** r1은 최소 크기 선택의 근거는 있으나 등장 시간 근거가 부족하다. 직위의 상한 5마리는 희소성을 자동 보장하지 않는다. 측정 없이 size 100을 최종 조건으로 확정하기 어렵다.

### 2. 왜 프레데터가 최상위 주변에 접근하는가

기존 r1의 ‘가까운 최상위 영역을 알고 확률적으로 이동’은 시스템 목표만 설명한다. AI 입장에서는 먹이·상대 등 실제 기회가 없어도 움직여서 인위적인 집결로 보일 수 있다.

**대체 행동 제안: 영역 자체로 유인하지 않고, 그곳에서 발생한 성장 기회를 따른다.**

- r1 C절의 영역 소유자 탐색·50% 접근·8초 목적지 유지 규칙을 제거하는 안이다. 직위와 반경 600은 유지한다.
- 기존 AI 감지 안에서 관찰한 먹이 또는 흡수·전투 대상 때문에 접근한다. 영역 중심을 탐색 목표로 쓰지 않는다. 초기에는 기존 감지 범위와 대상 우선순위를 유지한다.
- 큰 개체의 전투 처치 보상은 이미 먹이 군집을 만든다. 최상위 주변에 교전이 생기면 살아남은 개체와 주변 AI가 이를 수확하고, 새로운 충돌이 생기는지를 먼저 관찰한다. 최상위 직위만으로 전투 빈도를 높이지 않는다.
- size 70 이상 프레데터가 체력 50% 초과이고 추격·회피·흡수 중이 아닐 때만, 감지된 먹이를 중심 거리 120 이내 묶음으로 평가한다. 자신이 현재 먹을 수 있는 orb의 growthValue 합이 80 이상인 묶음이 있으면 기존 배회보다 우선한다. 여러 묶음은 중심까지 거리가 가장 가까운 것을 선택한다. 이는 종족·영역과 관계없이 동일하게 적용한다.
- 실제 추적 대상은 묶음의 가장 가까운 먹이 한 개다. AI 판단 주기마다 먹이와 위협을 다시 확인한다. 먹이가 없어지거나 먹을 수 없거나 감지 밖으로 나가면 해제하며, 다른 생존·전투 우선순위는 유지한다.
- 성장 가치 80·묶음 거리 120은 검증용 제안이다. 누적 세계 정보나 맵 전체 먹이 탐색은 추가하지 않는다. 집계의 성능 비용을 측정하고 현재 공간 검색 결과를 재사용한다.

예상 서사: 큰 개체끼리 교전 → 보상 먹이가 남음 → 주변 포식자가 수확 기회에 접근 → 경쟁이나 새로운 교전 발생 → 작은 개체는 위험을 피해 이동하거나 남은 먹이를 노림. 이는 가능성이지 보장된 이벤트가 아니다. 실제 로그에서 교전·먹이 발생·접근·섭취 순서를 확인해야 한다.

**자체평가:** 행동 동기는 자연스러워지지만 ‘영역 가까이에 큰 적이 더 많음’은 약해질 수 있다. 기존 보상과 국소 먹이 판단만으로 분포가 형성되는지 확인한다. 실패하면 영역 집결을 몰래 다시 넣지 않고 생성 분포나 지역 자원 배치에 대한 다음 제안을 제출한다. 먹이 군집에 모든 역할이 모여 초반 성장을 방해하는지도 평가한다.

### 3. 이번 재제안의 판단

직위 조건 size 100과 영역 반경 600은 측정을 시작할 가설로 유지한다. 이동은 성장 기회 기반으로 수정하는 것을 권장한다. 등장 시간·희소성·행동 동기 검증을 완료 조건에 추가한다. 사용자의 컨펌 전 기준 기획서와 반영 로그에는 확정 규칙으로 반영하지 않는다.

## 코드 분석 후 재제안 — 002-r1

이 절이 현재 제출안이다. 아래 최초 제안은 이력이며 구현 기준으로 사용하지 않는다. 기준 기획서에는 아직 반영하지 않았다.

분석 대상: `qwerzaq56-sketch/ball-game`, 커밋 `4e552a6026f35ea46eaf49a46505fa14180294f1`. 상세 근거는 [코드 분석 메모](../../04_개발_협업/07_코드_분석_메모.md)에 기록한다. 실행 실측이 아닌 정적 코드 분석이다.

### A. 직위와 공통 점수

- 모든 플레이어·AI에 개체 점수를 둔다. 생성 시 0으로 시작하며, 랜덤 시작 크기 자체로 점수를 주지 않는다.
- 현재 플레이어 규칙을 공통으로 적용한다. 먹이 섭취는 `round(먹이 growthValue)`, 동족 흡수는 `round(흡수한 growth)`, AI 전투 처치는 `round(직접 성장 보상) + 100`을 획득한다. 처치 후 떨어진 먹이를 주우면 그 먹이 점수도 별도로 획득한다.
- 현재 플레이어 처치 시에는 처치자 보상 없이 패배 처리로 바로 반환한다. 이번에는 이 규칙을 유지하며 AI의 플레이어 처치에도 직접 처치 점수를 추가하지 않는다. 변경하려면 별도로 제안한다.
- 플레이어의 Life 부활에서는 기존 점수·크기를 유지한다. AI 사망 후 새로 생성된 개체는 새 점수 0으로 시작한다. 전체 초기화 시 모든 개체 점수를 초기화한다. 기존 HUD·로컬 Top 10에는 플레이어 개체 점수를 연결해 이중 가산을 방지한다.
- 살아 있는 플레이어·AI의 점수 상위 5마리 중 **`size >= 100`(실제 반지름 50)**인 개체만 최상위 포식자로 인정한다. 크기 미달인 상위 개체를 건너뛰어 6위 이하를 승격하지 않는다.
- 최소 크기 100은 현재 두 번째 공격 스택 해금 기준과 같다. 랜덤 초기 크기나 누적 성장값에 종속되지 않는 절대 기준이다.
- 2초마다 평가하며 후보 자격이 두 번 연속 같으면 직위를 변경한다. 최초 배정은 즉시, 사망 시 해제도 즉시 처리한다. 플레이어가 같은 업데이트에서 즉시 부활하더라도 패배 이벤트에서 먼저 직위·영역을 해제하고 재선정은 두 번 연속 평가를 거친다.
- 동률은 기존 순서를 유지하고 신규 동률은 ID 순으로 정한다. 직위와 프레데터 역할은 독립적으로 계산하며 직위만으로 스탯을 바꾸지 않는다.

### B. 영역은 고정 절대 반경 600

- 소유자를 따라가는 원의 반경을 **월드 좌표 600**으로 한다. 크기에 따라 영역을 확대하지 않는다. 맵 경계에서는 표시와 이동 목적지를 맵 안으로 제한한다.
- 5000 × 5000 맵에서 5개 영역이 전혀 겹치지 않아도 합계 면적은 약 22.6%다. 영역 밖 공간을 확보하기 위한 초기값이며, 공간이 남는다는 계산이 생존 안전성을 보장하지는 않는다.
- 소유자 색의 얇은 경계와 낮은 불투명도 내부, 직위 아이콘을 표시한다. 진입 HUD는 가장 가까운 소유자 한 명을 안내한다.
- 영역 겹침을 허용하되 이동 유인이나 효과를 중복 적용하지 않는다. 영역은 위험 안내이며 통과 제한·지속 피해·점령 효과는 없다.

### C. 큰 AI를 유도하는 지속 이동

- 대상: **프레데터 역할이면서 `size >= 70`, 체력 50% 초과, 최상위 직위가 없는 AI**. 크기 70은 현재 두 번째 회피 스택 해금 기준이다.
- 추격·흡수·피격 회피·도주·공격 동작이 없는 탐색 상태에서, 다른 개체의 영역 소유자가 중심 거리 **1200 이내**일 때만 유인을 고려한다. 맵 전체의 최상위 위치를 추적하지 않는다.
- 가장 가까운 적격 영역을 선택하고 새 배회 목표를 고를 때 50% 확률로 그 영역의 중심 거리 **300~600** 사이에 목적지를 정한다. 같은 색 영역도 가능하며 기존 흡수·전투 판정이 관계를 결정한다.
- 목적지는 맵 안의 고리 부분에서 선택한다. 선정 실패 시 기존 배회를 사용한다. 목적지는 최대 **8초** 유지하고 **80 이내** 도달, 소유자 사망·직위 해제, 먹이·흡수·전투 대상 발견 또는 생존 반응 발생 시 즉시 해제한다. 선정 후에는 목적지를 고정해 움직이는 소유자를 계속 따라가는 추적 명령으로 만들지 않는다.
- 현재 배회는 1~3초마다 방향을 바꾸고 이동속도도 55%라 긴 이동 명령을 수행하기 어렵다. 영역 이동은 기존 탐색 속도를 유지하는 별도 목적지 상태로 구현하고 매 프레임 목적지 방향으로 이동한다. 기존 공격·회피 동작 및 흡수당할 때 도주를 우선한다.
- 강제 이동이나 스폰 분포 변경은 없다. 기존 플레이어 주변 350 거리 안전 스폰 정책도 유지한다.

### D. 완료 조건과 범위

- 먹이·흡수·처치 점수가 플레이어와 AI에 동일한 계산으로 한 번씩 가산되는지 확인한다. 현재 플레이어 처치 예외도 유지한다.
- 점수 상위 5위와 `size=99/100` 경계, 동률, 직위 유예, AI 사망, 플레이어 부활, 전체 초기화를 확인한다.
- 영역 반경이 소유자 크기와 무관하게 600인지, 겹침·맵 경계·HUD가 정상인지 확인한다.
- 영역 유인이 먹이 추적·전투·도주를 중단시키지 않고 목표 만료·도달·소유자 사망 시 해제되는지 확인한다.
- 위험 분포는 아래 최초 제안의 3개 시드·거리별 평균 크기 비교를 사용하되 R은 600으로 고정한다. 통제 테스트로 행동 동작을 확인하고, 자연 시뮬레이션으로 안쪽에 큰 AI가 더 모이는지는 따로 평가한다. 이 조건을 만족하지 않으면 후속 수정안을 제출한다.
- 현재 `Math.random()` 기반이라 재현 시드는 아직 없다. 자동 비교 전 생성·AI·전투·보상에 사용하는 난수의 시드 제어와 시뮬레이션 시간 고정을 추가해야 한다. 그 전 관찰 결과는 재현 가능한 비교 결과로 표기하지 않는다.
- 원안의 특수능력과 기존 공격 거리 감소는 다음 제안에서 함께 설계한다. 이번은 영역 기반 위험 선택을 검증하는 단계이며 최상위 포식자 전체 기능의 완료가 아니다.

위 수치는 코드 구조에 맞춘 검증용 제안이며 플레이 실측으로 확정된 값은 아니다.

## 최초 제안 — 대체됨, 이력 보존

출처: 최상위 5마리·최소 크기·영역·주변 위험 분포는 사용자 직접 제안. 아래 수치와 적용 방식은 Codex 제안이다. 컨펌 전에는 기준 기획서와 반영 로그를 변경하지 않는다.

## 목적과 범위

플레이어가 눈에 보이는 위험 영역에 접근하거나 피하며 난이도를 선택하게 한다. 이번에는 직위 선정, 이동하는 영역, 큰 AI의 접근 경향과 검증을 구현한다. 특수능력과 기존 공격 이동거리 감소는 함께 균형을 맞춰야 하므로 별도 제안으로 묶는다.

## 최소 규칙

### 1. 직위 선정

- 살아 있는 플레이어와 AI를 점수 내림차순으로 정렬한다. 점수 상위 5마리 중 시작 반지름의 3배 이상인 개체만 최상위 포식자로 인정한다. 조건을 충족하는 개체가 적으면 5마리 미만일 수 있다. 시작 반지름은 종족·개체별 값이 아닌 게임의 공통 기본 시작 반지름을 사용한다.
- 2초마다 평가하고, 새로 자격을 얻거나 잃는 상태가 두 번 연속 나오면 직위를 변경한다. 사망하면 즉시 직위와 영역을 해제한다. 최초 평가에서는 즉시 배정한다.
- 점수 동률은 이전 순서를 유지하고 신규 동률은 고유 ID로 정한다.
- 프레데터 역할과 최상위 직위는 별개다. 점수와 크기 순위가 다르면 두 판정이 다를 수 있다. 직위 자체는 행동 우선순위나 스탯을 변경하지 않는다.

### 2. 영역

- 영역은 소유자의 현재 위치를 중심으로 따라가는 원이다. 반경은 `max(소유자 반지름 × 8, 공통 기본 시작 반지름 × 30)`으로 시작한다.
- 영역은 맵 경계에서 잘라 표시하고, 소유권·통과 제한·피해 효과를 부여하지 않는다. 겹침을 허용하며 겹침 자체로 위험 가중치를 중복 적용하지 않는다.
- 경계는 소유자 색의 얇은 선으로, 내부는 낮은 불투명도로 표시한다. 공의 진영 색과 공격 전조를 가리지 않는다. 소유자에게 왕관 또는 별도 직위 아이콘을 표시한다.
- 플레이어가 영역에 들어오면 HUD에 ‘최상위 포식자 영역’과 소유자 식별명을 표시한다. 겹친 곳은 가장 가까운 소유자 한 명을 기준으로 표시한다. 영역을 벗어나면 안내를 해제한다.

### 3. 위험 분포 유도

- 기존 AI 감지 범위나 흡수·전투 판정은 변경하지 않는다. 현재 감지 대상이 없는 프레데터의 탐색에만 영역 접근 경향을 추가한다.
- 프레데터가 체력 50% 초과이고 추격·회피·위험 대응 중이 아닐 때, 배회 목적지를 고르는 시점에 50% 확률로 가장 가까운 다른 개체의 영역 안을 목적지로 선택한다. 목적지는 중심까지 거리 `0.5R~R`의 고리에서 선택한다. 적격 영역이 없으면 기존 탐색을 사용한다.
- 최상위 직위 보유자는 위 이동 가중치에서 제외한다. 이 단계에서는 최상위끼리의 교전을 추가로 유도하지 않는다.
- 영역 밖 목적지의 안전이나 먹이 확보를 보장하지는 않는다. 프레이는 컨펌된 도주 규칙을 사용한다. 영역 밖의 생존 경로가 실제로 남는지 검증한다.
- 개체를 강제 이동하거나 순위 변동 때 재생성하지 않는다. 영역만 보고 맵 전체의 적 위치를 알게 되는 효과도 없다. 생성 분포 변경은 이번 결과를 본 뒤 필요하면 별도 제안한다.

위 방식은 ‘가까울수록 큰 적’이라는 원안을 완전히 보장하지 않는다. 먼저 자연 이동만으로 위험 차이를 만들 수 있는지 검증하는 최소 구현이다. 차이가 없다면 구현 완료로 간주하지 않고 가중치·생성 정책의 후속 수정안을 제출한다.

## 설정과 확인 기준

최소 크기 배수, 평가 간격, 연속 후보 횟수, 영역 반경 배수·최소 반경, 이동 선택 확률, 접근 가능한 체력 비율은 설정값으로 분리한다. 모두 검증용 초기값이다.

- 상위 5위·최소 크기 조건을 각각 확인한다. 상위 5위라도 크기 미달이면 직위가 없어야 한다.
- 순위 변화의 유지·해제 유예, 사망 즉시 해제, 동률 처리와 플레이어 적용을 확인한다.
- 소유자 이동·맵 경계·영역 겹침 시 표시와 안내가 정상인지 확인한다.
- 프레데터의 영역 접근이 추격·회피를 끊지 않고, 작은 개체의 기존 도주와 색상 규칙을 유지하는지 확인한다.
- 자동 실행이 가능하면 기존 AI와 변경 AI를 같은 시드·시작 상태로 10분씩 비교하고 최소 3개 시드를 사용한다. 불가능하면 통제 시나리오와 관찰 기록을 제출하고 자동 비교 미수행을 표시한다.
- 거리별 크기는 자기 자신을 제외한 살아 있는 AI를 가까운 영역 소유자 한 명에 배정해 집계한다. 중심 거리 `0~R`, `R~2R`, `2R 이상` 구간의 평균 반지름·개체 수·관측 횟수를 기록한다. 영역이 없는 시간은 제외하고 빈 구간은 0으로 처리하지 않는다.
- 위험 분포의 초기 합격 기준: 유효한 안쪽·바깥쪽 표본을 가진 시드 3개 중 2개 이상에서 `0~R` 구간 평균 반지름이 `2R 이상`보다 높아야 한다. 표본 부족은 합격으로 처리하지 않는다. 수치 차이의 크기는 함께 보고한다.
- 영역 합집합이 맵의 70%를 넘는 시간이 발생하는지 기록한다. 반복적으로 넘거나 영역 밖 성장 경로가 막히면 반경 수정안을 제출한다. 즉시 자동 축소 규칙은 넣지 않는다.

## 이번에 보류하는 항목

색별 특수능력, 기존 공격 이동거리 감소, 직위별 스탯 보너스, 고정 영토와 점령, 큰 AI 생성 가중치는 이번 범위에 포함하지 않는다.
